# Medic Class Guide — Zombie Assault Resurgence Support

The Medic is the support class in Zombie Assault: Resurgence, and the first question players ask about it is whether support is worth a slot in a game built around shooting. The short answer: in a co-op squad that holds objectives, yes — and solo, the class is playable but has to be built differently. This guide covers the role, the point economy, and how to stay useful without turning into a passenger.

## What the Medic actually is

All three classes share the same skeleton: six Core skills, six Class skills, three Activated Abilities and two Speciality branches, with the third ability unlocking at rank 10. The Medic's identity comes from where its Class skills point — toward keeping the squad alive rather than adding raw damage.

Two official facts matter before any build advice. First, the game is being built to be **equally playable solo and in multiplayer**, so the Medic is not designed as a class that cannot function alone. Second, the launch build has not published a public list of Medic skill names or values. That means the honest guide explains the decisions and the trade-offs, and refuses to invent node names or percentages. Anything that quotes exact ZA:R numbers right now is either from the older SAS4 game or made up.

## The Medic's real value: uptime

A squad does not fail because it lacks damage; it fails when players go down and the team has to fight through revives. The Medic's contribution is uptime — keeping four mercs firing instead of three, and keeping the objective defended while someone is healed.

That value scales with the mission type. In Cache Recovery and Uplink, where the squad must hold a position while a timer runs, a support class directly protects the objective. In pure Eradication runs the value is lower, because a fast squad that never gets surrounded needs less healing. Build and pick your missions with that in mind.

## The point economy

Skill points are split into three types, and the Medic build has to respect the split.

| Type | When it arrives | Use |
|---|---|---|
| Basic | Levels 1, 4, 6, 8, 10, 12, 14, 16, 18, 20 | Shared Core skills |
| Class | Levels 2, 3, 5, 7, 9, 11, 13, 15, 17, 19 | Medic-specific Class skills |
| Subclass | First at level 20, then every other level | Locked Speciality branch |

By level 20 that is 10 Basic, 10 Class and 1 Subclass point ([Community] Levels (ZAR)). The Medic's temptation is to pour Class points into support nodes and leave the Core tree untouched, which produces a healer who dies before the heal lands. Core survivability is not optional for a support class.

## A support build order, level 1–20

This is an editorial plan, not a datamined one. It assumes you want to be a reliable squad member first and a damage dealer second.

| Phase | Levels | Priority | Why |
|---|---|---|---|
| Stay alive | 1–6 | Core survivability and weapon handling | A dead Medic heals nobody |
| Support core | 7–12 | Class nodes that improve healing and team utility | This is the reason the class exists |
| Third ability | 10 | Unlock the third Activated Ability | A third cooldown is extra recovery and utility |
| Branch preview | 13–18 | Bank Class points and read both Speciality branches | The branch locks in permanently |
| Subclass | 20+ | Spend the first Subclass point into the chosen branch | Subclass points only fit the locked branch |

The important discipline is at level 13–18: do not commit to a Speciality branch until you have read both. The choice is permanent for that character, and a respec costs in-game currency that is better spent on gear.

## Making the Medic work solo

Solo is where support classes usually fall apart, and the fix is to stop building like a pure healer. Alone, there is no one to heal but yourself, so the value of dedicated support nodes drops and the value of self-sustain and damage rises.

Three adjustments make a solo Medic viable:

- **Lean on Core survivability and self-healing.** If your Class tree heals allies, the same investment should keep you upright when there are no allies.
- **Carry a real damage weapon.** The [weapon catalogue](/guides/all-weapons-guide) has plenty of options; a support class that cannot clear a room will stall.
- **Play the objective modes defensively.** Holding a point solo is easier with sustain than with a glass-cannon build.

The developers' statement that the game is equally playable solo is the licence to try it — but it is a statement about viability, not about the Medic being as fast or as strong solo as an Assault.

## Three abilities, three jobs

Every class gets three Activated Abilities, with the third unlocking at rank 10. For a support player the split is slightly different from a damage class, because one of the three is almost always reserved for recovery.

A workable division of labour is one ability that saves a life, one that saves the objective, and one flex slot. The save-the-life slot is your answer to a player going down in the open. The save-the-objective slot is area denial or a defensive cooldown used when the horde reaches the point during Uplink or Cache Recovery. The flex slot is where mission type decides: a mobility or damage cooldown for Eradication, something defensive for Close the Breach.

The mistake is treating all three as healing buttons. Resurgence hands you a cooldown budget, not a heal budget, and a support class that only spends cooldowns on recovery has nothing left when the objective is about to fall.

## Weapons and gear for a Medic

The Medic is not weapon-locked, so the pairing is about covering the squad's gaps. In a typical four-player group the Assault and Heavy bring the damage, which frees the Medic to carry utility: a reliable mid-range primary, an area-denial option, and a secondary that can answer an elite that gets too close.

| Slot | What to prioritise | Reason |
|---|---|---|
| Primary | Reliable mid-range automatic | You need to contribute damage, not just heal |
| Secondary | Hard-hitting close-range answer | Elites break through to the back line |
| Utility | Grenade or turret (HVM options were in the demo) | Area denial protects the objective and the squad |
| Armour | Current tier, upgraded alongside skills | Gear is half of survivability |

Invest in one weapon rather than spreading upgrades thin. The [mod and crafting guide](/guides/weapon-mods-and-upgrading) explains how upgrading and mods work, and the [best weapons tier list](/guides/best-weapons-tier-list) gives a role-based shortlist for the launch build.

## Co-op etiquette that actually helps

A Medic who stands at the back and only heals is under-using the class. The better pattern is to position with the squad, heal proactively rather than reactively, and use your utility to shape where the horde meets the team. Three habits separate a good support player from a passive one:

- **Heal before the bar is critical.** Reactive healing loses players to burst damage.
- **Call the objective.** A support class is well placed to track the timer and warn the squad.
- **Do not chase a downed player into the open alone.** Trading two deaths for one revive is how runs end.

## Mistakes to avoid

- **Building pure support and nothing else.** Core survivability keeps the support alive.
- **Ignoring damage entirely.** A Medic who cannot clear a lane is a liability.
- **Locking a Speciality branch early.** Read both, then commit.
- **Assuming SAS4 skill names and numbers apply.** Resurgence has its own mods, rarity and Subclasses.
- **Playing support in a mode that does not need it.** Pure Eradication squads often want more damage instead.
