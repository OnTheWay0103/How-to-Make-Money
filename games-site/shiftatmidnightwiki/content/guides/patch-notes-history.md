## Shift At Midnight Patch Notes & Update History

*Shift At Midnight* (solo Australian indie **Bun Muen**, published by **Kwalee**) launched **July 22, 2026** on Steam and Xbox Game Pass. Launch week was strong — the game quickly climbed to a "Very Positive" rating — but early players hit **lobby connection problems**, and the developer responded with a temporary beta branch so affected players could keep playing while fixes were prepared.

This guide covers what is **officially confirmed** about the game's updates: the network-issues-patch beta branch, the Endless Mode beta, and the Q4 2026 roadmap. A note up front: the developer has not published a detailed day-by-day changelog, so third-party "patch history" lists should be treated with caution — where a change isn't announced officially or documented consistently by the community, this guide does not repeat it as fact.

---

## Launch & the Network Issues Patch

Some players could not join friends' sessions at launch, which is a serious problem for a co-op horror game. The developer's response was a temporary Steam beta branch so affected players could play immediately:

### How to Opt Into the Network Fix Beta Branch

1. Open Steam → right-click *Shift At Midnight* → Properties
2. Go to **Betas** (Game Versions & Betas)
3. Enter the access code: **`networkissues`**
4. Select the **`network-issues-patch`** branch from the dropdown

**Important**: everyone in your co-op group must opt into the same branch for it to work. Mixing versions breaks lobbies — this remains the most common cause of "can't connect" reports.

This branch is still the community's first recommendation when nothing else fixes connection issues. If you're still struggling after updating, see the [PC Performance & Issues Guide](/guides/pc-performance-guide) for the full network troubleshooting list.

## What Has NOT Been Confirmed

Some community posts and third-party guides describe specific patch details that have **no official confirmation** — including a supposed "6-player lobby" expansion and exact balance changes. Treat those with skepticism:

- The Steam store page describes the game as **1-3 player co-op**; claims that lobby size was expanded beyond that are not officially confirmed.
- Exact stat changes (health, damage, audio) are not disclosed by the developer; any guide citing precise numbers for a specific patch is speculating.
- "Full update history" lists with dated entries beyond the launch branch and roadmap have no official source.

If a guide on this site describes a mechanic, it reflects what the community consistently documents — not a specific patch version.

## How to Stay Updated and Report Bugs

- **Steam**: updates install automatically; check the game's announcement feed for patch notes and beta branches
- **Discord**: the official server is the developer's stated channel for bug reports and patch feedback
- **Steam Community Hub**: patch threads are usually pinned shortly after each update

A quick version check before a co-op session saves headaches: make sure everyone is on the same build — mixed Steam/Game Pass versions and one player on the beta branch are both common lobby killers.
