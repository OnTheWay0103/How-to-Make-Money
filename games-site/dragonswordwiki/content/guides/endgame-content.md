## Endgame Content Guide — Post-Story Loop & Farming

After the main story, DragonSword: Awakening shifts into a structured endgame loop: heroic dungeons, weekly raids, gear set farming, and familiar collection all feed into one progression track. This guide explains the loop and the order that maximizes your weekly gains.

### The Endgame Loop

| Activity | Cadence | Primary Reward |
|----------|---------|----------------|
| Heroic Dungeons | Daily | Set gear pieces |
| Weekly Raid Lockout | Weekly | Raid tokens, legendary sets |
| Familiar Expeditions | Daily | Familiar eggs, upgrade cores |
| World Events | Rotating | Enchantment materials |
| PvP Arena | Anytime | PvP tokens, unique trinkets |

### Heroic Dungeon Guide

1. **Unlock:** Heroic versions of all 6 story dungeons unlock at level cap with item score 3,400+.
2. **Scaling:** Heroic bosses gain 3 new mechanics each; the last dungeon (Heroic Throne) adds a hard enrage at 5 minutes.
3. **Set farming:** Each heroic dungeon drops 2 specific set pieces. Farm the dungeon, not the boss, for your set.
4. **Daily bonus:** The first heroic clear each day grants a guaranteed set piece — always spend it on your lowest set slot.

### Gear Set Farming

| Set | Dungeon | Bonus | Priority |
|-----|---------|-------|----------|
| Ember Ward | Heroic Cinder Mines | +15% fire damage | High for DPS |
| Iron Oath | Heroic Iron Bastion | +20% armor | High for tanks |
| Stormcaller | Heroic Sky Temple | +15% crit chance | High for crit builds |
| Abyss Sigil | Heroic Throne | +10% all stats | Top priority |

### Familiar Collection

- **Expedition slots:** Complete daily expeditions to collect eggs; each familiar grants a passive stat bonus.
- **Upgrade cores:** Familiar upgrades come from weekly raid tokens — spend them on your expedition familiar first.
- **Rarity tiers:** Common → Rare → Epic → Legendary. Legendary familiars drop only from the weekly raid chest.

### Optimal Weekly Progression Order

1. Clear all heroic dungeons daily — set pieces are the biggest power jump.
2. Complete the weekly raid lockout on the highest difficulty you can clear.
3. Run world events for enchantment materials before enhancing gear.
4. Bank raid tokens for familiar cores after your set is complete.
5. Finish with PvP arena matches for trinkets — they fill the last gear slot.

### Common Endgame Mistakes

1. **Farming the wrong dungeon for your set:** Each set drops from two specific heroics — check the loot preview before spending daily clears.
2. **Enhancing before set completion:** Set bonuses scale with set pieces, not enhancement levels. Complete the 4-piece set before pushing enhancement past +10.
3. **Skipping world events:** Event materials are the only source of certain enchantments; skipping a two-day event delays your build by a week.
4. **Spending raid tokens on gear:** Raid tokens buy familiar cores and exclusive sets — gear from heroics covers the rest of your slots.
