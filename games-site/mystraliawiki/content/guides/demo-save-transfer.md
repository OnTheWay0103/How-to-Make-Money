# Echoes of Mystralia Demo Save Transfer — Does Progress Carry to Early Access?

The short answer, per developer announcements: **yes — demo save data transfers to Early Access**, which launched on **August 11, 2026**. Borealys Games also stated that the progression systems were **reworked between the demo and Early Access**, so the two builds differ in some ways. This guide covers what's confirmed, what remains unverified, and what to check in the launch build.

## What's Confirmed

Per developer announcements:

1. **Demo save data transfers to Early Access.** Time spent in the demo is not wasted.
2. **Progression systems changed between demo and EA.** Borealys reworked systems during development, so treat demo-era expectations (currencies, upgrade costs, and the exact transfer list) as things to verify in the launch build.

What else transfers — Memories, spells, region progress — **has not been itemized**. The developer confirmed the save transfer but hasn't published a line-by-line list of what's included.

## What's Unverified (Check in the Launch Build)

- **Memories** — the demo has 50 Memories; Early Access launches with 100+. Whether your demo-collected Memories import into the larger pool has not been specified
- **Crafted spells** — the demo has 4 spells; Early Access launches with 16 starting spells. How (or whether) your demo-built loadouts map onto the new pool is unannounced
- **Region progress** — the demo's Ash Forest is one of three launch regions; progress state on transfer is unannounced
- **Hub progression** — the Lotus and its Altar upgrades exist in the launch build; whether demo-era progression imports is unannounced

The practical stance: **expect your save to transfer as a whole, but plan to re-earn anything that doesn't** — everything is quickly re-obtained in region one (the Ash Forest).

## How to Make Sure Your Save Transfers — Step by Step

Borealys hasn't published a transfer procedure, so these steps cover what any Steam player can do to maximize the odds of a clean transfer:

1. **Play the demo on the same Steam account** you'll use for Early Access. The demo and EA build share your Steam identity; switching accounts is the most common way saves go missing.
2. **Finish your demo run and return to the hub** — quit from a normal state rather than a crash or hard kill, so the save file is written cleanly.
3. **Confirm Steam Cloud sync completed.** The demo uses Steam Cloud saves; check your library's demo entry for a cloud-sync icon before closing Steam.
4. **On first boot of the EA build, accept the save-transfer prompt** if one appears — and verify after loading in: check your hub progression, spell list, and Memory count against what you had in the demo.

## Platform-Specific Notes

- **Steam only (confirmed).** Early Access launches on PC via Steam; other platforms have not been announced. There is no cross-platform save situation to worry about.
- **Steam Cloud saves** are the demo's save mechanism — they're tied to your Steam account, so the transfer stays within the same account ecosystem.
- **Back up manually if you want belt-and-braces safety:** locate the demo's save folder (typically the standard Steam `userdata` structure) and copy it before relying on the transfer. This is optional — Steam Cloud should handle it — but a manual copy costs nothing.
