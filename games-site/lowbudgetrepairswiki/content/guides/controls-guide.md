# Low-Budget Repairs Controls Guide — PC, Controller & Settings

> Controls listed here match the July 2026 demo build and developer announcements. The game was released on August 13, 2026; bindings we could not verify in the release build are marked **[Unconfirmed]**.

## PC Controls (Keyboard & Mouse)

Low-Budget Repairs uses standard first-person controls on PC:

| Action | Key |
|--------|-----|
| Move | **WASD** |
| Look / aim | **Mouse** |
| Interact (open, pick up, talk) | **E** |
| Use current tool / primary action | Left mouse button |
| Alternate tool action (pour, scrape, apply) | Right mouse button |
| Tool wheel | **Q** |
| Job info / contract details | **Tab** |
| Inventory & tool belt | I |
| Drop held item | R |

Hold the tool wheel (Q) to switch between the tools you're carrying — hammer, chisel, roller, brush, wrench, and whatever else you brought from the shop. Tab pulls up the current contract: what surfaces are required, what the client wants, and the flat fee on the table. Checking it before you start working saves you from painting rooms that were never in scope.

## Movement & Interaction Basics

- **Move with WASD, aim with the mouse** — the core of every interaction, from rolling paint to aiming a hammer.
- **E interacts** with everything: doors, objects, supplies, the client's neighbor who just wants to watch.
- **Left mouse uses your current tool** — a roller rolls, a hammer hammers. **Right mouse** handles alternate actions like pouring paint into a tray or scraping old tiles.
- **You can pick up and carry objects** — including furniture. Yes, including throwing it out the window to save time. The game never punishes you directly, though the neighbors may comment on it.
- **R drops** whatever you're holding. Drop things carefully — the game simulates gravity, and your flat fee doesn't cover broken vases.

## Tips for Working Smoothly

- **Keep the tool wheel to three or four tools.** You carry a limited tool belt — swapping is quick, but every swap costs time, and time is money.
- **Re-check Tab before you start.** Required surfaces are in the contract; everything else is optional and optional means *cheaper to skip*.
- **Move furniture instead of around it.** Carrying a wardrobe out of the way takes seconds and unlocks the hidden walls behind it — paint those and you've wasted money; leave them and you've saved some.
- **Learn the drop-in-spot technique.** When a job says "replace the sink," you can often drop the new one and connect the fittings instead of carefully assembling — the client checks function, not installation technique.
