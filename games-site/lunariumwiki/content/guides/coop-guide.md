## Co-op Overview

Lunarium supports **online co-op** for up to 3 players. Teaming up changes the game significantly — bosses have new attack patterns, some areas are only accessible in co-op, and class synergy becomes a major factor.

## How to Set Up Co-op

### Hosting
1. From the main menu, select **"Multiplayer"**
2. Choose **"Create Session"**
3. Set preferences: **Region**, **Password** (optional), **Max Players**
4. Share the **Session ID** with friends
5. Wait for players to join, then start

### Joining
1. Select **"Multiplayer"** → **"Join Session"**
2. Enter the Session ID from the host
3. If password-protected, enter the password
4. Select your character and ready up

## Co-op Exclusive Content

### Co-op Only Bosses
Some bosses have **co-op exclusive phases** — additional attacks and mechanics that only appear with 2+ players. These phases drop unique materials.

### Co-op Puzzles
Certain areas in each region feature **2-3 player puzzles**:
- Pressure plate mechanisms
- Simultaneous lever activation
- Split-path gauntlets

Completing co-op puzzles rewards bonus chests with rare gear.

## Co-op Boss Strategy

1. **Tank initiates** — Ave should always pull first and establish aggro
2. **Spread out during AoE** — Don't cluster; one AoE can wipe the team
3. **Focus adds immediately** — Boss adds are more dangerous in co-op
4. **Chain staggers** — Coordinate heavy attacks to keep the boss staggered
5. **Revive priority** — Support revives first, then Tank, then DPS

## Co-op Tips

- **Share loot** — Communicate who needs which drops before the run
- **Ping system** — Use pings to mark threats, treasures, and puzzle elements
- **Don't split too far** — Stay within one screen of each other
- **Coordinate ultimate abilities** — Stack buffs/debuffs for maximum effect
