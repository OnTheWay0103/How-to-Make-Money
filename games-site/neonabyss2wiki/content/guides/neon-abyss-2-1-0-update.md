Neon Abyss 2 left Early Access on October 8, 2026. The 1.0 build added a new Titan, a new mode, Steam achievements, per-Agent profiles, six reworked sets and a long quality-of-life pass — then three hotfix rounds followed within eight days. Here is all of it, organised.


## 1. The Seven Headline Additions

Veewo listed these explicitly in the 1.0 announcement:

| Addition | What it actually is |
|---|---|
| **Theia — Goddess of Vanity** | A new Titan, Titan Group's Chief Brand Officer, who "turns aesthetics into shackles and blinds Agents with dazzling light" |
| **Steam achievements** | 32 achievements on Steam; "Now available on every platform," and already-satisfied criteria pop automatically |
| **Storm Breach mode** | The beta mode that "offers a faster, more streamlined game mode perfect for our 1-4 player co-op" |
| **Random Agent selection + Agent profiles** | Random pick returns to the bar; each Agent tracks "their abilities as well as boss kill record and highest Fate record" |
| **Artisanism Faith rework** | Uses badges to "provide a new Affix after crafting," opening build options regardless of weapon |
| **Fishing room upgrade** | A day-night cycle plus a hidden boss Veewo deliberately does not explain |
| **In-game music player** | Plays any track from the soundtrack, for Supporter Pack or separate-OST owners |

Two of these matter more than the rest for a returning player. **Storm Breach** changes how long a session takes, and **Artisanism** changes what a crafting-heavy build can do. The music player is gated behind paid content and should be treated as a bonus, not a feature of the base game.


## 2. Six Sets Reworked

1.0 touched exactly six sets, and the notes describe each one:

| Set | 1.0 change |
|---|---|
| **Sky Heist** | Paid manual hacking replaced by a permanent rainbow key with automatic hacking; more keys widen target count, attack speed raises hack rate |
| **Alloy Resolve** | Keeps explosion immunity and free grenades; blast range now 1.5× previous |
| **Lovely Legion** | Visual and effect pass on Hatchmon eggs converting into shields |
| **Carnival Frenzy** | Jump Marks generate continuously; every third mark becomes an auto-targeting turret cloud with homing projectiles |
| **Tao Unfolds** | 10 Purple Wisps per battle, respawn time cut to 10% of previous, charge speed doubled |
| **Arcane Echo** | Active Curio Crystal cost halved (minimum 1); using a Curio stores up to 6 Crystal Daggers that fire periodically |

Our [build tier list](/guides/neon-abyss-2-weapon-tier-list) ranks these by how reliably they convert stats into damage. Short version: the three sets that now act without input — Arcane Echo, Carnival Frenzy, Tao Unfolds — moved up the most.


## 3. Quality of Life That Saves Minutes

The 1.0 notes group these under "Key Experience Improvements." The ones that change moment-to-moment play:

| Change | Before → after |
|---|---|
| **Wonder Blocks in shops** | Some shops and Athena reward rooms can now offer a Great Wonder Block, giving reroll options mid-floor |
| **Smiley Merchants** | Hold interact and spend coins to reroll the payment type across coins, hearts, bombs, keys, or eggs |
| **Weapon XP Hexjar** | Now releases souls in set amounts to pick up, instead of an unclear source |
| **Evolution progression** | Unlock order refined for a smoother early game |
| **Graphics vs frame rate** | Now independent: Medium/High quality with 60, 120, or uncapped frames on PC |
| **Ultrawide** | 21:9 support added, including 2560×1080, 3440×1440, 3840×1600 |
| **Controllers and menus** | Menu button steps back one level at a time; QTEs follow custom movement bindings |
| **Vibration and audio** | Controller vibration and screen shake now separate sliders; pickup and dismantle sounds play in the relevant room |
| **Localization** | Translations reviewed across all 12 supported languages |

The store page also lists DualShock and DualSense controller support as feature categories, so both pad families are covered by the game itself, not by a wrapper.


## 4. The Bug Fixes That Changed Runs

The 1.0 fix list is long enough to be unreadable in full. Grouped by what actually broke runs:

| Area | Representative fixes |
|---|---|
| **Stuck controls** | Movement locked after entering a room, continuing a save, or a failed door transition; stuck midair when flying into the next floor |
| **Lost progress** | Co-op progress leaking into personal saves; solo saves cleared when returning to menu; missing continuation data after switching to solo; skipped XP animation no longer skips progression |
| **Host disconnects** | Clients no longer treat a room as online after the host leaves; quitting on PC notifies teammates |
| **Saves** | Older-save compatibility, paired Steam backup/restore of save plus progression data, corrupted saves preserved before recovery |
| **Bosses** | Unreachable boss entrances, Zeus not acting, phases not advancing, Apollo's lingering final-phase attacks |
| **Weapons** | Weapons failing to recharge, souls lost during upgrade or dismantle, GLITZ baseballs not returning, VOLTEDGE's charged multiplier, melee attack speed counted twice |
| **Duplicated rewards** | Unique Wonder items dropping more than once per run; duplicate rewards from psychedelic butterflies |
| **Collision** | Stuck in terrain after shrinking or teleporting, collision blocking around bosses and Blackdog Chests |
| **Co-op sync** | Missing melee animations, ORIGAMI ammo mismatch, coin ownership, mines detonating across rooms |
| **Dark Zeus timer** | The 30-minute gate now uses active playtime, excluding pauses and loading, and keeps elapsed time on continue |

If you played during Early Access and remember a bug, there is a good chance it is on that list — the 1.0 patch was a cleanup patch as much as a content patch.


## 5. What the October Hotfixes Changed

Three default-branch updates shipped on October 10, 13 and 16, summarised by Veewo on October 19. The headline: no new content, a lot of co-op and save repair.

**Quality of life**

- Dismantle hold time cut from 2 seconds to **1 second**; item pickup banners shortened.
- **Tutorial skip** added: once one save finishes the tutorial, other saves can skip it.
- Confirmation prompt before abandoning a run from the main menu.
- Safehouse now offers an exit when all boss portals are locked, and the run timer pauses inside it.
- `Scream Soda` trigger cooldown reduced from 3 seconds to **1 second**.
- The clear-the-game achievement now needs **3** different Agents instead of **10**, with historical clears backfilled.
- 16:10 resolutions restored; save selection layout fixed on narrow screens.
- Network speed checks removed from bar entry; Dark Zeus countdown hidden while locked.

**Co-op**

- Basketballs no longer get stuck or locked after a disconnect; hosts can pick up balls thrown by others.
- Simultaneous pickups resolved consistently; claw-machine reward ownership fixed.
- Gambling machines and faith machines no longer freeze with several players interacting at once.
- Failed dice-machine attempts no longer consume coins, keys, or free unlocks.
- Door key/crystal consumption and door states now match between host and clients.
- Duplicate shop purchases and restock states fixed.
- Reconnecting in Classic Mode now restores the host's floor number plus items, skills, and stats.
- Minigame rounds use the host's difficulty for all players.

**Saves and progression**

- Corrupted local saves no longer trap players in a retry loop; the affected slot can be deleted.
- Crashes when loading or continuing fixed; stuck save notifications fixed.
- Boss objectives restored in older saves; Dance Party task reward quantity corrected.
- Tutorial dialogue no longer blocks progression.

**Interface and rooms**

- Map close button fits narrow displays; camera no longer drifts after closing the map.
- Dress-up and ban panels, emote wheel hit areas, and character previews fixed.
- Duplicate Hatchmon counts on stats, wrong Pet Temple image, wrong character-boss record images.
- Storm Breach level selection gained a localized confirm button.
- Overhead icon for Maneuver Gear and the F4 survey shortcut were removed.


## 6. The DLC Question

If you bought during Early Access, you keep the **Archenemy Returns** DLC for free. Veewo's August post says it plainly: "anyone who purchases during Early Access will get to keep the Archenemy Returns DLC for absolutely free… this WILL move to a paid DLC following 1.0 launch."

That is the only officially confirmed free-content promotion in the game's history. There are no redeem codes tied to it, which is why our [codes page](/guides/neon-abyss-2-codes) ends where it does.


## 7. Beta Branch: How to Switch, and Why Not To

The Beta branch still exists post-1.0 and is the fastest way to break co-op.

**Steam Library → Neon Abyss 2 → right-click → Properties → Betas → Beta** (no password). The main menu also has a branch switch.

Veewo's warning, repeated in every branch post: "different branches cannot play online together due to version differences." If your group cannot connect, check branches before you check anything else.

The other standing warning applies to every patch: **finish your current run before updating.** Both the 1.0 notes and the October roundup say updating can cause issues with in-progress runs.


## 8. What Is Still Unconfirmed

- **Roadmap.** Veewo says 1.0 "is just another beginning" and that more content is coming, without dates. No post-1.0 roadmap has been published.
- **Console storefronts.** 1.0 launched "on Steam and Consoles," but the official site and announcements do not list which stores.
- **Crossplay.** Not stated anywhere official.
- **Agent roster.** At least ten Agents exist; the full list with abilities is not published in patch notes.


## 9. FAQ

**When did Neon Abyss 2 leave Early Access?**
With the 1.0 build announced for October 8, 2026. Steam's store API lists the release date as Oct 7, 2026 — the one-day difference is recorded, not resolved, on our [FAQ page](/faq).

**Did 1.0 add new bosses?**
Theia, a new Titan, plus a hidden boss in the fishing room. Six other bosses had already been named in earlier updates.

**Do saves from Early Access carry over?**
Yes — 1.0 includes older-save compatibility work, and the October roundup added recovery for corrupted local saves. Back up nothing manually that Steam Cloud already handles, but do finish a run before patching.

**Is the game harder after 1.0?**
The notes describe accessibility additions, not a difficulty raise: adjustable difficulty is a store-listed feature, and Infinite Energy remains in settings with a warning that it reduces difficulty.
