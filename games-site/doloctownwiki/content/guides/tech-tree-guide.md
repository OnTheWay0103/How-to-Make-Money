# Tech Tree Guide — How to Upgrade Tools & Unlock Machines

Doloc Town's progression runs through the **Tech Tree** — the research system that unlocks everything from the Smelter to the 1.0 drone automation. This guide covers the verified mechanics and the community's research priorities.

## How the Tech Tree Works

- The Tech Tree contains **81 technologies** across four branches: **Agricultural, Industrial, Life, and Animal** (per [Neoseeker](https://www.neoseeker.com/doloc-town/walkthrough))
- **Using tools grants research points**: the Scythe, Pickaxe, and Axe grant **Field Study, Tech Research, or Tool Operation** points, which you spend in the Tech Tree (per [Neoseeker](https://www.neoseeker.com/doloc-town/walkthrough))
- The 1.0 update added an **Industrial Tech Tree** specifically for the drone automation system (per the [1.0 patch notes via VGSpoilers](https://www.vgspoilers.com/game/doloc-town/patches/1.0))

## What the Tech Tree Unlocks (Verified)

| Unlock | Branch (per source) | Notes |
|--------|---------------------|-------|
| **Smelter** | Tech Tree | Processes raw ore into metal (per [TechRaptor](https://techraptor.net/gaming/guides/doloc-town-guide-beginner-tips-and-tricks)) |
| **Sprinklers** | Tech Tree | Automates watering (per [TechRaptor](https://techraptor.net/gaming/guides/doloc-town-guide-beginner-tips-and-tricks)) |
| **Cooking** | Tech Tree | Unlocks cooking recipes and value-add processing (per [Grindnstrat](https://grindnstrat.com/doloc-town-1-0-beginner-guide/)) |
| **Automation node** | Tech Tree | Unlocks the 1.0 drone system (per the [1.0 content overview](https://steamcommunity.com/app/2285550/allnews)) |
| **Electric dryer** | Festival reward | From the salmon festival (25 salmon) — not a Tech Tree node (per [Prodigygamers](https://prodigygamers.com/2026/08/10/doloc-town-beginners-guide-4th-month-cash-strategy-farming-meta/)) |

## How to Upgrade Tools

"Upgrade tools" in Doloc Town means two things (per [Neoseeker](https://www.neoseeker.com/doloc-town/walkthrough) and the [1.0 patch notes](https://www.vgspoilers.com/game/doloc-town/patches/1.0)):

1. **Tech Tree research** — spending Tool Operation points unlocks better tool capabilities
2. **New tool tiers** — the 1.0 patch added new tool tiers and accessories (per [VGSpoilers](https://www.vgspoilers.com/game/doloc-town/patches/1.0)); the exact upgrade materials for each tier are [待确认]

## Research Priorities (Community Consensus)

1. **Cooking first** — the highest-ROI early research; turns every harvest into more Goldcoin (per [Grindnstrat](https://grindnstrat.com/doloc-town-1-0-beginner-guide/))
2. **Sprinklers second** — frees your daily Energy budget (per [TechRaptor](https://techraptor.net/gaming/guides/doloc-town-guide-beginner-tips-and-tricks))
3. **Smelter when Rivervalley opens** — lets you process the ore you mine there (per [TechRaptor](https://techraptor.net/gaming/guides/doloc-town-guide-beginner-tips-and-tricks))
4. **Automation node (late game)** — the drone system that ends manual farming chores (per the [1.0 content overview](https://steamcommunity.com/app/2285550/allnews))

## Unconfirmed Research Items
