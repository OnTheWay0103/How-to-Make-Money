# Big Walk Controls Guide — PC Key Bindings & Controller Layout

> Launch Version / Updated: August 5, 2026

Big Walk is a walking game with a tiny action set — move, look, pick up, use, talk. That simplicity is the point: the difficulty is in communication, not input. But a few bindings matter a lot, especially the **voice chat key** and the **tool wheel**, so a quick control tour saves your group real confusion on the first night.

**Note:** Big Walk launched August 4, 2026, and some default bindings may shift in early patches. This page reflects the launch build; we will flag changes as they land.

---

## PC Keyboard & Mouse (Default Bindings)

| Action | Key | Notes |
|--------|-----|-------|
| Move | **W A S D** | Walking game — no sprint confirmed, but keep moving |
| Look / Camera | **Mouse** | Standard |
| Jump | **Space** | Some ledges need it; most of the island is walked, not jumped |
| Interact / Pick up | **E** | Pick up tools, gourds, press buttons, pull levers |
| Use held item / tool | **Left Click** | Action button for whatever you are holding |
| Tool Wheel | **Tab** | Opens the radial wheel — hold to select, release to equip |
| Next / Previous tool | **1 / 2** or **Mouse wheel** | Quick-switch between last two tools |
| Push-to-Talk | **V** (default) | Voice chat key — see the voice chat section below |
| Gesture / Point | **Right Click** (while empty-handed) | Pointing is a real communication tool — use it |
| Throw / Toss held item | **Q** | Yes, you can throw things into the ocean |
| Pause / Menu | **Esc** | Settings, rebinding, session tools |

*Exact defaults can vary by patch; verify in Settings → Controls if anything feels off.*

## How to Change Key Bindings

1. Pause (**Esc** / Options) → **Settings → Controls**.
2. Select any action from the list — it highlights and waits for your input.
3. Press the new key/button to assign it. Conflicts are highlighted red — the game will not let you double-bind.
4. **Controller users:** rebinding works per-button on PS5 and Switch 2 via the same menu; Xbox and Steam users can also rebind at the platform level (Xbox Accessories / Steam Input).

**Recommended binding changes most groups make:**

- **Push-to-Talk off the stick.** Clicking L3 mid-walk is awkward; move PTT to a shoulder button or unused face button. (Or switch to open mic — below.)
- **Tool wheel to something thumb-friendly.** If you swap tools constantly, consider binding quick-switch to a mouse side button on PC.

## Tool Switching

- **Tool Wheel (Tab / Triangle / Y / X):** the radial wheel shows everything you carry. Hold to pause-time select, release to equip. All tools and toys in your hand come from here — see the [Tools Guide](/guides/tools-guide) for what each one does.
- **Quick-switch (1/2 or D-pad):** cycles your last two equipped items — faster than the wheel mid-puzzle.
- **Empty hand:** pressing the tool wheel's center (or swapping to "hands") drops your item back into your inventory without throwing it.

## Voice Chat Controls

Voice chat is the game's core mechanic, and it is **proximity-based**: voices fade with distance, echo in tunnels, and muffle through walls. That is intentional — see the [Multiplayer & Co-op Guide](/guides/multiplayer-coop-guide) for the full strategy.

| Setting | Default | Notes |
|---------|---------|-------|
| **Push-to-Talk (PTT)** | On (V / L3) | Recommended for big groups to cut background noise |
| **Open Mic** | Off | Best for duos — constant voice is the whole vibe |
| **Walkie-Talkie channel** | Automatic when held | Talking into a held walkie-talkie broadcasts long-range |
| **Voice volume (proximity)** | 100% | Turn this down if you hate the tunnel echo |
| **Mic sensitivity** | Medium | Tune in Settings → Audio if friends hear breathing |

**Tips:**

- If your group uses PTT, everyone must bind it **before** the walk starts — nothing kills a session like one friend shouting into silence.
- Walkie-talkies work while **held or equipped** — you do not need to be holding them mid-conversation.
- Open-mic duos: you will hear each other's footsteps through the proximity system. That is a feature, not a bug.

## Recommended Settings

- **Camera sensitivity:** 50% default is fine; most players drop it slightly for smoother spotting with binoculars.
- **Motion blur:** turn off if you get motion sick — Big Walk is all steady panning across terrain.
- **Subtitles:** on. Voices are positional, and subtitles save you in noisy groups.
- **Text size:** large, if you have any distance from your screen.
- **Field of view:** crank to max if you are the designated spotter (binoculars user).
- **Audio:** put voice chat on a separate volume slider above music — the game's soundtrack is lovely, but your group is the priority.

## Accessibility Options

House House's games have a strong accessibility reputation, and Big Walk's launch build includes:

- **Subtitles with speaker labels** — required for hearing-impaired players to follow positional voice.
- **Text size scaling** for UI and whiteboard notes.
- **Toggle vs Hold** options for interact and tool wheel (set to toggle to reduce grip strain).
- **Camera smoothing / shake reduction** toggles.
- **Full controller remapping** and **fully rebindable keyboard** (covered above).
- **Color-friendly UI options** for puzzle symbols and signs.

## Quick Reference: The Five Keys That Matter

1. **E** — interact. Half the game.
2. **Tab** — tool wheel. The other half.
3. **V** — push-to-talk. The *actual* other half.
4. **Q** — throw. Use with great care.
5. **Space** — jump. Sometimes the puzzle is literally that.
