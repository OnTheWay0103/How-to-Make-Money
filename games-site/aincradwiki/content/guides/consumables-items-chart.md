## Consumables Quick-Reference

| Consumable | Effect / Use | Where You Get It |
|------------|--------------|------------------|
| **Healing Potion** | Restores HP; stock up before boss fights | Daily quest rewards (e.g., the Herb Collection quest pays +3 Healing Potion) |
| **Standard Healing Items** | General healing stock — 10x recommended for the Crimson Canyon boss, 12–20 for the Floor 3 entry run | Purchasable / stocked before runs |
| **Full Heal Potion** | Full heal — 3x recommended in speed-run loadouts | Item stock (see Speedrun Tips) |
| **Light Resistance Potion** | 5x recommended for the Corrupted Fae Lord fight — use them to stay mobile through Phase 1 | Crafted from **Glimmerberries + Nectar** (Floor 3) |
| **Attack Elixir** | Temporary attack buff — one per boss from Floor 3 onward | Item stock (see Speedrun Tips) |
| **SP Regenerator** | SP recovery — 1x in speed-run loadouts | Item stock (see Speedrun Tips) |
| **Luck Meal** | Food buff — **+15% drop rate**, stacks with everything | Food buff (see Tips & Tricks) |
| **Elixir** (rare consumable) | **+30% drop rate**, stacks with Food, EX-Mod and Set buffs — save for boss farming | Rare consumable (see Tips & Tricks) |

## Drop-Rate Buff Stacking

Drop-rate buffs stack **multiplicatively across types** — same-type buffs do not stack (the highest value applies).

| Source | Type | Bonus | Stacks With |
|--------|------|-------|-------------|
| Food Buff (Luck Meal) | Food | +15% | Everything |
| EX-Mod (Luck Up) | EX-Mod | +10% | Food, Equipment |
| Equipment Set Bonus | Set | +20% | Food, EX-Mod |
| Elixir (rare consumable) | Elixir | +30% | Food, EX-Mod, Set |

**Maximum achievable drop-rate boost**: 1.15 × 1.10 × 1.20 × 1.30 = **97% increase** (roughly double base drop rate). Best farming setup: Luck Meal + Luck Up EX-Mod + Floor 4 armor set (+20% drop rate) + Elixir saved for boss farming.

## Pre-Boss Shopping List

1. **Healing stock** — Standard Healing Items (10+ for Floor 3) or Full Heal Potions for speed kills
2. **Light Resistance Potion ×5** — mandatory for the Corrupted Fae Lord fight (Phase 1 curse barrages)
3. **Attack Elixir + SP Regenerator** — for boss burn windows from Floor 3 onward
4. **Luck Meal (or Elixir) before farming** — never waste the +15%/+30% drop buff on non-farm runs
