# Waterpark Simulator Controls Guide (PC)

The complete key binding reference for Waterpark Simulator on PC (Steam). Last updated August 8, 2026 — bindings match the 1.0 release and can be remapped in the game settings.

## Movement & Camera

| Action | Key |
|--------|-----|
| Move | **W A S D** |
| Sprint | **Shift** |
| Jump | **Space** |
| Ragdoll | **R** |
| Camera view (cycle) | **V** |

## Interaction

| Action | Key |
|--------|-----|
| Interact / hold for tasks (repairing, serving, cleaning) | **Left Mouse** |
| Push visitors / throw trash bags | **Right Mouse** |
| Drop item | **Q** |
| Open inventory | **I** |
| Use the hammer | Hold **Left Mouse** |
| Use the sledgehammer | Equip, then left-click to swing |

## Building

| Action | Key |
|--------|-----|
| Open Build Menu | **B** |
| Rotate placement | **Mouse Wheel** |
| Place / confirm | Left Mouse |
| Cancel | Right Mouse or Esc |

## Menus & Tablet

| Action | Key |
|--------|-----|
| Open tablet (park stats, hire staff, manage ads, rename park) | **Tab** |
| Pause / game menu | **Esc** |

## The Three Core Tools (Early Game)

| Tool | What It Does | Best Use |
|------|--------------|----------|
| **Sledgehammer** | Destroys trash and demolishes buildings | Clearing trash piles, tearing down failed builds |
| **Hammer** | Builds items and repairs broken objects | Hold left mouse to repair; **upgrade it ASAP** — repair everything at closing (6 PM) |
| **Mop** | Cleans water puddles | Constant use during open hours — puddles cause slips and bad reviews |

## Advanced Tools (Research & 1.0)

| Tool | Unlock | Notes |
|------|--------|-------|
| **Water gun** | Research | Cleans faster than the mop; note: no research points from water-gun cleaning |
| **Water pressure gun** | ~4 stars | Replaces the mop and boxing gloves; pushes people off diving boards |
| **Boxing glove** | Front desk | Fast ejection tool for troublemakers |
| **Plunger gun** | 1.0 | Grappling-style movement |
| **Paintgun** | 1.0 | Paint things (and friends) |
| **Duck gun** | 1.0 | Bought from "the old man at Caymart" — no research needed |
| **Duck water cannon** | 1.0 | Power-wash guests/players; enables duck water battles |
| **Royal hammer** | 1.0 | Decorative |

## Pro Control Tips

1. **Right Mouse is your discipline tool** — push ticket cheaters, drunks, and vandals out of the park for ~$30 each.
2. **Hold the hammer** — tap-clicking repair does not work; it's a hold action.
3. **Use umbrellas to bounce high** and spot troublemakers from above.
4. In **co-op (1.0)**, the trumpet, megaphone, and walkie-talkie are extra communication tools — the walkie-talkie lets you chat from anywhere on the map.

## Console Controls (PS5 / Xbox Series X|S)

The console release (July 31, 2026) uses a native gamepad scheme: left stick to move, right stick camera, face buttons for interact/jump/ragdoll, triggers for build and tablet, and the same right-stick-push for troublemakers. Exact bindings are shown in the in-game control menu on each console.
