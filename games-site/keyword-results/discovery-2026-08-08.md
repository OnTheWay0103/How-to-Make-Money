## Top 候选详细分析

### 1. ReStory: Chill Electronics Repairs — 22/25 ⭐

- **类型**：怀旧电器维修模拟（2000s 秋叶原维修铺，第一人称鼠标操作）
- **开发/发行**：Mandragora Games / tinyBuild
- **上线**：2026-08-06 **已发售**（Steam，Win+macOS，€19.99 首周 -10%）
- **Wishlist**：~700-771K（Steam 全站 wishlist 历史榜第 56）
- **评分明细**：wishlist 5 / 内容 5 / 竞争 5 / SEO 4 / 时机 5 = 22
- **首发数据**：98% Overwhelmingly Positive（570+ 评测，tinyBuild 史上最高分游戏）；12K+ 峰值 CCU；12 小时回本、$1M+ 营收；Metacritic 84-85 / OpenCritic 89
- **竞争核查**：**零 wiki**（无 Fandom/社区 wiki）；已有文章攻略（2UpSkill/gamerblurb/allthings.how/destructoid/TechRaptor/intoindiegames）— 与 IRON NEST 建站时局面一致，文章攻略不构成 wiki 级竞争
- **内容潜力**：50 成就、2000+ 可修设备（授权 Atari + 恶搞"任天堂/索尼"仿品）、执照解锁系统、清洁/焊接/换件流程、分支剧情 15h+、市场倒卖 — 指南面广（设备清单、成就攻略、执照路线、商店经营技巧）
- **风险**：① 与 lowbudgetrepairswiki 品类邻近 — 但关键词零重叠（electronics repair vs renovation），且该站已证明模拟类可行；② 已上线 2 天，建站需本周内完成抢峰值
- **建议**：**优先候选**。修复模拟 = Low-Budget Repairs（21 分已建站）同赛道验证过的品类；参考 lowbudgetrepairswiki 内容结构（beginner/money-making/工具/设备参考/FAQ）

### 2. Beast of Reincarnation — 21/25 ⭐

- **类型**：动作 RPG（"一人一狗"，后末日日本 4026；格挡核心 + 狗伙伴指令）
- **开发/发行**：**Game Freak**（Pokémon 开发商的**首款原创 IP**，原 Project Bloom）/ Fictions
- **上线**：2026-08-04 **已发售**（Steam/PS5/Xbox，$59.99，Xbox Game Pass 首日，港区限定不可激活中国区）
- **Wishlist**：~718K（2026 全站前 20）；首发峰值 14.3K CCU
- **评分明细**：wishlist 5 / 内容 5 / 竞争 4 / SEO 5 / 时机 5 = 21
- **竞争核查**：**零 wiki**（无 Fandom/Fextralife）；Eurogamer/RPS/allthings.how/deltiasgaming 等文章攻略密集（章节向 + Boss 向）
- **内容潜力**：13 章（每章 Nushi 大 Boss 重复挑战升级）、40+ Boss（Rangifer/Lacerta/Corvus/Kunai/Kirin/最终 Boss 三阶段）、技能树、Spirit Stones、装备、Bloom Arts/FP 资源系统 — Soulslike 类 Boss 攻略长尾 + Game Freak 首 IP 全球热度
- **风险**：① Game Freak 大作 — Fandom/Fextralife 可能快速建 wiki（目前 4 天无动作，可赌 1-2 周窗口）；② $59.99 定价非独立，文章攻略覆盖密集（Eurogamer 章节攻略已在排）— 差异化靠系统深度（boss 列表、build、技能树）
- **建议**：**推荐**（附条件）。零 wiki 局面与 Big Walk 建站时相同；若主管接受大厂风险则立即建站，否则列入观察

### 3. Fallen Tear: The Ascension — 18/25

- **类型**：手绘动画 2D Metroidvania（JRPG 式叙事，全语音）
- **开发/发行**：Winter Crew Studios / CMD Studios（菲律宾）
- **上线**：2026-09-16 1.0（EA 自 2026-03，$24.99 首周 -10%）
- **Wishlist**：EA 期间 200+ 评测 "Very Positive"（无公开 wishlist 数）
- **评分明细**：wishlist 3 / 内容 5 / 竞争 5 / SEO 4 / 时机 4 = 18
- **竞争核查**：**零 wiki 零攻略**（搜索仅返回新闻稿，无任何 wiki/指南）
- **内容潜力**：1.0 内容近乎翻倍 — 20 区域、11 主线 Boss + 22 支线 Boss、21 Fated Bonds（盟友能力）、3 新 Ascension + 16 新技能、多结局、Temple of Oras 家园枢纽；主线 35-40h、全收集 80h
- **风险**：① EA 玩家基数中等（200+ 评测）；② 1.0 在 5.5 周后 — 需提前建站（参考 Delverium/Nivalis Nights 模式：先发信息类攻略）
- **建议**：**推荐**。Metroidvania = Boss 攻略长尾最佳品类之一；建议 9 月上旬建站

### 4. Waterpark Simulator — 17/25

- **类型**：水上乐园管理模拟（建造/清洁/票务/游客管理，第一人称）

- **数据**：1M+ 下载、96% Overwhelmingly Positive（7400+ 评测）、10.5K 峰值 CCU

- **内容潜力**：1.0 大更（海洋/阿兹特克/海盗主题泳池、博物馆任务线三 NPC、员工管理、研究系统、水枪/推人机制）— 模拟类参考 Low-Budget Repairs/Go-Go Town 已验证结构

- **建议**：**推荐**。低风险确定性收入型候选（已验证 96% 好评 + 零 wiki）
