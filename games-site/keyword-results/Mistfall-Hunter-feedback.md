## 1. 玩家痛点 Top 5

### 痛点 1：服务器地域缺失 + 高延迟橡皮筋（负面评价最大单一来源）
- **无 OCE 服务器、无专属 EU 服务器**：EU 玩家普遍报告 120–180ms 延迟，澳洲玩家直接差评 "Mixed Reviews because of no OCE server"；官方节点（US/DE/BR/SG/CN）与实际体验错位
- 橡皮筋 (rubber-banding)、敌人瞬移、攻击延迟判定、服务器 desync——"我打不到人，敌人也打不到我，我俩都在闪"
- 发售日排队/服务器拥塞：玩家名句"**最难的 Boss 是服务器排队**"（"the worst boss is the server queue"）
- 玩家威胁性差评："We need EU servers. Until then I uninstall"；该问题被官方承认并列入修复清单（回应"more than ten notable bugs"）

### 痛点 2：单排玩家被锁第二张地图（"单排歧视"）
- 游戏有**两张地图，第二张仅限 3 人小队进入**，单排/双排只能玩第一张
- 玩家评价为"discrimination against solo players"；mmo13/DTF 均将"第二图单排不可用"列为差评主因之一
- **Beta 期官方曾承诺"单排与三人共用地图（只是怪物配置调整）"**——发售后反而收窄，玩家感觉被欺骗
- 只有 Solo 和 Trio 两个队列，**无 Duo 队列**——双排玩家被迫补野人或分开单排

### 痛点 3：PC 性能与卡顿（部分服务端、部分客户端）
- 发售后大量报告掉帧至 20–30 FPS、microstutter、输入延迟
- 关键认知差：**橡皮筋/瞬移是服务端问题，画质设置救不了**——玩家调低画质无效后更愤怒
- 登录排队卡死 (stuck at queue) 是发售日高频求助场景（需取消排队→接受 ToS→重启→错峰等土办法）

### 痛点 4：首日平衡争议——最强职业又加强
- 发售日第二天（7/30 首日补丁）**再次强化本就强势的 Withered Knight**（蓄力冲刺/戳击/长枪连击/格挡消耗全面上调），社区批评"上线 48 小时就钉死强度榜"（GameSpot 标题："Mistfall Hunter's Best Class Just Got Even Better"）
- **1.0 发售构建重平衡了全部职业**，Beta 经验/榜单全部作废，玩家落差大
- 各媒体/社区榜单互相矛盾（Destructoid: Mercenary/Sorcerer S 级；Power Up Gaming: Sorcerer 第一；GameRant: Withered Knight 双 S）——meta 认知混乱期

### 痛点 5：商店与退款争议 + 发售期小毛病
- 商城被评"激进"（Eurogamer 原话 "cheeky shop"）：部分玩家称存在影响强度的商品，官方/其他玩家坚持纯外观——pay-to-win 争议未决
- 豪华版退款受阻（"Inability to get a full refund for the Deluxe edition"）
- 其他：主机掉线后无法重连（7/30 补丁已修）、战利品品类重复度、匹配透明度

**次生痛点（频率低于 Top5 但反复出现）**：Soul of Return 在灵魂树进出时被双扣（7/30 已修）、Solo 玩家只有一张图导致内容消耗快、PvE 模式诉求（Steam 论坛热帖"PvE mode?"）、黑箭 Javelin 新武器延期到后续赛季、Sorcerer 教程键位提示错误（特定语言，已修）。

## 2. 玩家情绪

### 他们爱什么（好评与媒体共识亮点）
| 亮点 | 细节 |
|------|------|
| 战斗手感 | "Elden Ring × Arc Raiders"式的完美结合；无锁定、站位制、挥砍沉重有质感；Eurogamer："Soulslike 与 Extraction 惊人地契合" |
| 职业/Build 深度 | 6 职业各锁武器姿态+天赋+宝石插槽，Buildcrafting 空间大；全球聊天与社交功能获好评 |
| 美术氛围 | 迷雾笼罩的 Weavereach 世界、独特美术风格；"完美的 Elden Ring 与 Arc Raiders 结合体"（俄语评测原话） |
| 发售热度 | 8 小时 10 万+ 玩家、峰值 2–3 万在线；GFinity："它让我想续订 Game Pass" |
| 产品形态 | 买断制 + Game Pass 首发（$24.99 而非 F2P），多数玩家认为定价合理 |

### 他们恨什么 / 为什么退坑
1. **服务器延迟/排队** → "等 EU 服务器，否则卸载"——退坑第一原因，也是 Mixed 评价主因
2. **单排图锁** → 独狼玩家感觉被设计歧视，"我这种喜欢单排的迟早要组队，希望加单排模式，长期会流失玩家"
3. **性能卡顿** → 帧数 20s、输入延迟，调设置无效（服务端问题）→ 退款
4. **首日平衡乱象** → 最强职业再加强、全职业重平衡推翻 Beta 认知
5. **商店争议 + 退款难** → 信任问题

### 总体情绪
- Steam **Mixed**（57%–71% 波动）；媒体共识："**底子一流，首发 teething issues 明显**"（Eurogamer："抛开磨合期问题和厚脸皮的商店，剩下的是一个出人意料成功的奇幻撤离 Soulslike"）
- 差评集中在**技术问题而非玩法**——gameplay 本身口碑正面，玩家在"等它修好"
- 服务器稳定性被部分玩家反馈"正在快速恢复"；官方已承诺继续修网络问题——情绪处于"观望期"而非"弃游期"
- 免费玩 Game Pass 的玩家宽容度明显高于 Steam 付费玩家；游戏被广泛推荐"先 Game Pass 试，别急着买"

1. **《服务器区域与排队/卡顿修复指南》** `server-regions-ping-guide`

### P1 — 新增或大更新
