# The Mound: Omen of Cthulhu — 玩家反馈分析

> 模式: deep | 日期: 2026-08-01 | 数据源: Reddit + Steam 评测 + 主流媒体评测

**游戏背景**：4 人合作 Lovecraft 恐怖撤离 (extraction) 游戏，ACE Team 开发、Nacon 发行。2026-07-15 上线 Steam / PS5 / Xbox Series X|S（Steam App ID 2569760），Unreal Engine 5。设定在 16 世纪南美诅咒丛林，核心机制是理智 (Sanity) 系统 —— 幻觉会让队友看起来像怪物、回放你之前的语音聊天、制造假枪声。Steam 当前评价为 **Mixed（褒贬不一）**。

**数据源说明**：Reddit 定向搜索 0 结果（游戏上线仅 2 周，玩家社区集中在 Steam 论坛与 Discord，开发者明确说规则留给社区在 Reddit/Discord 摸索 —— "puzzlebox" 设计）。实际反馈来自 Steam 评测（含 207 helpful 的顶踩长评）、VaporLens 评测聚合、IGN/GameSpot/DualShockers/GameReactor/GamingBolt/COGconnected 等专业评测及评论区。

## 1. 玩家痛点 Top 5

### 痛点 1：战斗系统"被剥夺操作权"（频率最高、情绪最强烈）
- 发售时**无格挡、无闪避、无弹反、不能跳/爬/翻**——中文评测原话"不能闪避，不能格挡，不能弹反，不能跳不能爬不能翻"，吐槽"原始人都会跳和闪"
- 近战手感"迟缓"，挥击"看似命中实际挥空"，敌人攻击优先级高于玩家
- 敌人比玩家跑得快，冲刺逃不掉、无法风筝——一条 207 helpful 差评总结："这不是难度，是披着难度外衣的运气"
- **格挡 (Block) 直到 Patch 1.02（7 月下旬）才以"发售后追加"形式加入**，评测讽刺"这不是售后内容，这是战斗系统第一天就该有的地基"
- 武器耐久：砍几刀就坏，也是常见抱怨

### 痛点 2：性能优化差（近乎全民抱怨）
- UE5 优化不足：**RTX 4080 Super @1440p 全高原生只有 45–58 FPS**，必须开 DLSS 才能到 60
- 森林区域微卡顿 (microstutter)、音频断流；Steam Deck 稳定性严重不佳
- 低配（<8GB 显存）连低画质都跑不动，"要高端 PC 才能勉强在 Medium 挣扎 60 FPS"

### 痛点 3：进度丢失 / 存档 Bug（最劝退、被称"不可原谅"）
- **有玩家反映完整进度与等级被重置**；硬崩溃一次蒸发 30–60 分钟远征进度
- 差评原话："合作游戏里你的时间会凭空蒸发，那投入时间就是个坏赌注"
- Patch 1.02 被迫加入**基于成就/奖杯的进度恢复工具**（全平台）+ PS5 专属进度丢失修复——说明该问题规模不小

### 痛点 4：撤离式 meta 进度"贫血"——战利品带不出来
- **武器/护甲带不出本局**，战利品"溶解成代币和永久商店解锁"，玩家觉得没有成长感
- "每次合同都像孤立任务，而不是旅程的一部分"；COGconnected 称"深入丛林捞好装备毫无动力，因为什么都不继承"，游戏"像未完成的原型"
- 等级系统"贫乏"（anemic），核心循环几局后疲倦（GameReactor："极其迟缓"）

### 痛点 5：难度失衡 + 新手上手引导差
- IGN 实测：有 Phasmophobia/Lethal Company 数百小时经验的老队，**最低难度也"真的很难"**，敌人数量膨胀太激进
- **合同难度跟随房主等级**——高等级玩家无法给新手朋友开低难图，带新人几乎不可能
- 序章"什么都没教你"；理智条显示不清晰；缺乏键位重映射等 QoL
- 传送门任务（紫色粘液 3 秒致死、无法复活、没有牛车）被评为最恶心内容

**次生痛点（频率低于 Top5 但反复出现）**：枪械被惩罚（枪声震耳引怪、**买不到弹药**、**雨天完全失效**、无准星、装填极慢、伤害与弩相同）、背包只有 6 格无排序无整理、跨平台联机（主机玩家找不到 PC 房间、无比赛 ID、大厅语言混杂、跨平台语音失效）、单人体验差（AI 队友不可靠、闷）、定价过高（"该是 Early Access 的成品卖全价"）。

## 2. 玩家情绪

### 他们爱什么（几乎零差评的亮点）
| 亮点 | 细节 |
|------|------|
| 氛围感 | 丛林"像活着的角色"，浓雾、剪影、油画质感，视觉"为暧昧而设计"——"氛围顶级，那片丛林太吓人了" |
| 音效 | 被称为 impeccable；理智系统武器化音频：回放玩家几分钟前的语音、假枪声、扭曲环境音 |
| 理智/幻觉机制 | 最受好评的核心创新：Faceless One 复制队友外形+回放其笑声、把队友看成怪物误杀、"我丢了我的队伍，分不清什么是真的了" |
| 合作时刻 | 近距离语音的节目效果——被追时互相尖叫、尸体被"驾驶"；媒体称"这些年最有趣的合作恐怖钩子" |
| 新颖感 | "前所未有的合作恐怖"、"没有两局是相同的"；GameSpot 认为核心概念"没有地基性失误"，jank 是可修复的 |

### 他们恨什么 / 为什么退坑
1. **进度蒸发** → 直接弃游："时间是坏赌注"
2. **战斗中失去控制权**（不能闪不能挡、跑不过敌人）→ 觉得靠运气而非技术 → 差评核心情绪是"被游戏玩"
3. **单人无聊**：AI 队友不可靠 + 空旷走廊"慢腾腾的苦差事" → 独狼玩家流失最快
4. **性能劝退**：硬件不达标直接退款
5. **meta 无成长感** → "每局都像第一次"
6. 社区环境：开发者鼓励 Discord 反馈，但粉丝团会围攻负面意见（差评被"群殴"）——导致部分真实批评被淹没

### 总体情绪
- Steam **Mixed**；媒体共识："伟大的底子，粗糙的壳"——氛围、音效、合作概念一流；战斗手感、优化、进度系统拖后腿
- 多条高赞差评的结论是："**先愿望单，六个月后再回来看看**"——玩家在等补丁成熟
- 补丁节奏正面信号：1.01（7/20，平衡+修复）、1.02（7 月下旬，格挡+进度恢复工具）——玩家在"等它变好"

## 5. 建议新增/更新攻略 (P0/P1/P2)

### P0 — 新增（搜索量大、痛点直击、现有缺失）

1. **《性能优化与 FPS 修复指南》** `performance-fps-fix-guide`
   - 关键词：The Mound low fps fix / best settings for max fps / stutter fix / Steam Deck
   - 内容：推荐画质配置表（Foliage/Volumetric Fog 降 Low 可省 15% FPS）、DLSS/FSR/TSR 选择矩阵、着色器编译 100% 后重启、SSD 迁移、驱动更新、`%LOCALAPPDATA%\TheMound\Saved\Config\WindowsNoEditor\` 配置重置、帧率上限策略、Steam Deck 建议
2. **《进度丢失修复与防丢档指南》** `progress-save-recovery-guide`
   - 关键词：The Mound progress reset / lost progress / progress recovery tool
   - 内容：1.02 进度恢复工具用法（基于成就/奖杯）、PS5 进度丢失修复、崩溃后恢复步骤、verify files、防丢档习惯、常见崩溃已知问题（Logbook Camp 蜈蚣攻击崩溃等）

### P1 — 新增或大更新

3. **《进度与成长系统解析》** `progression-system-guide`（新增）
   - 关键词：what carries over / tokens explained / why can't I keep my weapons
   - 内容：每局结束什么保留（代币、永久商店解锁、个人等级）什么不保留（武器/护甲），商店解锁优先级，解决"白打了"认知落差
4. **更新 `updates-patch-notes.md` → 1.02**（新增 Block Ability、全平台进度恢复工具、PS5 进度修复、Ultra 重开性能修复、同职敌人重复生成修复、Saints 不加载、单人无刀修复）
5. **更新 `crossplay-multiplayer.md`**：1.02 后联机现状、PC↔Xbox 可跨（评测证实）、PS5 情况、邀请与大厅问题、无比赛 ID 的替代方案（好友码/建房方式）
6. **更新 `contracts-guide.md` + `combat-survival-guide.md`**：合同难度随房主等级缩放机制、带新人降难度方法、"战斗为什么难"的解构（定位/体力纪律/格挡 1.02 实装校准）——做"差评救援"型内容

### P2 — 优化

7. **《背包管理指南》**（新增，小篇）：6 格优先携带表、拾取动画与应急换枪、背包整理技巧
8. **weapons-guide 强化**：弹药经济（买不到弹药→弩优先）、枪声引怪与噪音纪律
9. **price-platforms / 新篇《值不值得买》**：结合 Mixed 评价、补丁轨迹（"等六个月"叙事反转成"1.02 已修 X 个问题"）
10. **solo-guide 加诚实预期**：AI 队友能力、单人体感、匹配"the mound solo worth it"意图
11. **weapons-guide 补耐久信息**（现散在 loadout/nightmare-mode 中），回答"武器为什么几刀就坏"

### 优先级理由
P0 命中两个**当前最大真实搜索需求**（性能、丢档）且完全空白——玩家正在被这两件事逼退，搜索"how to fix"的意图最强。P1 的补丁更新与跨平台是时效性强、顺带建立站点权威（补丁后 48h 内更新是现有承诺）。P2 属长尾深耕。
