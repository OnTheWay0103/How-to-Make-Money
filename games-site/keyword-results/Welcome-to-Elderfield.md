## 四、风险与诚实标注规则

1. **恋爱/结婚未实装**：所有 romance 内容标注「开发者规划中、demo 未实装」→ 标题/正文用 "planned"/[Unconfirmed]，不得写成 confirmed 玩法
2. **价格未公布**：所有价格 [Unconfirmed]；第三方（Instant Gaming €18/$21 区间）仅作参考并标注非官方
3. **游戏未发售**：所有 demo 外机制（Old God alignment、日历事件、3x 城镇、第二/三地牢）标 [Unconfirmed] 或 pre-release overview
4. **命名**：官方难度名 Cozy Mode / Challenge Mode 已确认；「teeth corn / eyeball」作物为媒体/社区描述，正文用「crops like teeth and eyeballs」并标来源
5. **wiki.gg 竞争**：不写「零 wiki」；正文提官方 wiki 存在但早期、鼓励社区贡献（避免假竞争声明）
6. **英文标记**：所有未确认一律 [Unconfirmed]（英文），无中文泄漏
