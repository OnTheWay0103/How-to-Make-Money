# 词库归档

同一游戏出现两种命名时，保留内容更全的一份在 `keyword-results/`，把另一份移到这里。
保留原因：`keyword-index.mjs --check` 会把「同游戏多份主报告」判为硬问题；
历史数据不删，只是不再参与索引统计。

| 文件 | 对应主报告 | 移入原因 |
|---|---|---|
| Echoes-of-Aincrad.md | Echoes of Aincrad.md | 同一游戏连字符/空格两种命名 |
| Mistfall-Hunter.md | Mistfall Hunter.md | 同上 |
| Tears-of-Metal.md | tearsofmetal.md | 旧命名，已被新格式 `tearsofmetal.md` 取代 |
