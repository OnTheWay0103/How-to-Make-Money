## Price & Editions

The Mound: Omen of Cthulhu launched on **July 15, 2026** with two editions:

| Edition | Price | Includes |
|---------|-------|----------|
| **Standard Edition** | $29.99 | Base game, all 4 characters |
| **Deluxe Edition** | $39.99 | Base game + Fortune Hunters Character Pack (2 bonus characters) + Digital Artbook + Soundtrack |

### Xbox Game Pass

As of August 2026, The Mound: Omen of Cthulhu is **not on Game Pass**. The developers have not announced any Game Pass plans.

## The Free Demo

A **free demo** is available on Steam. It is a standalone experience designed to let you try the core expedition loop before purchasing — a great way to test whether the game (and your group, if you plan to play co-op) is for you.

### How to Download

1. Open **Steam** and search for "The Mound: Omen of Cthulhu"
2. Click on the game page
3. Look for **"Download Demo"** on the right sidebar
4. The demo is approximately 8 GB

### What's Included

| Included | Not Included |
|----------|--------------|
| All 4 base characters: Alonso, Father Miguel, Catalina, Rodrigo | Only the introductory jungle zone (full game has multiple zones) |
| 1 expedition zone (the introductory jungle area) | No character progression or rank system |
| Full online co-op with up to 4 players | Limited enemy variety |
| Basic weapons and equipment (the base weapon set — Crossbow, Matchlock Arquebus, Flintlock Pistol, Francesca Axe, Machete, Oil Lamp) | No crafting or base upgrades |
| Core mechanics: Sanity system, extraction, combat, exploration | No Deluxe Edition characters |

### How Long Is the Demo?

A single demo expedition takes **20-30 minutes**. You can replay the demo multiple times. There's no time limit — but content is limited to the single starting zone.

### Is the Demo Co-op?

**Yes!** The Steam demo supports full online co-op with up to 4 players. This is a great way to test if your group enjoys the game before everyone buys it.

To play demo co-op:
1. All players download the demo
2. One player hosts via the in-game menu
3. Share the lobby code with friends
4. All join and start the expedition

### Demo Progress to Full Game

**Progress does NOT carry over** from the demo to the full game. The demo is a standalone experience for trying the game. Don't grind resources expecting to transfer them.

### Demo Tips

1. **Try all 4 characters** — Find which playstyle suits you
2. **Test co-op** — Play with friends to see if your group enjoys it
3. **Learn the sanity mechanic** — It's unique to this game and takes practice
4. **Experiment with weapons** — Melee vs ranged feels very different
5. **Don't worry about dying** — The demo is low-stakes; use it to learn

### Should You Buy After the Demo?

If you enjoy the demo, the full game offers significantly more:

- Multiple larger expedition zones
- Deeper enemy variety and bosses
- Character progression and unlocks
- Crafting and loadout customization
- Regular content updates

The demo represents a small fraction of the full game's content.
