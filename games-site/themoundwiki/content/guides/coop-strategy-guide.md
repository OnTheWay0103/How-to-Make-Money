# The Mound Co-op Strategy Guide — Team Play and Communication

> Launch Version / Updated: August 10, 2026

**The Mound: Omen of Cthulhu** is designed for 1-4 players, but the full experience truly shines with a coordinated squad. The forest rewards teamwork and punishes solo heroics. Whether you are playing with friends or matchmade strangers, this guide will help your squad survive the worst the New World can throw at you.

---

## Co-op Overview

The Mound is a **1–4 player online co-op** extraction game, and co-op is the intended way to play — the sanity system is built to break trust between teammates. There is **no couch or local co-op**; every player needs their own copy and device.

| Mode | Players | Verdict |
|------|:--:|--------|
| True Solo | 1 | Hard — enemy swarms and no one to verify hallucinations |
| Solo + AI companion | 1 + AI | Viable but weaker than human teammates |
| Duo | 2 | The **sweet spot** — tense, manageable, and communication stays clear |
| Trio / Full Squad | 3–4 | Maximum chaos and treasure capacity |

PC (Steam), PS5, and Xbox Series X/S play together. Online services (PlayStation Plus / Xbox Game Pass Core) are required on console.

## How to Play With Friends

There are two layers of friendship: your **platform friend list** and the **in-game lobby system**.

1. **Platform friends:** add each other through your normal Steam friends, PlayStation Network, or Xbox network friends list — The Mound reads these lists for invites.
2. **In-game:** the host creates a lobby and shares its **6-character lobby code**. Anyone on any platform can join with the code — no cross-platform account linking required.

### Hosting a Game

1. From the main menu select **Expedition**
2. Choose **Host Game**
3. Set privacy to **Friends Only** (or Public for code-based joins)
4. Share the 6-character lobby code with your friends
5. Wait for everyone to ready up, then launch the expedition

### Joining a Friend

1. Select **Expedition** → **Join Game**
2. Enter the host's lobby code
3. Pick your character and loadout, then ready up

You can also join directly from your platform friend list if the host's privacy is set to Friends Only.

## Crossplay Status

Crossplay in The Mound is real, but it is not the seamless "everyone plays together" system the launch marketing implied. Here is the honest picture based on player reports and reviews:

| Platform Combination | Status | Notes |
|------|:--:|------|
| PC (Steam) ↔ Xbox Series X/S | ✅ **Working** | Confirmed working by multiple player reports and reviews — invite via lobby code or Steam/Xbox friend systems |
| PC (Steam) ↔ PS5 | ⚠️ **Inconsistent** | Crossplay exists, but PS5 lobbies are unreliable — console players frequently cannot find PC-hosted rooms |
| PS5 ↔ Xbox Series X/S | ⚠️ **Inconsistent** | Same lobby-finding issues as above; mixed results |
| All three together | ⚠️ **Works when it connects** | Possible, but expect lobby-finding failures and voice chat problems |

**The short version:** PC and Xbox players can reliably play together. PS5 crossplay is technically supported but buggy in practice — players on PS5 report long waits or failure to find rooms hosted on other platforms. If you are planning a mixed squad, assume the PC ↔ Xbox pairing is the dependable one and the PS5 pairing may need retries or third-party voice.

Voice chat and lobby codes work across platforms. The only platform split is progression accounts — your Rank and tokens live on the platform you play on.

### Why the Lobby Code Is Your Best Tool

Because matchmaking is unreliable and there is no match ID, the **6-character lobby code** is the reliable path to crossplay:

1. Host starts a game from the **Expedition** menu.
2. Set privacy to **Friends Only** (or Public for code-based joins).
3. Share the **6-character code** with friends on any platform — via Discord, phone, whatever.
4. Friends select **Join Game** and enter the code.

If the code join fails, the fallback is a **platform invite**: on Xbox use the Xbox party invite flow; on PC invite through Steam if your friend is on Steam. Mixed platform pairs (PC host → PS5 friend) are the most likely to need several attempts.

### Crossplay Session Tips
- **PC ↔ Xbox is the dependable pairing** — plan around it for serious progression runs
- **PS5 in the squad?** Budget extra setup time and have a third-party voice chat ready
- **Difficulty scales with the host** — if you are bringing a new player, let them host so the contract difficulty matches their level (see the [Contracts Guide](/guides/contracts-guide))

## Squad Roles (4-Player Team)

Assign these roles before every expedition. Players can flex between roles, but clear assignments prevent confusion during combat.

| Role | Primary Responsibility | Best Weapons | Key Items |
|------|----------------------|--------------|-----------|
| **Point Man** | Leads the advance, scouts ahead, identifies threats | Crossbow, Machete | Oil Lamp, Medallion |
| **Support** | Covers rear, provides fire support, watches flanks | Matchlock Arquebus, Pistol | Medallion, Healing Salves |
| **Rearguard** | Protects the squad from pursuit, watches for patrols | Flintlock Pistol, Crossbow | Mask of Nyarlathotep, Oil Lamp |
| **Pack Mule** | Manages Ox Cart, carries extra supplies, loot specialist | Crossbow, Machete | Medallion, Healing Salves |

### Role Responsibilities in Detail

**Point Man**
- Moves 10-15 meters ahead of the group
- Uses Medallion to detect chests and danger
- Marks patrol routes for the squad
- First to engage — opens with Crossbow or backstab
- Carries the primary light source

**Support**
- Stays in the middle of the formation
- Watches the Point Man's blind spots
- Provides suppressing fire when the squad is ambushed
- Calls out Sanity hallucinations for confirmation
- Carries backup healing items for the squad

**Rearguard**
- Watches behind the squad at all times
- Uses Mask of Nyarlathotep to delay pursuing enemies
- Closes doors or creates obstacles to block patrol paths
- Warns the squad if enemies are approaching from behind

**Pack Mule**
- Manages the Ox Cart route and timing
- Tracks total loot value per player
- Decides what to keep and what to discard
- Carries extra ammo and healing supplies

### Squads by Size

| Squad Size | How Roles Fold | Notes |
|------------|----------------|-------|
| **Solo (1)** | All duties in one loadout | Crossbow + Machete; stay silent, extract early — solo is not recommended by reviewers |
| **Duo (2)** | Point Man + Support | The Support carries the healing; the Point Man carries the light |
| **Trio (3)** | Point Man, Support, Rearguard | The lamp rotates to whoever is in front |
| **Full (4)** | All four roles | The intended experience — scales difficulty and rewards |

## Loadout Allocation

### The "No Gaps" Principle
Every expedition needs:
1. **Silent kill capability** — At least 2 Crossbows or Machetes
2. **Area denial** — At least 1 Oil Lamp or fire source
3. **Healing coverage** — Every player carries 1+ healing item
4. **Loot detection** — At least 1 Medallion in the squad
5. **Emergency stealth** — At least 1 Mask of Nyarlathotep

### Example Balanced Loadout
| Player | Primary | Secondary | Tool 1 | Tool 2 |
|--------|---------|-----------|--------|--------|
| Point Man | Crossbow | Machete | Oil Lamp | Medallion |
| Support | Matchlock Arquebus | Flintlock Pistol | Healing Salves | Oil Lamp |
| Rearguard | Flintlock Pistol | Crossbow | Mask of Nyarlathotep | Medallion |
| Pack Mule | Crossbow | Machete | Medallion | Healing Salves |

### Supplies Quick Reference

| Supply | What It Does | Who Carries It |
|--------|--------------|----------------|
| **Matchlock Arquebus** | Highest single-shot damage; unusable in rain | Support |
| **Machete** | Silent, weatherproof, backstab kills | Everyone (fallback) |
| **Oil Lamp** | Light, stuns light-sensitive foes, throwable fire | Point Man / designated light-bearer |
| **Bandages** | Heal wounds | Support / whoever's closest |
| **Ammo** | Shared pool — always limited, always track it | Announced, not hoarded |
| **Medallion (Tulu-metal)** | Versatile tool — **ringing it wakes the jungle**, use sparingly | Point Man / squad leader |
| **Black Ichor lure** | Lures creatures to a single spot (one jar can draw ~5) | Pack Mule |

### Plan the Shared Weapon Pool

The most overlooked co-op mechanic: **gear on the Galleon is shared across the whole party.** If the contract offers a single Flintlock Pistol, only one player can carry it. Before departure:

- Decide who takes the one Crossbow (usually your quietest player)
- Assign the Medallion and Oil Lamp roles — these are party tools, not personal loot
- Make sure everyone carries a Machete as their fallback

A squad that argues over the weapons rack at the Galleon is a squad that dies to the first ambush.

## Communication

The Mound uses **Spatial Voice Chat**: the distance and direction between players affects how clearly you hear each other. This is not a bug — it is a core gameplay mechanic. A microphone is effectively **required**.

### How Spatial Voice Works

| Distance | Audio Quality | Tactical Implication |
|----------|--------------|----------------------|
| 0-5 meters | Crystal clear | Normal conversation range |
| 5-15 meters | Slightly muffled | Can communicate but must speak louder |
| 15-30 meters | Distant, hard to understand | Use pre-arranged signals or pings |
| 30+ meters | Inaudible | You cannot hear teammates at all |

### Designate a Squad Leader

Every successful squad has exactly **one voice calling the shots**:

- The leader decides **when to fight** and **when to extract** — no debates mid-ambush.
- The leader assigns **watch zones** during loot phases and boss pulls.
- The leader makes the final call on **sanity reports** — if two players disagree on what they see, the leader's call wins and everyone verifies.

In a squad of four voices, silence during danger is a decision — and usually the wrong one.

### Callout Vocabulary That Works

Keep callouts short, specific, and repeated — the team needs to act on them in seconds.

| Situation | Say This | Response |
|----------|----------|----------|
| Enemy spotted | "Y'm-bhi scout, north, two" | Confirm count, choose stealth or pull |
| Sanity event | "Hallucinating, don't trust my left call" | Team verifies visuals before acting |
| Impostor / false ally | "He's not a teammate, don't engage" | Wait for second confirmation before shooting |
| Boss / elite pull | "Elite on me, need the Point Man" | Point Man moves, others hold the line |
| Extraction decision | "Extracting now, moving to flare" | Everyone moves; no solo heroics |
| Firearm noise | "Shot fired at 3 o'clock" | Assume the area is alerted |
| "Contact front / left / right / rear" | Enemy direction | Prepare or reposition |
| "Mask on / off" | Nyarlathotep activation | Do not shoot the masked player |
| "Pulling back" | Retreating to previous position | Cover the retreat |
| "Ox Cart" | Regrouping at the cart | Fall back to the anchor point |

**The verification rule:** in The Mound, one player may see a monster where another sees a teammate — or a clear path where another sees spikes. **Never act on a lone visual.** Confirm what you see with at least one teammate before swinging, shooting, or stepping.

### Communication Tips

1. **Stay in visual range.** If you can see a teammate, your voice will reach them.
2. **Use pings as backup.** If voice is not reaching, use the ping system. A Medallion ping is audible at longer range than voice.
3. **Do not shout over each other.** In combat, one person calls the shots. Designate a squad leader before the expedition.
4. **Headphones are strongly recommended.** Spatial audio works best with stereo or surround headphones.
5. **No health bars:** The Mound shows no teammate status. The only way to know someone is hurt or losing their mind is to ask them.

### The No-Mic Playbook

No microphone? You can still be a reliable teammate:

1. **Use the gesture wheel** — signal "enemy," "extract," and "follow me" deliberately.
2. **Stay glued to the team** — without voice, distance is the only thing you control. Never wander.
3. **Move last, move slow** — silent players should trail the group and watch the rear.
4. **Pre-agree simple signals** before the expedition starts (e.g., two quick pings = extract).

## Hallucinations, Impostors and Trust

The Mound's horror is *social*:

- **Hallucinations differ per player.** One teammate may see a monster where you see a friend — or a clear path where you see spikes. Never shoot on a lone sighting; verify with your teammate first.
- **Monsters impersonate teammates.** A creature can wear your friend's face, distinguishable only by occasional beast-like noises. If a "teammate" sounds wrong, it is not your teammate.
- **Corrupted allies:** a downed teammate who is not revived in time becomes an **AI-controlled corrupted enemy** that hunts you. Revive fast — Ammonia Salts are the item to carry for emergencies.
- **Noise attracts enemies for everyone** — one player sprinting or shooting can pull an ambush onto the whole squad.

### Helping Teammates Who Are Losing Sanity

Sanity is individual, but its effects are felt by the whole squad.

| Sign | What to Do |
|------|-----------|
| They call out things no one else sees | Gently tell them it is a hallucination. Ask them to stay still. |
| They shoot at nothing | Tell them to holster their weapon and move toward you. |
| They wander off alone | Follow them, keep talking, keep them oriented. |
| They attack a teammate | This is a hallucination. Do not shoot back — use non-lethal methods (push, body block). |
| They are unresponsive | They may be experiencing a deep hallucination event. Physically guide them. |

**Sanity Rescue Procedure**

| Step | Action |
|------|--------|
| 1 | Identify the affected player |
| 2 | Move close (within 5 meters) so voice is clear |
| 3 | Tell them they are hallucinating — use their name |
| 4 | Ask them to stop and look at you |
| 5 | Administer a Sanity-restoring item if available |
| 6 | Keep them in the center of the formation until they recover |

## Revival Mechanics

### Player Down States

| State | Trigger | Recovery |
|-------|---------|----------|
| Downed (Incapacitated) | HP reaches 0 | Teammate can revive with 8-second channel |
| Bleeding Out | Downed for 30 seconds without revival | Permanent death |
| Corpsed | Death confirmed | Body is consumed by the forest |
| Corrupted | Forest consumes the body | Corpses revive as AI-controlled corrupted version of the player |

### The Corrupted Teammate Threat

When a player dies and their body is consumed by the forest, they respawn as an **AI-controlled Corrupted version** that hunts the surviving squad members.

| Property | Detail |
|----------|--------|
| Appearance | Corrupted version of the dead player's character |
| Behavior | Actively hunts surviving players |
| Abilities | Retains some weapon abilities from the original loadout |
| Health | Increased compared to living version |
| Weakness | Same as Y'm-bhi (light sensitive) |

### Revival Priority

1. **Extraction is close (<5 minutes):** Only revive if safe. Otherwise, extract and let them respawn on the Galleon.
2. **Extraction is far (>10 minutes):** Revive. Losing a player for the whole expedition cripples the squad.
3. **Under attack:** Clear all enemies first. Reviving while under fire is suicide.
4. **Low Sanity squad:** Consider whether the revived player will immediately fall to hallucinations again.

## Team Survival Rules

1. **Assign roles before departure** — Point Man, Support, Rearguard, Pack Mule (see the Squad Roles section above)
2. **Designate a squad leader** — one voice calls the shots in combat
3. **Use the Ox Wagon as your meeting point** — its paint streak anchors navigation, and standing near it reduces everyone's Insanity
4. **Extract when sanity breaks down** — if two players are hallucinating, the haul is not worth the wipe. Dying means losing all gathered loot
5. **Never split up in the dark** — separated players cannot communicate, and that is exactly when the impostors hunt

## Advanced Team Tactics

### The "Turtle" (Defensive Formation)
Use when surrounded or at extraction point.
- Squad forms a tight circle
- All members face outward
- Each player covers a 90-degree arc
- Point Man calls targets
- Support and Rearguard watch for approaching enemies

### The "Ghost" (Stealth Formation)
Use when navigating high-density enemy zones.
- Single file, 5 meters apart
- Point Man leads, marks enemies
- All movement is crouched
- No guns unless absolutely necessary
- Mask of Nyarlathotep used for close passes

### The "Hammer and Anvil" (Combat Formation)
Use when engaging a strong enemy or group.
- Support and Rearguard hold position ("Anvil")
- Point Man flanks ("Hammer")
- Anvil draws aggro with noise
- Hammer strikes from behind with backstabs

## Troubleshooting Multiplayer

| Problem | Fix |
|---------|-----|
| Friend cannot join | Re-check the 6-character lobby code and host privacy (Friends Only) |
| Crossplay not working | Crossplay is on by default — ensure everyone is on the latest game version |
| Cannot invite from friend list | Verify the host's privacy setting, then use the lobby code as fallback |
| Console players can't find PC rooms | Have the PC player join the console player's room instead, or use the lobby code/invite flow directly |
| No match ID system | There is no visible match ID — random search is the only "public" path; always use the 6-character lobby code |
| Mixed-language lobbies | Random matchmaking can drop you into lobbies with players who speak a different language — no region or language filter exists; play with friends |
| Cross-platform voice broken | In-game voice chat is unreliable across platforms — use a third-party voice app (Discord/Party Chat) |
| No in-game friends list across platforms | The game has no cross-platform friend system — exchange lobby codes on Discord/other chat before launching |
| Voice chat inaudible | Proximity voice only — get within 5 meters, or use the gesture wheel; headphones strongly recommended |

### Crossplay Troubleshooting Checklist

Work through these in order when crossplay fails:

- [ ] All players on the same game version (version mismatch blocks crossplay)
- [ ] Host recreated the lobby **after** friends tried to join (stale lobbies are a common failure)
- [ ] Lobby code entered exactly — 6 characters, case-sensitive if the game distinguishes
- [ ] Try the reverse direction: **console player hosts, PC player joins**
- [ ] Restart the game fully (not just to menu) on all devices
- [ ] Check **NAT type** — open NAT is required for reliable hosting; UPnP enabled on the router
- [ ] Platform accounts online: PSN online / Xbox Live / Steam online all required
- [ ] Firewall/antivirus not blocking the game executable
- [ ] If voice fails specifically: use Discord/Party Chat for the session
- [ ] Still stuck? Check the [Patch Notes](/guides/updates-patch-notes) for known issues, and report on the official Discord
