# Fallen Tear: The Ascension System Requirements Guide

Fallen Tear: The Ascension is a hand-drawn 2D Metroidvania — modest hardware requirements, but worth confirming before launch day. The requirements below are from the official Steam store page [Official].

## Minimum Requirements

To run the game at minimum settings:

| Component | Requirement |
|-----------|-------------|
| **OS** | Windows 10 64-bit |
| **CPU** | Intel Core i5-4460 / AMD Ryzen 3 1200 |
| **RAM** | 8 GB |
| **GPU** | NVIDIA GTX 950 / AMD Radeon R7 370 |
| **DirectX** | Version 11 |
| **Storage** | 15 GB available space |

[Source: Official]

## Recommended Requirements

For a smooth experience at higher settings:

| Component | Requirement |
|-----------|-------------|
| **OS** | Windows 10 / 11 64-bit |
| **CPU** | Intel Core i5-6600K / AMD Ryzen 5 1400 |
| **RAM** | 16 GB |
| **GPU** | NVIDIA GTX 1060 3 GB / AMD RX 580 4 GB |
| **DirectX** | Version 11 |
| **Storage** | 15 GB available space |

[Source: Official]

## What These Specs Mean

The requirements are **modest** — a 2015-era CPU (i5-4460) and a GTX 950 can run the game at minimum [Editorial]. Hand-drawn 2D animation is less demanding than 3D:

- **Minimum spec** = playable at low settings, likely 1080p/60fps for a 2D game, but with possible slowdown in dense combat [Editorial].
- **Recommended spec** = smooth 60fps with room for effects like the dash fire-trail and Overgrowth form [Editorial].
- **15 GB** is the install size — modest for a 20-region hand-drawn game.

These performance expectations beyond the official specs are [Unconfirmed] — treat them as estimates.

## Steam Deck

The game is listed as **Steam Deck playable** on the Steam store page [Official]. This is a good sign for a 2D Metroidvania with a controller-first combat scheme. Exact Steam Deck performance (framerates, TDP, verification details) is [Unconfirmed] — expect the official Steam Deck verification status to be updated at 1.0 [Editorial].

## Storage and Installation Notes

- **15 GB install size** is the requirement on both minimum and recommended specs [Official].
- The game uses **Steam Cloud** for saves [Official] — your progress syncs across devices.
- **Family Sharing** is supported [Official], so one library copy can be shared with family accounts.
- A DirectX 11 runtime is required; Windows 10 64-bit is the floor [Official].

Because the install is modest, you will not need to clear out other games to make room — 15 GB is on the small side for a 20-region hand-drawn Metroidvania [Editorial].

## Controller Support

Fallen Tear is a fast, timing-based combat game, and its Steam page tags it as a **gamepad-friendly** action game [Editorial]. While the exact supported controllers have not been enumerated [Unconfirmed], the "Steam Deck playable" status and the action-combat design strongly imply full gamepad support, including the PlayStation and Xbox controller standards [Editorial]. Expect keyboard/mouse and gamepad bindings to be configurable at launch [Unconfirmed].

## Comparing to Similar Games

To calibrate the specs, compare to other hand-drawn 2D Metroidvanias of similar scope:

- **Hollow Knight** (2017): a reference point for hand-drawn Metroidvania — the minimum i5-4460 / GTX 950 requirement is in the same league as Fallen Tear's floor [Editorial].
- **Ori and the Will of the Wisps** (2020): more demanding than Fallen Tear on paper, but a similar genre benchmark [Editorial].

In short: **if your PC ran a mid-2010s 2D Metroidvania at 60fps, it will run Fallen Tear** [Editorial]. The requirements are deliberately modest to match the hand-drawn art style.

## If Your PC Is Below Minimum

If you fall below the minimum spec (e.g., 6 GB RAM or a pre-2014 GPU):

- **Lower the resolution.** A 2D game at 720p can often run where 1080p stutters [Editorial].
- **Check for effects toggles.** The dash fire-trail and Overgrowth effects are the likeliest performance hogs — toggling them off may help [Editorial].
- **Steam Deck is your fallback.** If your desktop is old, the Deck (which meets or exceeds recommended) is the safest purchase [Official].
