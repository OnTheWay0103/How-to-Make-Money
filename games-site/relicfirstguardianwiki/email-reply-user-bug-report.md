That said, your report is really useful — we've heard similar complaints from other players, and we've actually just updated our Troubleshooting Guide based on the exact issues you described. Here's a quick summary that might help:

**Inventory / Map Freeze**
- On PS5: Close the game completely (PS button → Options → Close Game), restart your console, then relaunch.
- On PC: Verify game files via Steam (Library → right-click → Properties → Installed Files → Verify integrity). Some players report the freeze correlates with high VRAM usage — try lowering Texture Quality in Settings → Graphics.
- Save at a checkpoint bonfire *before* opening inventory or map. If it freezes, you only lose progress since the last save.

**Save Progress Lost**
- The game only saves when you interact with checkpoint bonfires — passing near one is not enough. Make sure you see the save icon appear.
- After boss kills or cutscenes, wait 10-15 seconds before closing the game — the autosave needs time to complete.
- On PS5, if your save file is corrupted: Settings → Storage → Saved Data → The Relic: First Guardian → re-download from cloud backup (requires PS Plus).
- Check that you have at least 500MB of free storage — if the disk is full, saves can fail silently.

Full guide here: https://relicfirstguardianwiki.vercel.app/guides/troubleshooting
