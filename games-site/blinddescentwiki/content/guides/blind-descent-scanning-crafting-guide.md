# Blind Descent Survival Game: Scanning and Crafting

> Last verified: October 28, 2026 · Pre-release build (Early Access opens December 2, 2026)

Blind Descent has no recipe book to memorise. You scan lifeforms and structures, each scan widens the pool of things you can build, and the crafting itself is modular rather than a fixed list. That combination turns crafting into exploration instead of a checklist. This page explains how the two systems feed each other and what to craft in what order.

## Why there is no fixed recipe list

Most survival games hand you a tree: gather wood, unlock the workbench, unlock the axe, unlock the better axe. Blind Descent inverts that. The official store page describes scanning as the input to crafting, not a side activity:

> "Scan and study the lifeforms around you to gather resources and craft essential tools." It adds that "observing how alien creatures interact with their environment can lead to powerful insights."

The publisher's October 2026 release note then describes the output side: "Modular crafting instead of following fixed recipes," covering weapons, tools, shelter and medicine.

Put together, the loop is: observe, scan, gain an insight or a material, and the set of things you can assemble grows. There is no published recipe table to print, which is why guides that list exact recipes for this game should be treated with suspicion. If a site gives you a full recipe list before December 2, ask where it came from.

## How scanning feeds the recipe pool

The playtest coverage describes the scanner as the strongest system in the build: almost every plant, animal and structure can be scanned, and each scan expands the recipe pool, producing progression that feels like a tech tree without an explicit unlock screen.

Practical consequences:

- **Scan non-obvious targets.** Structures and passive creatures count, not just hostile ones.
- **Scan repeats are still worth doing** if the object is new to you. There is no confirmed penalty for over-scanning.
- **Your recipe pool is a map of where you have been.** If it stops growing, you have exhausted the local content, not the game.
- **Insights are the interesting half.** The store page separates resources (scan to gather) from insights (observe how creatures interact with the environment). The second is easy to miss because it does not look like loot.

## Modular crafting, in plain terms

"Modular" means the game gives you components and lets you assemble them, rather than handing you a finished item named in a menu. The publisher's phrasing matters: weapons, tools, shelter and medicine all sit under the same modular system.

What that implies for a player:

| System | What modular means in practice | Confidence |
|---|---|---|
| Weapons | Different weapon types behave differently; the release note says "every weapon type plays different" | Official |
| Tools | Tools are built to solve an obstacle, so the tool follows the terrain | Official |
| Shelter | Built log-by-log, so the structure is assembled rather than placed as a prefab | Official |
| Medicine | Craftable, and the game tracks infection and body-part injuries that need treating | Official |
| Tools mutating | Some gear is described as gaining new behaviour rather than being replaced | Community, [Unconfirmed] |

That last row is the one to be careful with. Third-party coverage describes a system where tools and weapons "mutate" instead of levelling, with examples like a hammer gaining stronger strikes or a shield and sword unlocking defensive moves. The official material confirms modular crafting and confirms mutation as a player path, but it does not spell out gear mutation as a system. Treat it as `[Unconfirmed]` until the build ships.

## The early craft order

This order is ours, built from what the playtest actually needed and what the store page says the game rewards. It is not an official list.

| Priority | Craft | Why |
|---|---|---|
| 1 | Water container | Converts loose sips into one carried item and fixes the worst early death |
| 2 | Fire pit | Boiling and cooking both depend on it |
| 3 | Axe | Gathering and a usable melee option in one tool |
| 4 | Club | Cheap backup weapon for the first hostile creature |
| 5 | Lean-to | A respawn-adjacent shelter before you have a base |
| 6 | Workbench | Unlocks base-side crafting and is the anchor for expansion |
| 7 | Containers | Solves the weight problem that separate inventories create in co-op |
| 8 | Climbing gear | Documented traversal tool; opens vertical routes and shortcuts |

The trap is skipping 1 and 2 because they are boring. Every playtest account of death in the opening traces back to water, food or exposure, not to a monster.

## Resources: weight, durability and stacking

Three resource rules shape how you play, and all three are documented.

**Weight.** The playtest build tracked resource weight, and the reviewer flagged interface problems around stacked resources. The design consequence is that you cannot strip a room bare and walk home; you make trips.

**Durability.** Gear wears out. That makes the axe a consumable as much as a tool, and it makes a repair or replacement loop part of the routine rather than an emergency.

**Stacking.** Stacked-resource interactions were listed as an interface complaint in the playtest, which tells you stacking exists and is meaningful. Assume partial stacks are normal and plan storage around it.

In co-op, all three get sharper because inventory is separate per player. Four half-full packs are worse than one organised base, which is why the [co-op guide](/guides/blind-descent-coop-multiplayer-guide) puts a quartermaster in the role split.

## The adaptations interface is your real quest log

The playtest described an "adaptations interface" that presents objectives and biome opportunities, including armour crafting, signal tracking and new shelter blueprints. If you are used to a quest journal, this is the closest equivalent, and it is worth opening regularly.

Treat it as a menu of what the game thinks you are ready for. When a new blueprint appears there, it usually means a scan or a story beat has opened a door, and the materials for it are somewhere in the biome you are standing in.

## Common scanning and crafting mistakes

| Mistake | What it costs | Fix |
|---|---|---|
| Scanning only hostile creatures | Recipe pool grows slowly, gear stalls | Scan plants, structures and passive animals |
| Hoarding raw materials at a node | Weight lock, no base progress | Carry to storage, return, repeat |
| Building wide before building storage | Four overflowing packs in co-op | One workbench and several containers first |
| Ignoring durability | Tool breaks mid-expedition | Carry a spare or return before the bar empties |
| Assuming a recipe list exists | Wasted time hunting for a menu that is not there | Scan more, memorise less |
| Treating insights like flavour text | Missing the observation-based unlocks | Watch how creatures interact, then scan the result |

## Scanning and crafting questions

| Question | Answer |
|---|---|
| Is there a recipe book? | No fixed recipe list is documented; crafting is described as modular |
| How do I unlock new items? | By scanning new lifeforms and structures, which expands the recipe pool |
| Can I scan everything? | The playtest reported almost every plant, animal and structure was scannable |
| Do scans cost anything? | Nothing documented; scan freely |
| Are there skill points? | No conventional skill tree is described; progression runs through scans, gear and the mutation fork |
| Do tools level up? | [Unconfirmed] — third-party coverage describes gear mutation, official sources do not |
| What should I craft first? | Water container and fire pit, then axe and club |
| Does crafting differ in co-op? | The system does not, but separate inventories change how you store and share materials |
