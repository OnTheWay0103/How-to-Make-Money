# Skills & Raids Events Guide — Limited-Time Activities and Rewards

**Skills & Raids Open Beta / Updated: July 27, 2026**

Skills & Raids regularly features time-limited events that offer exclusive gear, cosmetics, and upgrade materials. Understanding the event calendar and optimizing your participation can dramatically accelerate your progression. This guide covers every active event type, schedule patterns, and reward priorities.

---

## 1. Recurring Event Types

### 1.1 Daily Challenges

Every day resets a set of three challenges with escalating rewards.

| Challenge Tier | Objective Example | Reward | Difficulty |
|---------------|------------------|--------|------------|
| Easy | Extract from any map once | Enhancement Shard x5 | Very Low |
| Medium | Kill 3 elite monsters | Enhancement Crystal x2 | Low |
| Hard | Extract with 10,000+ loot value | Radiant Shard x1 | Medium |

**Tips:**
- Stack easy challenges across multiple characters for bonus materials.
- Hard challenges often overlap with normal gameplay — check them before queueing.

### 1.2 Weekly Boss Rush

Every weekend (Friday through Sunday), the Boss Rush event activates.

| Boss Rush Wave | Enemies | Exclusive Reward | Recommended Team Score |
|---------------|---------|-----------------|----------------------|
| Wave 1–5 | Mini-bosses | Boss Cache (common) | 200+ |
| Wave 6–10 | Full bosses | Boss Cache (rare) | 400+ |
| Wave 11–15 | All bosses simultaneously | Event Currency | 600+ |
| Wave 16–20 | Mega-boss wave | Exclusive Weapon Skin | 800+ |

**Reward Scaling:** The further you progress, the better the weekly reward chest. Surviving wave 15 or higher guarantees an Event Currency drop.

### 1.3 Seasonal Events

Seasonal events run for 2–4 weeks and introduce themed maps and unique currency systems.

| Season | Theme | Duration | Exclusive Items |
|--------|-------|----------|-----------------|
| Haunted Harvest | Halloween | Oct 25 – Nov 7 | Pumpkin weapon skin, ghost pet |
| Frostfall | Winter | Dec 20 – Jan 10 | Ice armor set, snowboard mount |
| Spring Bloom | Spring | Apr 1 – Apr 14 | Flower pet, nature-themed cosmetics |

## 2. Event Currency and Reward Shops

Most events introduce a temporary currency that can be spent in a dedicated reward shop.

### 2.1 Currency Sources

| Activity | Currency Earned | Rate |
|----------|----------------|------|
| Daily Challenge completion | 10 tokens per challenge | 30 tokens/day |
| Boss Rush wave milestone | 50 tokens per 5 waves | 200 tokens/weekend |
| Seasonal map extraction | 5–15 tokens per run | Variable |
| Event achievement | 100–500 tokens per achievement | One-time |

### 2.2 Reward Priority List

Not all shop items are worth the same. Prioritize as follows:

| Priority | Item | Token Cost | Why Buy |
|----------|------|-----------|---------|
| 1 | Radiant Shard (weekly limit x3) | 50 each | Cheapest source of endgame upgrade material |
| 2 | Exclusive Weapon Skin | 300 | Limited-time cosmetic, never returns |
| 3 | Legendary Gear Cache | 500 | Guaranteed legendary item |
| 4 | Enhancement Crystal Bundle (x10) | 100 | Good value for mid-game players |
| 5 | Pet Egg (event-themed) | 200 | Exclusive pet, minor gameplay value |

## 3. PvP Tournament Events

Special PvP tournaments run on the last weekend of each month.

### 3.1 Tournament Format

| Phase | Duration | Description |
|-------|----------|-------------|

| Round of 32 | Saturday, 4 hours | Single elimination |
| Quarterfinals | Saturday, 2 hours | Best-of-5 |
| Semifinals + Finals | Sunday, 3 hours | Best-of-5, live spectated |

### 3.2 Tournament Rewards

| Placement | Reward | Additional |
|-----------|--------|------------|
| 1st Place | Golden Weapon Skin + Title "Champion" | 1,000 event tokens |
| 2nd Place | Silver Armor Skin + Title "Runner-Up" | 500 event tokens |
| Top 8 | Bronze Accessory Skin | 200 event tokens |
| Participant | Participation Banner | 50 event tokens |

## 5. Event Calendar Management

Optimize your play schedule around these event windows.

### 5.1 Weekly Priority

| Day | Priority Event | Time Required |
|-----|---------------|---------------|
| Monday | Fresh daily challenges, weekly reset | 30 min |
| Tuesday–Thursday | Daily challenges only | 15 min |
| Friday | Boss Rush starts, PvP qualifiers | 1–2 hours |
| Saturday | Boss Rush continuation, PvP elimination | 1–2 hours |
| Sunday | Boss Rush final push, PvP finals | 1–2 hours |

### 5.2 Seasonal Planning

- **First week of season:** Grind seasonal currency hard. New items cost more but are available longest.
- **Mid-season:** Focus on daily challenges and weekend boss rushes. Stockpile tokens.
- **Final week:** Spend all remaining tokens. Unused seasonal currency is converted to gold at a poor rate.
- **Between seasons:** No events active. This is the best time for normal progression and practicing hard content.

---

## 6. Pro Tips for Event Efficiency

- **Stack boosts with events.** Using XP boosters during Double Loot Weekend doubles both.
- **Alt characters multiply rewards.** Daily challenges are per-character. Three alts = triple daily tokens.
- **Save enhancement attempts for cost reduction weekends.** A single weekend of reduced costs can save hundreds of thousands of gold.
- **Join the official Discord.** Event announcements, extended weekend timers, and bonus reward codes are posted there first.
