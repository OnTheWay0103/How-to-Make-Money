# Skills & Raids System Requirements — PC Specs & Performance Guide

Skills & Raids is a party-based extraction RPG with real-time ability combat — and its requirements are genuinely low. This guide covers the published minimum specs, what is still unpublished, and what to expect on your machine.

**Honesty note:** as of August 8, 2026, the Steam page lists modest minimum specs (reported via launch coverage), but a full official spec table — recommended tier included — has not been confirmed in coverage we can verify. Figures below are the reported minimum; anything else is marked TBD.

## Reported Minimum System Requirements

| Component | Minimum (reported) |
|-----------|--------------------|
| **OS** | Windows 10 |
| **Processor** | Intel Core i3 4th Gen or equivalent |
| **Memory** | 1 GB RAM |
| **Graphics** | Most dedicated GPUs (modest requirement) |
| **Storage** | ~1 GB available space |

## What the Numbers Mean

- **1 GB RAM** and **~1 GB storage** are extremely low bars — if you can run Windows 10, you can almost certainly run this game.
- The processor requirement (4th-gen i3-class) is a decade-old baseline.
- "Most dedicated GPUs" is the published phrasing — the game's handcrafted 2D-art presentation keeps GPU demands modest.
- **Recommended specs: not published** as of August 8, 2026. Anyone quoting a recommended tier is estimating.

## Performance Notes (Honest)

- The game's presentation is **handcrafted fantasy art with real-time combat** — not a heavy 3D renderer. Expect light GPU load.
- The **pause mechanic** is the real performance friend: mid-fight pauses read skill and status descriptions, and it also lets a slower machine catch up between action beats.
- **The demo is your benchmark.** The May 27, 2026 demo runs the same engine — if the demo runs well, the full game will (see the [Release Date Guide](/guides/release-date-guide) for demo access).
