# Why Is the Loadout Station Locked in Crimson Moon?

You finish a mission, return to Sanctus Clypeus, walk up to the Loadout Station, and find it unusable. Sometimes it is floating above the room or stuck in the ceiling. The natural conclusion is that the game has bugged out.

It usually has not. The Loadout Station is locked because **you are still in an active run**. Crimson Moon treats a run as a single continuous commitment — three missions and a World Boss — and returning to the hub between missions does not end it. Until that run finishes or you abandon it, your loadout is frozen.

This guide explains what the game counts as a run, where the Loadout Crystal actually is, how to end a run cleanly, and how purification and Gajov upgrades interact with the gear you are trying to equip.

## The Short Answer

The Loadout Station stays unavailable **during an active run** [Official]. That is the developer's own explanation, published in the September 2, 2026 "Helpful Resources: Runs, Loadouts & Gear" post after players repeatedly reported the station as broken.

The same post confirms two related rules that cause most of the confusion:

- **Purifying an item unlocks it at Common quality**, regardless of the quality you found it at.
- **Gajov upgrades raise that item's minimum quality** everywhere it appears — in future runs, whether you select it from your Loadout or find it as loot.

In other words, the station is not refusing to let you equip your gear. It is refusing to let you rebuild your character in the middle of a run you have already committed to.

## What Counts as a Run?

A full run is **three missions plus a World Boss** [Community]. The hub visit between mission one and mission two is a breather, not a reset. The same applies between mission two and mission three.

That distinction is the whole problem. Players see the cathedral, the War Table, and the NPCs, and assume the run has ended because they are physically back in the hub. Crimson Moon does not use location as the boundary. It uses the run state.

A run ends when one of the following happens [Community]:

- You complete the full run, including the World Boss.
- Your **Life Pool** is depleted and the run fails.
- You choose **Abandon Run** or **End Session**.

Simply walking back through the cathedral door does not qualify.

## Where the Loadout Station Is

The station is easy to miss because it is not in the main hub room. The community-documented route is [Community]:

1. Return to **Sanctus Clypeus**.
2. Go to the **War Table** and select **Mission 1** as if you were starting a fresh run.
3. Head **north and upstairs**.
4. Interact with the **Loadout Crystal** in the room before the mission entrance.

The Crystal is where you select, edit, or create a loadout. Community guides report **five saved slots**, which is enough to keep separate setups for different builds without rebuilding from scratch each time [Community].

If you are standing at the War Table but have not selected Mission 1, you are still in the old run's flow. Select Mission 1 first, then go upstairs.

## What You Can and Cannot Change Mid-Run

Once a run has started, your starting Angel, weapons, armour, and trinkets are fixed [Community]. You cannot reopen your permanent collection and rebuild your character between missions.

You can still change equipment using gear **found or bought during that run** [Community]. That is the intended pressure valve: the run gives you loot, and you decide whether the new piece is worth swapping in for the current mission.

Items waiting in your Armory are **reserved for future loadouts**, not for the active run [Community]. Reserved items cannot be equipped or dropped mid-run; they auto-purify when you return to the hub [Community]. This is why a powerful item you purified last run may sit unusable in the Armory while you are mid-run.

The design is deliberate [Editorial]. If you could rebuild your character between every mission, the three-mission structure would lose its risk: every bad match-up could be solved by walking back to the Crystal. Locking the loadout forces you to commit to a plan and live with it.

## How to End a Run Properly

If you genuinely need to change your build, end the run rather than hunting for a workaround.

### Finish the run

The cleanest option is to complete the third mission and the World Boss. You keep the run's rewards and return to a fresh state.

### Abandon the run

If the build is not working, use **Abandon Run** or **End Session** from the menu [Community]. You do not have to die deliberately. The community guide is explicit that these options exist and are preferable to throwing a run just to reset.

### Let the Life Pool run out

Dying also ends the run, but it is the slowest and least controlled option. In co-op, remember that the Life Pool is shared — one player's deaths drain the team's margin. See the [Co-op Guide](/guides/coop-multiplayer-guide) for how the shared pool works.

Once the run has ended, select **Mission 1** at the War Table and visit the Loadout Crystal before entering the mission.

## Purification Quality and Gajov Upgrades

The Loadout Station confusion is often tangled with a second misunderstanding: players purify a Rare item and expect a permanent Rare version. That is not how it works.

The official explanation is precise [Official]:

- **Purification unlocks the item at Common quality.** The quality you found does not carry over as a permanent baseline.
- **Gajov upgrades raise the item's minimum quality.** Once upgraded, the item's floor improves everywhere — in your Loadout and in future loot.

So the loop is: purify the item to add it to your permanent pool, then invest in Gajov upgrades to make the permanent version worth using. Purification is the unlock; Gajov is the power.

The developer acknowledged that these systems need clearer in-game explanations, so expect the interface to improve in a future patch [Official]. Until then, the [Purification Guide](/guides/purification-guide) covers what to keep and what to skip, and the [Builds Guide](/guides/builds-guide) explains how purified gear fits into a full build.

## Step-by-Step: Change Your Loadout

Use this checklist when you want to change your setup [Community]:

1. **End the current run.** Complete it, abandon it, or let the Life Pool empty.
2. **Return to Sanctus Clypeus.**
3. **Select Mission 1 at the War Table.**
4. **Go north and upstairs** to the Loadout Crystal.
5. **Pick a saved slot or create a new loadout.**
6. **Confirm your Angel, weapons, armour, and trinkets** before entering the mission.
7. **Start the run.** The loadout is now locked until the run ends.

If the Crystal is still unusable after step 4, confirm that the previous run actually ended. A hub visit alone is not enough.

## Troubleshooting

**The Crystal is floating above the room or stuck in the ceiling.**
This is a visual symptom of the mid-run lock, not a separate bug [Community]. End the run and reload the hub.

**I abandoned the run but the Crystal is still locked.**
Make sure you selected Mission 1 again after abandoning. The station is tied to the pre-mission state, not the hub itself [Community].

**I restarted the session and it is still locked.**
Community guides suggest restarting the session and, as an unverified workaround, entering a Quick Match lobby before returning to the hub [Community]. The guide that documents this calls it unverified, so treat it as a last resort rather than a fix.

**My purified item is only Common quality.**
That is the intended result. Use Gajov upgrades to raise its minimum quality [Official].

**Can I use an Armory item mid-run?**
No. Reserved items are for future loadouts and auto-purify on returning to the hub [Community].

## FAQ

**Is the Loadout Station supposed to be locked during a run?**
Yes. The official post states it stays unavailable during an active run [Official].

**Does returning to the hub end the run?**
No. A run is three missions plus a World Boss. The hub visit between missions is part of the same run [Community].

**Can I change weapons mid-run?**
You can swap to gear found or bought during that run. You cannot rebuild from your permanent collection [Community].

**Why did my purified Rare item become Common?**
Purification unlocks the item at Common quality. Gajov raises the minimum quality afterward [Official].

**Does this affect co-op?**
Yes, in the sense that the run state is shared. If one player needs a loadout change, the team has to end the run. Plan builds before you start, especially with a shared Life Pool.

**Will this be fixed?**
The lock is intentional, so it is unlikely to be removed. The developer has said the explanations around loadouts and purification need improvement [Official].
