# Crimson Moon System Requirements — PC, Steam Deck, PS5 Pro

## Official PC System Requirements

Crimson Moon's official PC system requirements are now published on the Steam store page (App 4317690). The widely-reported figures are:

| Tier | Component | Requirement |
|------|-----------|-------------|
| **Minimum** | OS | Windows 11 (64-bit) |
| | Processor | Intel Core i5-8400 / AMD Ryzen 5 2600 |
| | Memory | 16 GB RAM |
| | Graphics | NVIDIA GeForce GTX 1070 / AMD Radeon RX 5700 |
| | DirectX | Version 12 |
| | Storage | 50 GB available space |
| **Recommended** | OS | Windows 11 (64-bit) |
| | Processor | Intel Core i7-10700K / AMD Ryzen 5 5600X |
| | Memory | 32 GB RAM |
| | Graphics | NVIDIA GeForce RTX 3070 / AMD Radeon RX 6700 XT |
| | DirectX | Version 12 |
| | Storage | 50 GB available space |

**Note on a spec discrepancy [Unconfirmed]:** most coverage (Wccftech, GameSpace, GamerFuzion) reports the Windows 11-only table above, while the **Epic Games Store** listing and some European outlets cite a variant with **Windows 10/11 support**, an Intel Core i5-9500 / GTX 1660 Ti minimum, and an i7-11700K / RTX 3070 recommended tier. Both agree on DirectX 12 and the GTX 1070-class / RTX 3070-class GPU split — verify against your storefront's listing if the OS line matters to you.

## PS5 Pro PSSR Support

The one concrete performance detail confirmed is **PS5 Pro support with PSSR** — Sony's spectral super-resolution upscaler. This means PS5 Pro owners should get higher resolution or smoother framerates than base PS5, leveraging PSSR's upscaling.

## Can I Run It on PC?

With the official specs above, here is how to judge your machine:

- **Windows 11 only:** both tiers list Windows 11 (64-bit) with no Windows 10 fallback in the majority of sources — check your OS before buying if you're on Windows 10.
- **RAM is the surprise:** 16 GB minimum / 32 GB recommended is high for an isometric action RPG — the run-based Incursion loop and loot persistence likely drive it.
- **50 GB storage:** no SSD requirement is listed, though an SSD is advisable for the mission-based run structure.
- **Verify against your storefront:** the Steam and Epic listings are the authoritative sources for the specs you'll actually get.
