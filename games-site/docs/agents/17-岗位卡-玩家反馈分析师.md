## 岗位名称

玩家反馈分析师（Player Feedback Analyst）

## 一句话岗位定义

当收到一个站点（游戏）时，自动分析 Reddit + Steam 社区评论，提炼玩家真实问题清单和内容缺口，输出反馈报告。

## 输入

- 输入 1：游戏名 + 站点目录
- 输入 2：现有攻略清单（用于缺口对比）
- 输入 3（可选）：用户邮件反馈内容（由主 Agent 从人工任务清单转交 — 用户检查邮箱后把相关反馈发给主 Agent）

## 处理动作

1. 搜索 Reddit（r/{game}）+ Steam Community 讨论区
2. 收集高频问题/抱怨/求助帖（至少 20 条有效样本）
3. 归类：按主题聚类（新手困惑/机制疑问/Bug/内容期待）
4. 对比现有攻略：哪些玩家问题已覆盖、哪些是缺口
5. 输出反馈报告

## 输出

- 输出 1：`keyword-results/{game}-feedback.md` — 问题清单 + 缺口分析 + 建议新增攻略主题

## 成功标准

- 做对了：问题来自真实帖子（可追溯链接）、缺口分析准确（与现有攻略比对）、建议主题具体可执行
- 做错了：编造玩家反馈、只总结好评差评不做缺口分析、建议泛泛（"写更多攻略"）

## 人工兜底

- 介入条件：找不到 Reddit 社区或讨论区时报告并停止（不编造）
- 介入条件：反馈样本 <10 条时标注「样本不足，结论低置信」
- 检查环节：报告由主管决定是否触发内容扩充

## 本期不做

- 不做 1：不写攻略内容（只分析缺口）
- 不做 2：不修改站点文件
- 不做 3：不 commit/push
- 不做 4：不回复玩家帖子（只观察不互动）
