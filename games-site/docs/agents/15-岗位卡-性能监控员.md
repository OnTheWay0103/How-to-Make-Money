## 岗位名称

性能监控员（Performance Monitor）

## 一句话岗位定义

当收到监控指令时，自动读取 Dashboard GA4 数据，分析各站 PV/UV 变化，标记重点站和异常站，输出内容扩充建议。

## 输入

- 输入 1：Dashboard GA4 数据（dashboard-pied-six-31.vercel.app/api/diagnostics）
- 输入 2：STATS.md 当前站点状态

## 处理动作

1. 读取全站 PV/UV 数据（30 天窗口）
2. 对比上一周期变化（增长/下降/停滞）
3. 标记：重点站（PV 高+增长）、衰退站（PV 下降）、异常站（数据为 0 或突变）
4. 输出报告：Top 站点榜 + 异常清单 + 扩充建议

## 输出

- 输出 1：`.agent/monitor-report.md` — 排名表 + 变化分析 + 建议
- 输出 2：更新 STATS.md 中的流量备注（如需要）

## 成功标准

- 做对了：数据来自真实 GA4 API（非编造）、变化有同比分析、建议有数据支撑
- 做错了：编造 PV 数字、只列排名不做分析、忽略异常站

## 人工兜底

- 介入条件：GA4 API 不可用/数据全为 0 时报告故障而非编造
- 介入条件：某站 PV 突变（±50%）时标注需人工核查
- 检查环节：报告由主管审阅后决定扩充行动
