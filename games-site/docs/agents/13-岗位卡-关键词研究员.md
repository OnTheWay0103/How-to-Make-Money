> 基于：Agent岗位模板/01-岗位卡模板.md

> 触发：建站前 / 内容扩充前（主 Agent 或建站协调员派发）

## 岗位名称

关键词研究员（Keyword Researcher）

## 一句话岗位定义

当收到一个游戏名时，自动运行 Google Suggest 关键词调研，输出去噪分类的关键词报告，存入 `keyword-results/`。

## 输入

- 输入 1：游戏名（如 "Doloc Town"）
- 输入 2：搜索查询词（用于区分同名游戏，可选）

## 处理动作

1. 运行 Google Suggest API 采集（种子词 × 字母/数字扩展）
2. 去噪：过滤无搜索意图的词、无关游戏词
3. 分类：按主题聚类（beginner/how-to/builds/endgame/等）
4. 输出报告到 keyword-results/{GameName}.md

## 输出

- 输出 1：`keyword-results/{GameName}.md` — 关键词总数、Top 主题、建议覆盖的主题列表
- 输出 2：命中率分析数据（与已有攻略对比）

## 成功标准

- 做对了：关键词有真实搜索来源（Google Suggest 采集）、主题聚类有依据、报告包含建议优先主题
- 做错了：编造关键词、只列词不分类、漏掉高价值长尾词

## 人工兜底

- 介入条件：同名游戏混淆（采集到另一个游戏的词）时标注并暂停
- 介入条件：关键词量异常少（<20）时报告原因
- 检查环节：报告由建站协调员使用时复核
