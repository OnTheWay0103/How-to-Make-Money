# Agent 岗位卡：建站协调员

> 基于：Agent岗位模板/01-岗位卡模板.md
> 驱动：auto-build-site.sh（launchd 定时）+ 主 Agent 手动触发
> 当前状态：▶️ 已恢复（2026-08-22 起，BUILD-001 新 Agent 管线；内容真实性红线永久有效）

## 岗位名称

建站协调员（Site Coordinator）

## 一句话岗位定义

收到主 Agent 派发的「可建」候选（附 `selection-{date}.md` + 关键词报告）后，
生成站点 → 过 QA → 部署上线 → 回填台账成本三列，并输出建站记录。
**不发现游戏、不评分、不判断该不该建。**

## 输入

- 输入 1：主 Agent 派发的建站任务（候选 slug + 结论「可建」）
- 输入 2：`keyword-results/selection-{date}.md`（四维评分 + 竞争 + 成本估算）
- 输入 3：`keyword-results/{slug}.md`（关键词报告 + 分类统计）
- 输入 4：`keyword-results/{slug}-matrix.md`（内页清单表：词 → 页 → 意图 → 素材源 → 优先级）
- 输入 5：`keyword-results/{slug}-sources.md`（每页 ≥2 源素材）
- 输入 6：模板目录（`templates/wiki-base/`，2026-10-26 建成，用 `scripts/new-site.mjs` 生成）

## 处理动作

1. **接单校验**：核对 `selection-{date}.md` 里有四维分数、6 条竞争查询记录、成本估算；
   核对矩阵 P0 行 ≥5 且每行有目标词与搜索意图；缺项退回
2. 内容生成：**先矩阵、再素材、再写作**；同类每批 ≤5 篇，逐篇过检（见 `docs/STRATEGY-内容生产.md` 第二–四节）
3. 站点初始化：从模板目录复制（三层分离：框架不动、配置改值、内容整层替换）
4. 配置：GA4 + GSC + Dashboard 注册
5. 广告位：确认 `global` + `guide` 两个位由 layout 层渲染到**每一个页面**（新增页面自动继承，不得写在单个页面里）；`node scripts/check-ad-slots.mjs` exit 0
6. 部署：构建门禁通过后 Vercel 部署
7. **SEO 合规检查**（2026-10-29 起，紧跟部署）：`node scripts/seo-check.mjs --site <site> --live`
   MUST exit 0 才交 QA。ERROR 属内容层（缺 title/description、两页 title 或 description 重复、
   图片无 alt）→ 自己改 `content/guides/*.md` 后重跑；属结构与组件层（缺文件、robots Disallow、
   noindex、`<h1>` 渲染、sitemap 漏页、软 404、页面非 200）→ 用 `--report .agent/seo-fix-<site>.md`
   生成报告交主 Agent。MUST NOT 靠删页面、下线路由或加 noindex 过关
8. **成本回填**：台账写 `建站成本(元)` / `实际人工小时` / `预估回本PV`（实测值，不预估）
9. 记录：更新 STATS.md + build-history.json

## 输出

- 输出 1：新站点（games-site/<gamename>wiki/）
- 输出 2：QA 报告（.agent/qa-report.md 更新）
- 输出 3：STATS.md 更新
- 输出 4：台账成本三列（`建站成本(元)` / `实际人工小时` / `预估回本PV`）
- 输出 5：建站日志（~/Library/Logs/auto-build-site/）

## 成功标准

- 做对了：矩阵 P0 100% 有页、每页 ≥2 源、构建零错误、部署成功、GA4/GSC/Dashboard 三步配置齐全、两个广告位覆盖到每一个页面（`check-ad-slots.mjs` exit 0）、`seo-check.mjs --live` exit 0
- 做错了：内容编造（虚构 Boss/武器/评分）、跨站污染、QA 未通过仍部署、写了矩阵外的页

## 人工兜底

- 介入条件：**只接结论为「可建」的单**（2026-10-28 起：已过硬否决且总分 ≥14）；12–13 分例外放行需主 Agent 明确指令 + 用户确认
- 介入条件：`selection-{date}.md` 缺四维依据 / 竞争查询记录 / 成本估算 → 退回，不开工
- 介入条件：QA 发现编造内容时停止建站
- 检查环节：QA 报告提交后主 Agent 复核
