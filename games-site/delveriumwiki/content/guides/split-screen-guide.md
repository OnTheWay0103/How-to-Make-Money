# Delverium Split-Screen Guide — 4-Player Couch Co-op Setup

Split-screen isn't an afterthought in Delverium — **it's the reason the game exists.** Lead developer Scott Lowther started the project around 2016 after playing split-screen Terraria with his family, and 4-player local split-screen has been in the game since the demo's launch on February 7, 2025. This guide covers everything about playing Delverium on one screen: setup, controllers, starting a session, mixing local and online play, and tips for making couch co-op run smoothly.

> **Pre-release guide — will be updated for EA launch (Sept 22, 2026).** Exact in-game UI steps are based on the demo build; anything unconfirmed is marked TBD / 待验证.

## Split-Screen Facts (Confirmed)

| Fact | Detail |
|---|---|
| **Max local players** | **4 players** on one screen, one world |
| **Available since** | Demo launch, February 7, 2025 |

| **Player count range** | The game supports 1–8 players overall, so split-screen is one mode within that |
| **Mixing local + online** | Conceptually supported (1–8 players), exact combination rules TBD / 待验证 |

## How to Set Up Split-Screen (Demo-Verified Steps)

### 1. Gather the controllers

- You need **gamepads** — one per local player
- Full controller support is planned for the release; gamepads work with split-screen in the demo today
- Keyboard-and-controller mixing on one screen is not documented — plan for controllers

### 2. Launch Delverium

- Launch **Delverium Demo** (or the full game after September 22, 2026) on Steam
- The demo supports up to 4 players on one screen from the start

### 3. Start a world together

- Start a new world — you can customize **world, character, and difficulty** (added in the Feb 2026 demo update), which is great for mixed-skill groups
- Players join the same world on the shared screen
- Exact UI flow will be finalized for EA — the demo proves the feature, the menus may evolve

### 4. Play

- Everyone shares the same world and progression
- The demo supports **drop-in/drop-out** play (confirmed Feb 2026) — family members can join and leave without restarting

## Split-Screen vs Online Co-op: What's Different

| | **Split-screen (local)** | **Online co-op** |
|---|---|---|
| **Players** | Up to 4, one screen | Up to 8, via Steam |
| **Requires** | Gamepads + one PC | Steam invites + internet |
| **Feel** | Shared couch experience — everyone sees everything | Each player has their own screen |
| **Best for** | Family, housemates, kids, parties | Friends at distance, large groups |
| **Full details** | This guide | [Co-op & Multiplayer guide](coop-multiplayer-guide) |

The two aren't rivals — the game supports 1–8 players total, and the natural direction is combining them (2 local + friends online), though exact combination rules are **TBD / 待验证** for EA.

## Couch Co-op Role Ideas (No Classes Needed)

Delverium has no character classes — roles are what you do, not what you pick. A classic 4-player family spread:

| Player | Role | Keeps the party supplied with |
|---|---|---|
| **1** | Gatherer / explorer | Ores and materials for crafting upgrades |
| **2** | Builder | A safe, well-equipped base |
| **3** | Farmer / cook | A steady food supply for every run |
| **4** | Delver / crafter | Gear, dungeon loot, and progress |

Agree on roles in session one — four people planting seeds while nobody mines is the classic couch-co-op failure.

## Tips for Split-Screen Play

1. **Tune the run to the group** — world, character, and difficulty customization (confirmed Feb 2026) makes the game playable for kids and newcomers
2. **Build the shelter as a party** — the base is everyone's resupply depot; building together is the tutorial
3. **Farm early, together** — food sustains dungeon runs; a family that farms together survives the dungeon
4. **Explore split, meet at the shrines** — hidden **Journey Shrines** (fast travel, confirmed) let the party fan out and regroup
5. **Take turns on the dungeon** — the dungeon is the risk layer; in a family game, let the delver lead and others support
6. **Play the demo first** — split-screen is free in the demo right now; test the setup before EA
