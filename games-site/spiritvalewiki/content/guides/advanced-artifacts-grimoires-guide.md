# SpiritVale Advanced Artifacts & Grimoires Guide — Box of Mastery, Masterwork Cores, and the 20-Core Recipe

> **Last verified: October 24, 2026 — SpiritVale 0.34.2.**

**You finished a four-piece artifact set, hit the level 150 maps, and your damage stopped moving.** That is the point where most players conclude the gear curve is over. It is not — SpiritVale added a second artifact tier in **0.32.0** on September 21, 2026, and the game explains almost none of it. There is no quest, no marker, and the only NPC who tells you the recipe is the class master you probably have not visited since advancing.

This guide covers the whole loop: what an advanced artifact is, where the boxes actually come from, when to dismantle one for a **Masterwork Core**, and how the **Advanced Grimoire** recipe consumes them. It also separates what the official patch notes confirm from what only the community database currently supports.

---

## 1. What counts as an "advanced" artifact

The 0.32.0 announcement is precise about the pool and vague about everything else: an Advanced Artifact Box contains **a random artifact out of 32 (8 sets)**. The community database fills in the names and the piece structure.

| Set | Pieces recorded | Status |
|-----|-----------------|--------|
| Deadeye | Four-piece set | Name confirmed by database; no official class mapping |
| Umbral Veil | Four-piece set | Same |
| Manifold | Four-piece set | Same |
| Arcane Elementalist | Four-piece set | Same |
| Aegis Light | Rune, Jewel, Scroll, Relic | Four pieces confirmed by a live recipe (Paladin grimoire) |
| Sanctum Grace | Four-piece set | Name confirmed by database |
| Bloodfury | Four-piece set | Name confirmed by database |
| Gravebound | Four-piece set | Name confirmed by database |

Eight sets × four slots is the 32 the patch notes mention. The Aegis Light four-piece requirement is confirmed by an actual craftable recipe; for the other seven sets, the four-piece shape comes from the community database and should be treated as **[Unconfirmed]** until you open the class master's recipe screen.

**Do not look for a tier list yet.** Neither the official announcement nor the database maps the eight sets to classes, damage types, or BiS slots. Check the item tooltip and your class master's recipe instead.

---

## 2. Where the boxes come from

The item is called the **Box of Mastery** in the 0.33.0 patch notes and the **Advanced Artifact Box** in the 0.32.0 announcement. The community database lists its internal name as **"Artifact Box Advanced"** and its contents as exactly the eight sets above — strong evidence that both names refer to the same item. One third-party guide argues they are separate items, so verify the name on the tooltip before you spend currency. **[Unconfirmed]**

There are two guaranteed routes to a box, and both are currencies rather than gold:

| Route | Cost | Where | Source |
|-------|------|-------|--------|
| Echoing Spire | 25 Umbral Fragments | Spire crafting, Lv 146–155 | Community database |
| PvP Lobby | 25 Valor Crests | PvP Lobby | Community database |

The 0.32.0 notes themselves list "25 Umbral Fragments" next to the box, which matches the Spire recipe. If you already run Conquest, the Valor route is the lower-variance option: 25 Crests is a fixed price, while 25 Umbral Fragments means repeated tower clears.

Boxes also drop directly. The community database records 116 monster sources; the official 0.33.0 notes summarise the field rates by map rank:

| Source | Drop rate | Notes |
|--------|-----------|-------|
| Echo Master bosses (8 of them) | 3% | Highest recorded rate; also drop Corrupted Cores at 1% |
| Cosmic Entity, Orc Warchief, Suphara, Turtle Champion | 2.5% | World-boss tier |
| Abyss Archon, Wraith King | 2% | |
| Demon Lord, Ice Titan, Kraken | 1.5% | |
| Echo map trash monsters | 0.3% | Dark Fortress / Dark Manor tier |
| S-rank maps (Dark Fortress, Dark Manor) | 0.3% | Official 0.33.0 summary |
| A-rank maps (Night Garden, Warcamp, Forge, Nexus) | 0.25% | Official 0.33.0 summary |
| B-rank map (Abyss) | 0.2% | Official 0.33.0 summary |
| C-rank maps (Maw, Sunken, Starfall) | 0.15% | Official 0.33.0 summary |

The rates changed once already. 0.32.0 originally listed **0.1% on A- and S-rank maps**; 0.33.0 explicitly buffed field farming to the 0.25% and 0.3% figures above. There is no documented pity system, selector, or guaranteed set, and a 0.3% rate is not a promised one-in-333 schedule.

## 3. Masterwork Cores: the dismantle decision

Every advanced artifact is also currency. Dismantling one yields **one Masterwork Core**, and the artifact is consumed. Cores are then spent in two separate places:

- **Refining an advanced artifact** requires a Masterwork Core plus the existing refinement material, and the Core is consumed on success.
- **Crafting an Advanced Grimoire** requires **20 Masterwork Cores**.

That creates the mistake almost everyone makes: dismantling a set piece for a Core before reading the recipe, then discovering that the recipe wanted that exact piece.

The safe order is always recipe first, dismantle second:

1. Open your advanced class master's recipe list and write down the exact set name and the four pieces it requires.
2. Bank those pieces, even if their current stats look worse than what you wear.
3. Dismantle only duplicates and off-set pieces.
4. Refine only after the grimoire is crafted — refinement and the recipe compete for the same Cores.

If you are starting from zero, a grimoire costs **20 destroyed advanced artifacts**, each of which came from a random box that could roll any of eight sets. Do not budget from a handful of boxes; the set is not selectable and the notes publish no expected-value figure.

## 4. Crafting an Advanced Grimoire

Advanced Grimoires are the class-locked passive slot added with the same patch. The recipe is short, but every part of it is exact:

| Step | Requirement | Confirmed by |
|------|-------------|--------------|
| 1 | Be on the advanced class the grimoire belongs to | Community recipe entry (Paladin example) |
| 2 | Go to that class's master / crafter | Official 0.32.0 announcement |
| 3 | Bring all four pieces of the **exact** named set | Community database; official says "matching artifact set" |
| 4 | Bring **20 Masterwork Cores** | Official 0.33.0 (reduced from 25) |
| 5 | Bring **1 Corrupted Core** | Official 0.32.0 |
| 6 | Craft — the result is **account bound** | Official 0.32.0 |

The concrete example is **Crushing Advance**, a Paladin grimoire: all four **Aegis Light** pieces (Rune, Jewel, Scroll, Relic) plus 20 Masterwork Cores and 1 Corrupted Core. It is account bound, restricted to Paladin, and grants an autocast on charge with +1% melee, ranged, and magic damage, +25 block, and +25% movement speed. Those numbers come from the community database, not the patch notes.

Two binding rules get confused constantly. Older grimoires were changed to **character bound** in the 0.31.0 Dark Fortress update. New **advanced** grimoires are **account bound**. They are different item types, so do not assume an old grimoire can be moved the same way.

The database currently lists **75 advanced grimoires** against 39 base grimoires. A complete recipe table does not exist in any official post we could reach; the class master's own recipe screen is the authority.

## 5. The two bottleneck materials

### Corrupted Cores

| Source | Rate |
|--------|------|
| Eight Echo Master bosses (Lv 150–155) | 1% each |
| Echo map monsters (Lv 145–150) | 0.1% each |

That is the full 23-source table in the community database. The same material is used by 22 gear recipes — Dusk armor, Dusk weapons, and Perfect Wing Ears — so if you are also crafting Dusk gear you are competing with yourself. Bank the first Corrupted Core you see; do not spend it on a Dusk piece the week before your grimoire is ready.

### Umbral Fragments

Umbral Fragments come from clearing tower floors, and the yield rises with depth:

| Floor band | Fragments per clear |
|------------|---------------------|
| F1–49 | +1 |
| F50–74 | +2 |
| F75–99 | +3 |
| F100+ | +5 |

At F100+, five clears' worth of fragments buys one box (5 × 5 = 25). At F50–74 it takes roughly thirteen clears. This is the strongest argument for pushing depth rather than farming the entrance.

Two recent patches made that easier. **0.33.0** allows up to three mid-run party invites and stops disconnecting players who idle at the Spire entrance. **0.34.2** cut the Memory cost of Spire Compasses and Boss Lures from 20 to 10, and reduced monster damage in A-, B-, and C-rank maps. The 0.32.0 rework also made every party member carry a Compass, stopped Compass costs from rising per craft, and added a storage NPC on boss floors — so you can bank drops mid-run instead of leaving.

## 6. A practical order of operations

1. Pick the grimoire before you pick the farm. The recipe decides which set you are allowed to keep.
2. Run the Echoing Spire for Umbral Fragments, or queue Conquest for Valor Crests if you prefer a fixed price.
3. Kill Echo Master bosses when they are up — 3% boxes and 1% Corrupted Cores in the same kill is the best combined rate in the game.
4. Keep every piece of your target set, even duplicates of the same slot; dismantle everything else.
5. Stop refining advanced artifacts until the grimoire is crafted.
6. Craft at the class master, then refine with the remaining Cores.

## 7. Common mistakes

| Mistake | Why it costs you |
|---------|------------------|
| Dismantling before reading the recipe | The piece may be one of the four the recipe requires |
| Assuming any set can substitute | No generic substitution is documented; the recipe names an exact set |
| Treating 20 Cores as the whole cost | Refinement consumes Cores separately, on success |
| Farming the Spire entrance | F100+ yields five times the fragments per clear |
| Spending the first Corrupted Core on Dusk gear | 22 gear recipes compete with the grimoire for the same material |
| Confusing old and new grimoire binding | Old = character bound; advanced = account bound |

## 8. What we could not confirm

- **Set-to-class mapping and set bonuses for all eight sets.** Only Aegis Light is confirmed through a live recipe.
- **Whether "Advanced Artifact Box" and "Box of Mastery" are the same item.** The database's internal name and contents say yes; one third-party guide says no.
- **The exact Core quantity per refinement attempt.** The official notes say "a Masterwork Core" (singular); the UI may scale by item or refine level.
- **Any pity timer or guaranteed-drop schedule.** None is documented.
- **A complete Advanced Grimoire recipe table.** The class master screen is the only complete source we could verify.

If your recipe screen disagrees with anything above, trust the screen and the patch notes over this page — and tell us, so we can correct it.

## FAQ

**Can I choose which of the eight sets the box gives me?**
No. The announcement describes a random pool, and no selector is documented.

**Is a Masterwork Core tradable?**
The database does not establish a market restriction. Check the item tooltip before planning to buy your way to 20 Cores.

**Do advanced grimoires replace my old grimoires?**
They occupy the class-locked grimoire slot system, but the binding differs: old grimoires are character bound, advanced ones are account bound. Check both labels in game.

**Is the grind worth it?**
Only if your class's grimoire fixes a problem you actually have. Read the effect before farming 20 Cores.
