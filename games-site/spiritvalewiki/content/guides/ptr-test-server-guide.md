# SpiritVale PTR Guide — How to Join the Public Test Server and What's on It Now

**SpiritVale EA / Updated: September 13, 2026**

SpiritVale's developers test their patches in public before those patches reach live servers. That test build is the **PTR** — a Steam beta branch named `publictest` that anyone who owns the game can switch on in four clicks. It is where the auction house rework was validated in early August, and as of September 13, 2026 it is running the two systems the game has been promising since spring: **Advanced Artifacts and Grimoires**.

Here is what the PTR is, the exact opt-in steps, what it does and does not do to your characters, and how the go-live decision actually gets made.

---

## 1. Why SpiritVale Has a PTR

The testing server was not part of the original plan. It was a reaction to a rough launch. The developer's own explanation, posted July 31, 2026:

> "We have made a lot of changes related with items, in order to make sure we don't do silly mistakes we created PTR, our testing server."

Two days later the same reasoning was put more bluntly: a PTR server "has been created to help test things before going live (especially since past few patches have broke the game)."

That is the whole purpose of the branch. Live patches in SpiritVale's first months had a habit of shipping new problems — the trade shutdown, item loss, disconnects — so item and economy changes now get a public rehearsal first. The developer's stated goal is "to keep transparency for upcoming changes and what we been working on" and to "deliver more stable updates to the live servers."

## 2. The Four Ground Rules

Before you opt in, know what you are opting into. All four come from the July 31 announcement, in the developer's own wording:

| Rule | What it means |
|---|---|
| **Not live progression** | The PTR is "NOT LIVE SERVER" progression — it does not touch your live account's progress |
| **Character copies** | You get "a version of your characters for testing" |
| **Progression can be reset** | The devs may "reset/change" PTR progression at any time |
| **No connection to live** | "There is no connection to live servers" |

In practice the PTR is a sandbox. You cannot lose live progress by testing on it, and you cannot gain any either.

## 3. How to Join

The steps are identical in the July 31 and September 10 announcements — the process has not changed in six weeks:

1. Right-click **SpiritVale** in your Steam library
2. Open **Properties**
3. Open **Game Versions & Betas**
4. Select **`publictest`**
5. Launch the game and join the test server

This is a Steam branch switch, not a second install and not a second purchase — the same game files, a different build. To return to live, go back to the same menu and drop the beta selection. The announcements do not spell the return trip out; that is simply how Steam beta branches behave.

## 4. What's on the PTR Right Now

As of September 13, 2026, the test build includes **Advanced Artifacts and Grimoires**, per the September 10 announcement. Two details matter for anyone testing it:

- **The test items are handed to you.** The announcement states that "all advanced artifacts and grimoires will be in Nevaris closer to the center," so you can inspect the new systems without farming them first.
- **The notes live on Discord, not Steam.** The September 10 post links both its patch notes and a dedicated **PTR Bugs Reports** channel to the official Discord. The Steam store page names that same Discord as the studio's channel for bug reports, suggestions and roadmap input.

That post also says the test "will run until next weekend," so the current build is a short, time-boxed window rather than a permanent state of the game. The PTR branch is permanent; its contents are not.

## 5. How Long Until PTR Changes Go Live

The developer answered this one directly:

> "While we have the final say, it will depend on PTR players, if most players are happy with the stability, we will push them live. Could be fast, could take a bit depending on what we find."

So a PTR build is not a preview with a calendar date attached. It goes live when testers stop finding problems with it. The one completed example ran fast: the PTR opened July 31 with item trading, guild storage and the auction house, and the tested patch reached live servers on **August 4, 2026** — the auction house returning under a 5% seller tax and a 30-listing cap.

That is the trade you make by testing. You see content early, and your bug reports are what decide when everyone else sees it.

## 6. Why This Test Matters More Than the Last One

Advanced Artifacts and Grimoires are not a new idea. They were originally slated for the Echoing Spire update (0.17.0, May 24, 2026) and were cut from it. The official notes for that update shipped **base-class Grimoires only**, with the Advanced Class Grimoires and their Artifact Sets explicitly delayed because designing and balancing them was taking longer than expected.

Since then the pair has been a standing item in the studio's own update posts: named as work in progress on August 2, listed among features planned for the next major update on August 17, and now finally running on the test build. No official post gives them a release date. An expanded artifact and Grimoire system ships when this PTR round says it is ready.

How base-class Grimoires currently work — the three class-locked slots and the Box of Origin / Box of Mastery trade-ins — is already documented in the [Artifact Sets Guide](/guides/artifact-sets-guide). This page is about getting into the test build, not re-explaining the systems themselves.

## 7. Reporting a Bug So It Actually Gets Fixed

The PTR only pays off if testers file reports. Two habits make the difference:

1. **Use the right channel.** Bugs found on the PTR go to the Discord's **PTR Bugs Reports** thread linked in the September 10 announcement — not to Steam reviews, and not to general chat.
2. **Include the details support always asks for.** The same character / server / time-of-incident trio that the [Connection & Server Guide](/guides/connection-server-guide) recommends for live server reports is what makes a PTR report reproducible.

## 8. What the PTR Is Not

- **Not a progression shortcut.** Nothing you do there carries back to live.
- **Not a stable build.** It is an early build of an early access game, and the developer wanted "a bit more internal/PTR testing" before shipping the last patch. Crashes or a progression reset on the PTR are the system working as designed, not a bug you need to report.
- **Not a faster support queue.** If your live character is restricted or your trade access is locked, the PTR will not help — the [Account Ban Appeal Guide](/guides/account-ban-appeal-guide) covers that path.

## 9. Should You Opt In?

Opt in if you want to see Advanced Artifacts and Grimoires before they ship, or if you want a say in how soon they ship — the go-live decision rests on tester feedback, so testing is the lever. Skip it if you only play for live progression, or if a build that can be reset mid-session would frustrate you more than it informs you.
