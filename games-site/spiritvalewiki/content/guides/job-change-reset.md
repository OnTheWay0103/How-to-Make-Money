## Overview

SpiritVale allows you to change your class, reset skills, and reallocate stats — but it's not free. This guide covers every respec option, costs, and when it's worth doing.

## How to Change Job/Class

### Basic Class Change
1. Visit the **Class Guild Hall** in any major city
2. Talk to the **Class Master NPC**
3. Select "Change Class" from the dialogue
4. Choose your new class from the available options

### Requirements
- Character level 15+ to unlock class changing
- First class change is **free**
- Subsequent changes cost **10,000 gold** per change
- Your gear and inventory are preserved when changing classes

### Advanced Class Unlock
Advanced classes require completing a quest chain:
1. Reach level 30 with the base class
2. Complete the "Path of Mastery" quest from the Class Master
3. Defeat the class-specific trial boss
4. Return to unlock the advanced class

## How to Reset Skills

### Skill Point Reset
1. Visit any **Skill Trainer NPC** (marked with a book icon on the map)
2. Select "Reset Skills"
3. Pay the fee (scales with level)

| Level Range | Reset Cost |
|-------------|-----------|
| 1-20 | 1,000 gold |
| 21-35 | 5,000 gold |
| 36-45 | 15,000 gold |
| 46-50 | 30,000 gold |

### Free Respec Items
- **Tear of Clarity**: Rare drop from world bosses, grants one free skill reset
- **New Player Gift**: First character on an account gets one free respec at level 30
- **Balance Patches**: Major class balance changes sometimes come with a free respec

## How to Reset Stats

1. Visit the **Stat Trainer NPC** (near the Skill Trainer)
2. Select "Reallocate Stats"
3. Cost is the same as skill reset (scales with level)
4. All stat points are refunded for redistribution

### Recommended Stat Allocation
| Class | Primary Stat | Secondary |
|-------|-------------|-----------|
| Knight | VIT (Vitality) | STR |
| Paladin | STR + WIS | VIT |
| Priest | WIS (Wisdom) | VIT |
| Shinobi | DEX (Dexterity) | STR |

## How to Change Stance

Stances are combat styles within a class. To change:
1. Open your **Skills menu** (K)
2. Click the **Stance** tab
3. Select a new stance (must be unlocked first)
4. Stances can be swapped freely outside of combat

Stances are unlocked through class quests and leveling, not purchased.

## When Should You Respec?

### Good Times to Respec
- Hitting level 50 and optimizing for endgame
- Switching from solo leveling build to group/raid build
- After major game balance patches
- When joining a guild that needs a specific role

### Don't Respec For
- Minor skill point adjustments (wait until you have more points)
- Testing builds (use the Class Trainer's preview mode instead)
- Temporary content (use your free first respec wisely)
