# Demon Bluff Release Date, Platforms and Price

Demon Bluff is scheduled for **November 2026** on Steam. That is the whole date: Valve's data returns `coming_soon: true` with the string "November 2026" and no day of the month, and no price at all as of 29 October 2026. It is listed for Windows, macOS and Linux.

If you are deciding whether to wait for it, the useful part is not the window — it is everything Valve has already locked down: platforms, languages, system requirements and Steam features. Those are final enough to plan around. The day, the price and every console port are not.

## What the release date actually says

The store page has carried "November 2026" for months. There is no countdown, no pre-order, and no "coming soon" date with a day attached. When a Steam page shows a bare month with `coming_soon: true`, the developer has told Valve the window but not the day, and Valve renders it exactly that way.

Two things follow from that:

- **Any "confirmed" day you see elsewhere is wrong until the Steam page changes.** Media outlets routinely convert a month into a plausible date for their article templates. The store page is the only source that updates when the studio actually commits.
- **A month-level window can still slip.** Studios hold `coming_soon: true` until certification and final builds are done. Nothing about the current listing guarantees 30 November over 1 November, and nothing guarantees November over December.

We will update this page the moment the day appears. Until then, treat the release date as a one-month range.

## Platforms: PC, Mac and Linux

The store data returns three platform flags, and all three are true:

| Platform | Status | Source |
|---|---|---|
| Windows | Listed, with published minimum specs | Steam appdetails, 2026-10-29 |
| macOS | Flagged as supported, **with a published caveat** — the store page carries the notice "This product is not compatible with macOS 10.15 Catalina or above" | Steam appdetails + store page, 2026-10-29 |
| Linux | Listed as supported; no separate spec block published | Steam appdetails, 2026-10-29 |

Mac users should read that caveat before anything else on this page. Valve's platform flag is true, but the same store page tells you the build does not support Catalina or newer — which is most Macs in use today. A `mac: true` flag combined with a "not compatible above 10.15" notice is not a working macOS release; it is a legacy build. Treat macOS as unsupported in practice until the studio says otherwise.

Linux has no such warning, but also no published requirements. For a 2D card game with a 500 MB install the bar is low — but "low" is our reading, not a published figure.

## Is there a PS5, Switch or mobile version?

No. There is no PlayStation, Xbox, Switch or mobile listing for Demon Bluff, and nothing on the Steam page mentions a console or phone release.

This matters because the search suggestions around the game are full of platform guesses — `demon bluff ps5`, `demon bluff switch`, `demon bluff mobile`, `demon bluff mobile release date`. Those queries exist because people assume a card game this small must be on everything. It is not, as of 29 October 2026. If a console version is announced, it will almost certainly appear on the same Steam news feed first, because the studio's announcements already run through it.

## Price: not announced yet

Valve's API returns `price_overview: null`. That is not an error — it is what an unreleased game with no pre-order page returns. There is no wishlist discount, no pre-purchase bundle, and no listed base price.

What we can say without guessing: the game is a paid title, not free-to-play (`is_free: false`). Anyone quoting a specific dollar amount today is extrapolating from comparable roguelite deckbuilders, not from Valve's data. A price usually appears on the store page when pre-orders open, which for a November window would be weeks rather than months out — but that is a pattern across Steam, not an announcement for this game.

**Is Demon Bluff free?** No. It is a paid single-player game with no announced price.

## Demo status

There **is** a free demo, and it has been live since **27 May 2026**. It is a separate Steam app (3803820), installs independently of the full game, and carries no purchase requirement.

The demo is not a teaser: the studio's May 2026 post describes 40+ villager cards and nine Relics, against 100+ collectible cards at release. Most footage and writing about Demon Bluff today — including this site's mechanics pages — reflects that build.

One caveat worth knowing before you read patch-sensitive pages: the main game's page data shows no scheduled playtest, so the demo is the only current build. Whether it receives the same updates as the release build is not announced. The [demo and ascension guide](/guides/demo-and-ascension) covers what is in it and how the ladder works.

## Languages at launch

**Twelve** languages are listed on the main store page today, which is unusually generous for an indie deckbuilder:

English (with full audio), French, German, Italian, Spanish (Spain), Polish, Russian, Japanese, Korean, Portuguese (Brazil), Simplified Chinese and Traditional Chinese.

The studio's own demo post from May 2026 says **13 languages on release** and names Turkish, which is not on the main store page but does appear on the demo's listing. Accurate wording: twelve listed, thirteen planned, Turkish the odd one out.

Only English carries the full-audio asterisk. The other eleven are interface and subtitle support. If you are playing in a non-English locale, the deduction wording is the thing to watch: this is a game about parsing sentences for lies, so a loose translation changes difficulty more than it would in an action game.

## System requirements

Valve lists one requirement block, for Windows:

- **OS:** Windows 7, 8/8.1, 10 or 11
- **Processor:** "Anything, really" — the studio's own wording, not ours
- **Memory:** 2 GB RAM
- **Graphics:** NVIDIA GeForce 840M
- **Storage:** 500 MB available space

The processor line is the studio being honest about a 2D card game, and the 840M is a 2013-era laptop GPU. Anything that boots Windows 10 will run this. The 500 MB install size also means the game is not shipping large video or high-resolution art assets — relevant if you were expecting animated card art on the scale of a bigger production.

## Steam features

The categories Valve returns are: Single-player, Steam Achievements, Steam Cloud, Stats and Family Sharing.

- **Achievements and Stats** are both on, which means there is a public per-achievement global percentage feed. We use that feed for progression guides as soon as the game launches.
- **Steam Cloud** means your run history and unlocks follow your account between machines.
- **Family Sharing** is enabled, so a household can share one copy.
- There is **no Steam Workshop** and no trading cards category listed pre-launch.

## Is Demon Bluff multiplayer?

No. The store categories list Single-player and nothing else, and the store description calls it "this single-player social deduction game". The "social" part is the puzzle — you are deducing which cards are lying to you — not other players. `demon bluff demo online` and `demon bluff game online` are answered the same way: there is no online mode, no co-op and no separate server.

The honest framing: reviews at launch will be the first real signal about whether the deduction loop holds up over dozens of runs, and that is the one thing a pre-release guide cannot tell you. What we can tell you is what the systems do, which is what the rest of this site covers.

## What you actually do in Demon Bluff

The store description is unusually direct, so here it is in its own words: "demons have infiltrated your village and disguised themselves as allies. Every card you turn over is either a friend or a foe."

Concretely, each character is a card. Villager and Outcast cards give you information and abilities that help you identify the disguised Demons and Minions; the Demons and Minions feed you false information. You investigate a corrupted village across a run, gather claims from each character, and try to work out which claims contradict each other before you commit to a kill. It is a deduction puzzle wearing a roguelite deckbuilder's clothes.

The store page also confirms the mode structure: multi-village runs with a randomised pool, a **Deckbuilding mode** where you draft your own deck, an **endless mode**, and **challenges**. Card collection runs past 100 characters, with cosmetic unlocks layered on top.
