# Anomaly President Controls & Settings Guide — Set Up Your Campaign

Anomaly President is a fast action game at night, which means **controls decide whether the combat loop feels good**.
Reviewers consistently describe the movement as responsive and the parry as the make-or-break input. This guide collects
what is confirmed about the control scheme and settings, what is still unconfirmed, and how to set the game up on PC or
Steam Deck.

One honest caveat up front: Phew Phew Games has not published a full keyboard layout in any source we can verify, so the
**exact key for each action is [Unconfirmed]** as of the September 2026 Early Access build. The *actions* below are
confirmed from reviewer hands-on coverage; the *keys* are checked in-game via Options → Controls.

## The Confirmed Move Set

Reviewers across the board describe the same core actions [Respawning, Community]:

| Action | What it does | Status |
|--------|--------------|--------|
| **Move** | 2D side-scrolling movement with "slightly weighty but tight and responsive" feel | Confirmed |
| **Jump** | Vertical movement and aerial attacks (jump-kick attacks were patched in v0.5.0.13) | Confirmed |
| **Dodge / dash** | Evasive roll or dash; the main defensive answer to red (unblockable) attacks | Confirmed |
| **Parry** | Timed block that opens enemies up; central to the swordmaster build | Confirmed |
| **Main weapon attack** | Your primary melee action | Confirmed |
| **Secondary weapon attack** | Attacks with your second carried weapon | Confirmed |
| **Special / anomaly abilities** | Anomaly Powers and run-granted abilities | Confirmed |
| **Finisher** | Instant kill on an enemy whose **stamina** bar you break | Confirmed |

The **enemy stamina system** matters for controls: every enemy has health *and* stamina, and once you break the stamina
bar you can trigger an instant finisher [Respawning, Community]. That means part of "learning the controls" is learning
to recognise when a finisher is available instead of continuing to mash attacks.

## Yellow vs Red Attack Indicators

Enemy telegraphed attacks are colour-coded, and reading the colours is a control skill in itself [Respawning, Community]:

- **Yellow** — blockable. This is what the parry is for.
- **Red** — unblockable. Do not try to parry; dodge or reposition instead.

If the parry timing is giving you trouble, the fix is usually on the input side: wait for the **yellow** flash and press
parry as the attack is about to land, not when the enemy winds up. See the [combat tips guide](/guides/combat-tips-guide)
for the timing discussion in depth.

## Does Anomaly President Have Keyboard Rebinding?

The Steam store page lists **Keyboard + Mouse** as the required input method, and the game is Windows-first [Official].
However, we could not confirm a full default key list or the presence of a full rebinding menu from any public source at
the time of writing. Treat the following as **[Unconfirmed]** until you open Options → Controls in-game:

- The exact default keys for parry, dodge, and each weapon slot.
- Whether every action can be rebound (patch notes mention a **"Special Attack at Combo End"** input that had a bug fixed
  in v0.5.0.17, which implies combo-end specials use a dedicated input).

If rebinding matters to you, the safest assumption is that the game supports the actions above with a keyboard/mouse
scheme and **controller input** (see below), and that granular rebinding should be verified in the current build.

## Controller Support

Controller support is confirmed, but it had a rocky start that is worth knowing:

- **Demo era:** the first demo hotfix **disabled Steam Input** to fix a controller configuration bug and "double input"
  issue [Official patch note, Community]. If you played the demo with a controller and hit double-inputs, that specific
  bug was addressed.
- **Post-launch:** patch v0.5.0.13 (August 11) changed the controller input for returning to the bus from the World Map
  to **D-pad Down** [Official patch note, Community] — evidence that controller navigation is actively maintained.
- **Steam Deck:** N-Gamz's French Steam Deck test reports controller controls as **"excellent"** and the game stable on
  Deck LCD, with only occasional slowdowns in dense crowds [Community]. Virtual Grip and Behind Gaming also report a
  native-console feel. **One counterpoint:** Steam Deck HQ's August 18 review reported the game as *not* stable on Deck
  [Community]. Treat Deck stability as patch-dependent in Early Access.

## Display and Settings You Can Change

Published patch notes reveal a few real settings that exist in the current build [Official]:

- **Display mode** — new save files now default to **Borderless** (changed in v0.5.0.16, August 14). Borderless is
  usually the best choice on a single monitor.
- **Windowed / fullscreen** options exist alongside borderless (implied by the borderless default note).
- **Audio and video sliders** — not documented in detail in public sources; treat granular graphics options as
  [Unconfirmed].

What you will **not** find in Early Access settings, per reviewer consensus: **no difficulty options** as of launch
[Community]. Multiple critics flagged the missing difficulty setting as a gap for accessibility. That could
change in an update; the [patch notes & roadmap guide](/guides/patch-notes-roadmap-guide) tracks settings-related changes
as they ship.

## Setting Up for Steam Deck

If you play on Deck, the confirmed baseline is:

1. **Controller scheme** — the game maps cleanly to a gamepad per N-Gamz; use the default layout first and only remap
   (via Steam Input) if a specific action feels off.
2. **Verify before assuming Verified** — several outlets call the game **Steam Deck Verified**, while Steam Deck HQ
   reported instability in mid-August. The practical move: test the first two runs on Deck, watch for slowdowns in dense
   crowd phases, and check the newest patch before trusting an old review.
3. **Performance expectations** — reviewers describe the pixel-art as perfectly readable on the 7-inch screen with
   reasonable battery drain, so no special TDP tweaks are reported as necessary [N-Gamz, Community].
