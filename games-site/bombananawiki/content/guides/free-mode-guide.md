# Free Mode / Custom Bomb Editor

Every game needs a sandbox. In BOMBANANA!, the mode is officially called **Custom** on the Steam store page — the community calls it **Free Mode**. Either name, it is the feature that lets players **design their own bombs** to test how much their friends trust each other.

The store page describes it this way [Official]:

> "Players create their own challenge by adjusting bomb difficulty, the timer, module types, environmental hazards, and how many mistakes are allowed."

## What You Can Adjust

The Custom / Free Mode editor exposes five confirmed dials [Official]:

| Dial | What it controls |
|------|------------------|
| **Bomb difficulty** | Overall complexity of the bomb's modules and their rules. |
| **Timer** | How much time your team gets before the bomb detonates. |
| **Module types** | Which modules appear on the bomb — pull from the module set (wires, numpad, switch panels, and more) [Community]. |
| **Environmental hazards** | In-game chaos: power outages, obstructions, and loud interruptions [Official]. |
| **Mistakes allowed** | How many wrong inputs the team can make before the bomb punishes you. |

## What Free Mode Is For

### 1. Training a specific module
If your team keeps dying on **switch panels**, build a bomb with switch panels, a generous timer, and more mistakes allowed. Practice the callout: *"Switches, top row. Light order is red, green, blue, yellow. Digit string is 8972. Waiting for switch states before enter."* [Community]

### 2. Breaking in a new Mute Monkey
The hardest role deserves a gentle arena. Build a wires-only bomb with a long timer so your new Mute can practice page-finding and gesture translation without pressure.

### 3. Pure chaos with friends
Crank the timer down, add environmental hazards, allow zero mistakes, and throw in the nastiest modules. That is the "test how much your friends trust each other" setting.

### 4. Rehearsing hazard conditions
Power outages and loud interruptions change how the team communicates. Free Mode lets you practice those conditions before they appear in Campaign levels [Official].

## How to Design a Good Training Bomb

These are editorial suggestions grounded in how the modules work [Editorial]:

1. **One new thing at a time.** Add a new module type only when the team is comfortable with the current set. Jumping from wires to a full numpad + switch-panel + hazard bomb is a recipe for frustration.
2. **Timer last.** Dial the timer down only after the team can solve the module set comfortably with time to spare.
3. **Mistakes allowed early, strict later.** Start with a forgiving mistake limit, then remove it as the team's callout discipline improves.
4. **Hazards are a separate skill.** Power outages cut sight or sound for part of the team — practice them deliberately before they appear in a 30-level campaign [Official].

## Free Mode FAQ

**Is Free Mode in the demo?**
No. The demo does not include the Custom / Free Mode editor — it is listed as a full-game mode [Official]. The demo teaches the modules you will later mix in Free Mode [Community].

**Can I play Free Mode solo to practice?**
No. Like every mode, Free Mode requires exactly three players — the game is strictly 3-player co-op [Official].

**Does Free Mode unlock anything?**
The store page does not state that Custom-mode defusals unlock campaign levels or other content. Treat Free Mode as a sandbox, not a progression path [Unconfirmed].

**What is the difference between "Free Mode" and "Custom"?**
They are the same mode. The Steam store page calls it **Custom**; community guides and player discussion call it **Free Mode**. Both refer to the player-created bomb editor [Community].
