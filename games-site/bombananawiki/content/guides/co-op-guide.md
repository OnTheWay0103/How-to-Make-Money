# Co-op & Invites Guide

BOMBANANA! is **exactly-three-player online co-op** — "no more, no less" [Official]. The whole game is built around three monkeys, three roles, and one shared timer. This guide covers how to get your trio into the same lobby, from inviting friends to matchmaking a third.

## The Three-Player Rule

- **Exactly 3 players required.** There is no solo and no two-player mode [Official].
- Each of the three roles (Blind, Deaf, Mute) is **unique and cannot be repeated** — you cannot have two Mute monkeys [Community].
- The game is **Online Co-op on Steam**; all players need a Steam account and the same version of the game (or the demo, for the demo build) [Official].

## How to Invite Friends (Demo-Verified Flow)

The invite flow below comes from demo play reporting. The full release lobby may differ slightly, but the core flow is expected to hold [Community]:

1. **One player hosts.** Launch BOMBANANA! and select **Online Co-op**.
2. **Create a room.** Choose the difficulty and whether to allow **public matchmaking** (turn this off for a friends-only game).
3. **Open the invite list.** In the room waiting screen, click the **Invite Friends** button (commonly top-right of the room interface).
4. **Pick two online friends.** Select up to two online Steam friends and send the invites.
5. **Friends accept.** They accept via the Steam pop-up or in-game notification.
6. **Pick roles and ready up.** All three choose their roles (Blind / Deaf / Mute Monkey), click **Ready**, and the host starts the game.

## Backup: Steam Overlay Invite

If the in-game invite is not working, use Steam's own invite:

1. The host creates the room as above.
2. Press **Shift+Tab** to open the Steam overlay.
3. Open the friends list, right-click an online friend, and select **Invite to Game**.
4. The friend accepts the Steam invite and joins the room.

This is the classic Steam backup path and works in most Steam online co-op titles [Community].

## Matchmaking a Third Player

If you only have two friends (or one friend and a stranger):

- The host can **enable public matchmaking** when creating the room, and Steam matchmaking can fill the third slot [Community].
- Note that the official store description says exactly three monkeys are required — a random third player is a risk, since the game depends heavily on a shared communication style. For your first runs, prefer two trusted friends [Editorial].

## Setting Up Communication Before You Start

Getting three people into a lobby is only half the battle — getting them to actually talk is the other. Because the roles split information asymmetrically, your communication setup determines how many bombs you defuse [Community]:

1. **Decide on external voice (recommended).** The game has built-in voice chat, but the Mute Monkey cannot speak in-game, and the Deaf Monkey cannot hear anything. Running external voice (e.g., Discord) alongside the in-game gesture/emote tools lets the Deaf Monkey's relay still work if someone's mic drops. Many teams report this hybrid setup is the most reliable [Community].
2. **Assign the Deaf Monkey to the player with the clearest speech.** The Deaf Monkey is the relay bottleneck — the whole team depends on them speaking every instruction in the callout order. Put your calmest, clearest talker there [Community].
3. **Agree on gestures before the timer.** At minimum: yes, no/wrong, wait, go back, and a number sign set. This is the Mute Monkey's entire vocabulary. See the [roles guide](/guides/roles-guide) for the gesture dictionary.
4. **Set a repeat-back rule.** Make it a hard rule that nobody acts until an instruction has been repeated back once. This prevents the most common demo deaths [Community].

## Choosing a Host

The host creates the room and starts the game, so the hosting choice matters more than it does in most co-op games [Community]:

- **Host with the best connection to the other two.** In a trio where one player is far away, the two closest players should host to keep the relay snappy.
- **The host controls matchmaking.** If you want a friends-only game, turn public matchmaking off when creating the room; if you need a third, leave it on.
- **Hosts can pass the torch.** If the current host's invites keep failing, have a different player create the room instead — this resolves many demo-era invite issues [Community].

## Before You Invite: Checklist

Make sure everyone in the group has done the following, or invites may silently fail [Community]:

- **Steam is online** — nobody is in Offline or Invisible mode for the invite.
- **Steam overlay is enabled** — Steam Settings → In-Game → "Enable the Steam Overlay while in-game."
- **Same version** — everyone has the same game build (or all have the demo).
- **Voice chat set up** — the game has built-in voice chat, but because the Mute Monkey cannot speak in-game, many teams run external voice (Discord) *plus* in-game gestures [Community].

## Troubleshooting Common Issues

| Problem | Likely fix |
|---------|------------|
| **Invite not received** | Check Steam is online and the overlay is enabled. Restart Steam and the game, or have the friend right-click your name in Steam and choose "Invite to Join Game." [Community] |
| **Lag / can't join** | Close background downloads and video software. Some regions may need a network accelerator for stable Steam connections [Community]. |
| **Invite unresponsive** | Everyone exits the game, restarts Steam, and try a different host [Community]. |
| **Microphone not working** | Switch the correct microphone input device in game settings [Community]. |

## Can You Play With Bots or Two Players?

The official line is **exactly three players required** [Official]. Some community reports describe starting a round with two players and an AI filling the third role, but this is not confirmed and is described as a poor substitute for a human teammate [Unconfirmed]. For the intended experience, bring three humans.

## Cross-Play and Local Play

- **No cross-platform play** — the game is PC-only (Windows and macOS), so there is no cross-console scenario to worry about [Unconfirmed].
- **No local split-screen** has been reported; the game is online co-op via Steam [Unconfirmed].
