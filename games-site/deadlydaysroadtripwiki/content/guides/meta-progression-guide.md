# Deadly Days: Roadtrip Meta Progression Guide — 1.0

Deadly Days: Roadtrip is a roguelite, so the run is temporary and the base is permanent. Apples, upgrades, unlocks, character item stickers, and workbench features carry between runs; the backpack and level-ups do not. This guide explains every confirmed meta system in 1.0 and gives a buy order that stops new players wasting apples.

## What Carries Over — and What Does Not

| Carries over | Resets each run |
|---|---|
| Apples and purchased upgrades | Backpack contents |
| Survivor unlocks | Weapons and items found in the run |
| Character item stickers / modifiers | In-run level-ups |
| Workbench features (crafting, rerolls, banishing) | Run currency |
| Run history and leaderboard stats | Route progress |
| Memo snippets and story unlocks | Temporary buffs unless stated |

The 1.0 announcement confirms that Early Access save games carry over, including achievements. If you are returning after a break, your old meta progress should still be there, though a wave of achievement notifications on first load is expected.

## Apples: The Only Meta Currency

Apples are earned in runs and spent at the base. They are the gate on almost every permanent upgrade, including character item modifiers. The 0.19 update lowered the prices of several existing incremental upgrades, so older guides that quote prices are probably outdated.

Two rules for spending apples:

1. **Buy survivability before damage.** A run that reaches the boss with a weak build still has a chance; a run that dies on day two has none.
2. **Check the row locks.** The 0.19 update added four incremental upgrades with row-based unlocking. A cheap upgrade in a new row can unlock a better tier than an expensive upgrade in a finished row.

## Base Upgrades, in Priority Order

### Tier 1 — Survive Longer

- **Health / armor.** The most direct fix for early deaths.
- **Movement speed.** Positioning is the main defensive skill; speed supports it.
- **Loot speed.** More items per day means a stronger backpack by the boss.

These three pay off in every run, with every survivor. If you are dying before the first boss, this is where the apples go.

### Tier 2 — Build Consistency

- **Rerolls.** Rerolls turn a bad item offer into a usable one. The dice item grants more rerolls and is unlocked with any reroll at the workbench.
- **Luck.** Added in 0.19. Higher luck improves your chances by rerolling chance checks. The Lucky Clover item boosts it.
- **Radar.** The 0.22 update added a one-time unlock for an improved radar that shows the rarity of loot crates and gas canisters. It is one of the highest-value quality-of-life buys in the game.

### Tier 3 — Power and Utility

- **Damage upgrades.** Take these once you reliably reach the boss.
- **Banishing slots.** At the highest tier you can remove up to 10 items from the loot pool. Powerful, but only after you know which items you never use.
- **Character item stickers.** Each survivor's signature item can be upgraded with modifier tickers bought with apples. These persist across runs and are the closest thing to a character-level system.

Do not buy banishing in your first ten runs. You do not know the item pool well enough, and a narrow pool is worse than a slightly cluttered one.

## The Workbench Is the Meta Hub

The workbench is where most meta systems meet. Community guides report it unlocks with **tape**, which appears as loot. Once open, it supports:

- **Crafting and combining** items into stronger and legendary versions.
- **Rerolls**, including the dice unlock.
- **Item banishing**, which removes unwanted items from future loot pools.
- **Character item stickers / modifiers**, purchased with apples.

If you have not opened the workbench, you are missing a large part of the progression layer. Treat tape as a priority pickup, not junk.

## Character Item Stickers and Modifiers

The 0.19 update reworked the character selection screen. Each character's signature item can now be upgraded with modifier tickers that enhance its abilities. Upgrades are purchased with apples and **persist across runs**.

This is the closest thing the game has to a character level. A Vampire with upgraded bats is a different character from a fresh Vampire. The practical implication: once you choose a main, invest stickers into that character's item before spreading apples across the roster.

The 0.21 update also references "Character Item Modifiers" that unlock after beating a boss, so boss clears are a gate on part of this system.

## Run History and Why It Matters

The 0.19 update added a Run History panel at the base. It shows:

- Backpack contents from each run.
- Stat trends: enemies killed, items looted, level-ups, days reached.
- Enemy type breakdowns.
- Win/loss streaks per character.

Use it to diagnose, not to admire. If your runs consistently end on the same day or against the same enemy type, that is a build problem, not bad luck. If one character has a much better streak than another, that is a signal about which stickers to invest in.

## Weekly Mode

The 0.20 update added **Weekly Mode**, a rotating challenge with a leaderboard. Each week:

- A randomly selected character.
- A random scoring system (kills, peak DPS, body count, and others).
- Four modifiers chosen from a pool of nearly 30.

Weekly Mode is not the main progression path, but it is a good test of fundamentals. Because the character and modifiers are fixed, everyone competes on the same terms. A high weekly score is evidence that your backpack and route skills transfer across characters.

The 0.20.3 hotfix fixed a crash caused by Luck rerolls in Weekly Mode, so if you are returning after a break, update before you chase a score.

## MKing Response Level and the Endgame

The 0.21 update added the **MKing Response Level**. While you prepare for the Headquarters Run, this level rises and gradually increases the game's difficulty. That is a meta-system with a cost: the more you prepare, the harder normal runs become.

The Headquarters Run itself is the story climax: build a bomb, infiltrate MKing Corp, defeat the CEO, and blow up the building. Beating bosses repeatedly also drops memo snippets that fill in the backstory. Treat the response level as a difficulty dial you opt into, not a free power spike.

## The 1.0 Coffee Stand

The 1.0 update added a coffee stand to the revamped base. Brewing a coffee lets your next run start with increased movement and loot speed, and 1.0 also lengthened days slightly.

This is a small, repeatable buff. Use it before a boss attempt or a loot-heavy route, not before a run you expect to end in two minutes. It costs time at the base, so it is a deliberate choice rather than an automatic ritual.

## A Buy Order for Your First 20 Runs

1. **Health or armor** to stop early deaths.
2. **Loot speed** to improve every backpack.
3. **Workbench tape** as soon as it drops.
4. **Radar** for crate and gas rarity.
5. **One reroll source** to smooth bad item offers.
6. **Character item stickers** for your main survivor.
7. **Damage** once you reach the boss reliably.
8. **Banishing** only after you know the item pool.
9. **Luck** as a third-stat investment.
10. **Cosmetic or novelty unlocks** last.

If you follow only one rule: do not buy damage before survivability. The game's difficulty curve punishes a glass cannon long before it rewards one.

## Bottom Line

The meta layer is about removing variance: more health, more loot speed, more rerolls, a radar, and a workbench. Power comes after consistency. Apples are scarce early, so spend them on systems that help every survivor before you invest in a single character's stickers.
