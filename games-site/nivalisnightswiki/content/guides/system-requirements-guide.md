# Nivalis Nights System Requirements — PC Specs & Steam Deck

Before you open your noodle bar, make sure your PC can run the city. Here are the Nivalis Nights system requirements as listed per the official Steam store listing.

## Minimum Requirements

| Component | Requirement |
|-----------|-------------|
| OS | Windows 10/11 (64-bit) |
| Processor | AMD / Intel CPU |
| Memory | 16 GB RAM |
| Graphics | Dedicated AMD/NVIDIA GPU with at least 6 GB VRAM |
| DirectX | Version 11 |
| Network | Broadband internet connection |
| Storage | 30 GB available space |
| Sound Card | Integrated or dedicated sound card |
| Additional | Controller or keyboard + mouse |

## Recommended Requirements

| Component | Requirement |
|-----------|-------------|
| OS | Windows 10/11 (64-bit) |
| Processor | AMD / Intel CPU |
| Memory | 16 GB RAM |
| Graphics | Dedicated AMD/NVIDIA GPU with 8 GB VRAM (e.g., GTX 2070 or newer) |
| DirectX | Version 12 |
| Network | Broadband internet connection |
| Storage | 30 GB available space (SSD recommended) |
| Sound Card | Integrated or dedicated sound card |
| Additional | SSD drive, Controller or keyboard + mouse |

## Reading the Specs

### GPU — The Real Requirement
The minimum asks for a **dedicated GPU with 6 GB VRAM**; recommended is **8 GB VRAM** (GTX 2070 or newer as a reference point). Nivalis Nights is a dense, rain-soaked city with dynamic lighting — the GPU is the component that will actually determine your experience.

- **6 GB VRAM:** GTX 1660 Super/Ti, RTX 3050, RX 5600 XT-class — minimum settings territory
- **8 GB VRAM:** RTX 2070/3060/4060, RX 6600 XT-class — the recommended baseline
- **More is better:** 10–12 GB cards will comfortably exceed the recommendation for the city's weather effects and night lighting

### RAM — 16 GB Either Way
Both tiers list **16 GB RAM** — this is the hard floor. The game runs a living city (135 citizens with schedules, dynamic markets), so don't plan on 8 GB being enough even on minimum settings.

### Storage — 30 GB, SSD Recommended
30 GB of free space is required. The recommended tier calls out an **SSD** — the city streams a lot of content as you move between districts and load venues, so an SSD will noticeably cut load times and stutter.

### OS — Windows 10/11 64-bit Only
Note that the official requirements list **no macOS or Linux support** — the game is Windows PC at launch. Linux users will need to rely on Proton (community-tested after release).

## Steam Deck Compatibility

**Official status: not yet verified.** As of August 7, 2026, the Steam page has not listed a Steam Deck verification rating.

What we can infer:

- **System requirements are demanding for a handheld** — 16 GB RAM and 6 GB VRAM minimums are at the high end of what Deck hardware provides.
- **Controls:** the requirements mention "Controller or keyboard + mouse," so controller support is expected.
- **Reality check:** expect Steam Deck to run the game at reduced settings and frame rates, if at all — we'll publish verified Deck settings after launch once the game is tested on hardware.

If Steam Deck performance matters to you, wait for community tests after September 29 before assuming it'll run well.

## Performance Tips (Pre-Launch Planning)

- **Install on an SSD** even if your system only meets minimum specs — the biggest cheap upgrade for this game.
- **Close background apps** — 16 GB RAM is the floor, not headroom; browsers and Discord eat into it fast.
- **Update GPU drivers** before launch day — Nivalis Nights will ship with day-one driver support from NVIDIA and AMD.
- **Check your Windows version** — Windows 10/11 64-bit required; older Windows versions won't run it.

## Will My PC Run It? Quick Checklist

- ✅ Windows 10/11 64-bit
- ✅ 16 GB RAM or more
- ✅ Dedicated GPU with 6 GB+ VRAM (8 GB+ for recommended)
- ✅ 30 GB free storage (SSD for best experience)
- ✅ DirectX 11 or 12

If you hit all five, you're ready for launch day on **September 29, 2026**.
