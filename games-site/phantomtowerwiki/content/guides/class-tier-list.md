# Phantom Tower Class Tier List — The Honest Version (Early Access)

Ask "what is the best class in Phantom Tower?" and most answers will tell you confidently about classes the developer has never named. This is the honest version: a tier list built only on the confirmed class descriptions, with reasoning you can check, for the four classes that actually exist in the official record.

## Why This List Is Different (Read This First)

Phantom Tower launches with **8 classes**, per official press materials. Only **four are named**: Warrior, Mage, Archer, and Assassin. There are no published class stats, damage numbers, or difficulty ratings.

That means this list is **not a measurement of performance** — no one has official data to measure. It is a ranking of what the confirmed class descriptions imply: how much each class has going for it in the confirmed systems, how forgiving it is to learn, and how its identity maps onto the two game modes. When the developer publishes the four unnamed classes or official stats, this list will change. That is the point of an honest tier list in Early Access.

## The Overall Rankings

| Tier | Class | Reasoning (from confirmed descriptions) |
|------|-------|------------------------------------------|
| **S** | **Mage** | The confirmed caster lives in the element-swap reaction system — the game's most distinctive power. Reacting from range to trigger the 16 reactions (Freeze, Erode, Shockwaves are officially named) is the highest ceiling among confirmed classes. |
| **S** | **Archer** | The confirmed ranged specialist. Range lets you read enemy patterns before they reach you, which translates into safe damage on every floor and the safest way to learn new content. Consistent and strong everywhere. |
| **A** | **Warrior** | The official starting class and a melee generalist. Reliable in every system — forge, upgrade, Soulbind, climb — and the class the game teaches its mechanics around. The ceiling is lower than the ranged classes, but the floor is the highest. |
| **B** | **Assassin** | The confirmed "Shadow Specialist": high mobility, high lethality, Shadow Clones for synchronized strikes. Powerful in bursts but demanding — repositioning and combo execution take knowledge of enemy patterns that new players do not have yet. |

The reasoning matters more than the letters. **Mage and Archer rank highest because confirmed ranged identities convert the confirmed combat systems (elemental reactions, pattern reading) into safe damage.** Warrior is the consistency pick. Assassin is the skill-check pick.

## Best Class for Beginners

| Rank | Class | Why |
|------|-------|-----|
| **Best** | **Warrior** | It is the official starting class — the game's tutorial structure is built around it, and melee fundamentals (dodge timing, element swapping, boss pattern recognition) transfer to every other class. |
| **Good** | **Archer, Mage** | Archer teaches ranged spacing safely; Mage is a natural introduction to the reaction system. Both are fine first picks if you prefer ranged play. |
| **Avoid for now** | **Assassin** | Clone-based tricks and combo execution reward players who already know enemy patterns. No official difficulty data exists — this is judgment from the class description, not a stat. |

## Survival Mode Rankings

Survival Mode is infinite hordes with a chosen loadout and permanent death. The mode's demands flip the ranking logic:

| Tier | Class | Why |
|------|-------|-----|
| **S** | **Mage, Archer** | Range is king against endless waves. Mage's area reactions clear packs; Archer kites safely in dense rooms. Both convert the confirmed systems into survivable sustained output. |
| **A** | **Warrior** | Survivable through the early waves with forged gear; kills more slowly as hordes scale past it. |
| **B** | **Assassin** | Strong in bursts, fragile when surrounded. Mobility matters, but sustained horde fights punish combo-dependent play. |

## What Would Change This List

An honest tier list states its failure conditions. This list changes when any of these become official:

1. **The four unnamed classes launch.** One of them could be the actual S-tier. The 8-class roster is confirmed; the meta is not.
2. **Official stats or patch changes.** If the developer publishes class stats or rebalances, the descriptions this list is built on change with them.
3. **Elemental affinities get published.** Every class has an elemental affinity per the official description — which element each class favors is TBD. If the Mage's affinity is revealed as weak, its ranking is re-examined.
4. **Soulbinder behavior in Survival Mode is clarified.** Whether bound stats carry into Survival Mode is unconfirmed; the answer shifts the Survival rankings.

## How to Use This List Without Losing Your Mind

- **Rankings are starting points, not verdicts.** Every class is playable; the game is designed around the Warrior being your first run.
- **Play the class that matches your goal.** New to the game → Warrior. Learning fights from range → Archer. Living in the reaction system → Mage. Speed-running known floors → Assassin.
- **Do not over-invest pre-official-stats.** Class-specific "best builds" that promise exact numbers are unverified. Build around the confirmed systems — elements, blessings, Blacksmith forging, the Soulbinder — and let the class be the frame, not the fact.
