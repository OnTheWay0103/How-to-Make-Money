# Phantom Tower Quick-Reference Cheat Sheet — Everything Confirmed on One Page

This is the bookmark page: every confirmed Phantom Tower fact, compiled into tables. Everything here comes from official sources (store description, press materials, Steam page). Where the community has invented details, this sheet says so explicitly rather than repeating them.

## Classes

**8 classes at launch — 4 officially named:**

| Class | Role | Confirmed Details |
|-------|------|-------------------|
| **Warrior** | Melee fighter | The official starting class |
| **Mage** | Ranged caster | Spell-focused; natural fit for elemental reaction play |
| **Archer** | Ranged attacker | Kiting and safe damage; strong for learning boss fights |
| **Assassin** | "Shadow Specialist" | High mobility, high lethality, **Shadow Clones** for synchronized strikes |
| **4 more classes** | TBD | Unannounced; treat community names ("Elementalist", "Berserker") as inventions |

The mobile release also lists a **Necromancer** (collects souls to summon allies) — not confirmed for Steam.

## Elements & Reactions

| Element | Notes |
|---------|-------|
| **IGNIS** | Fire — part of the four-element combat system |
| **AQUA** | Water — pairs into the confirmed reactions |
| **TERRA** | Earth — part of the element-swap system |
| **VENTI** | Wind — part of the element-swap system |

**16 elemental reactions total** — only 3 officially named:

| Reaction | Official Description |
|----------|---------------------|
| **Freeze** | Immobilizes enemies (per official materials) |
| **Erode** | Melts enemies from the inside; spreads to nearby targets |
| **Shockwaves** | Damage that chains between foes |

The other 13 are unpublished — any guide listing all 16 by name is speculating. Combat trick: apply one element's effect, swap, and trigger the reaction — swapping elements mid-fight is the signature mechanic.

## Gear

| Stat | Confirmed Value |
|------|-----------------|
| **Weapons** | 128, across six types |
| **Total equipment pieces** | 200+ |
| **Soulbinder stat cap** | Level 99 on a single locked stat |
| **Crafting hub** | The Blacksmith (forging) |

Bosses drop **Boss Unique Weapons** — the game's confirmed chase items.

## Tower Blessings

- **47 total blessings** that reshape runs
- Only two officially named: **Artemis Descent** (arrows hunt the highest-HP enemy on dodge) and **Chain Quake** (damage ripples between foes)

## Game Modes

| Mode | Rules | Progression |
|------|-------|-------------|
| **Climb Mode** | Main campaign; 100-floor tower; hordes and bosses | Materials/resources/equipment carried out between runs; permanent Soulbinder stats |
| **Survival Mode** | Infinite hordes; pick your loadout before entering | **True permadeath** — no checkpoint, no carry-over |

- **New bosses** — more boss content planned
- **Additional playable characters** — beyond the 8-class launch roster
- **More diverse gear** — the 128-weapon / 200+ pool expands

The game entered Early Access **July 13, 2026** at $12.99 (24% launch discount for two weeks); a full-release date has not been announced.
