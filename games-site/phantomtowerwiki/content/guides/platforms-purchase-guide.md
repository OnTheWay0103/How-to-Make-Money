# Phantom Tower Platforms & Purchase Guide — Steam, Android, iOS, and Console Status

"Which platforms is Phantom Tower on? Is it on PS5? Is the mobile version the same game?" The honest short answer: Phantom Tower exists in **two separate products** — a paid Steam Early Access version for PC and a free-to-play mobile version on Android and iOS. No console version has been announced. This guide walks through each platform, what it costs, how the versions differ, and what we could not verify.

## Steam (PC) — The Early Access Version

| Fact | Detail | Source |
|------|--------|--------|
| Developer | Horien Studio (two-person team, Genoa, Italy — debut title after four years of development) | Official press release |
| Launch | Early Access on **July 13, 2026** | Official press release |
| Price | **$12.99 / €12.99 / £11.75** | Steam store page |
| Launch discount | 24% off for the first two weeks (July 13–26, 2026) — now ended; the current list price is the full $12.99 | Steam store page |
| Demo | Free demo available (separate Steam listing) | Official press materials |
| Future price | Will increase when the game reaches 1.0 (targeted for the first half of 2027) | Steam store page |
| Languages | Windows build; 9 languages including English, Simplified Chinese, Japanese, and Korean | SteamDB `[Community]` |

The Steam version is **ad-free** and a one-time purchase. If you want to try before buying, the free demo is the recommended starting point — the demo's content cap has not been published, so treat any "demo goes up to floor X" claim as `[Unconfirmed]`.

## Android & iOS — The Free-to-Play Mobile Version

Phantom Tower is also a **free-to-play mobile game** with ads and in-app purchases, available on both stores under the developer name "Horien Studio SRL":

| Fact | Detail | Source |
|------|--------|--------|
| Google Play (Android) | `com.horienstudio.phantomtower`; free with in-app purchases | Google Play listing |
| App Store (iOS) | App ID `6745515425`; free with in-app purchases; iOS 15.0 or later; ~731 MB | App Store listing |
| In-app purchases | Starter packs (Mage/Warrior/Archer), Standard/Premium/Advanced Bags, and a "Full Game Unlock" — 7 IAP items per third-party tracking | App Store / third-party data `[Community]` |
| Release order | The mobile version launched first (a mid-2025 date appears in third-party data); Steam Early Access followed July 13, 2026 | Third-party data `[Community]` |
| Offline play | Described as playable as a single-player, offline game | Mobile coverage `[Community]` |
| Ads | Free version carries ads; the Steam version has none | Press materials `[Official]` |

Mobile version numbers move fast — third-party data showed v0.4.14 in June 2026 — so always check the store page for the current build. Note the mobile roster is separate: the **Necromancer** class appears on mobile (per community reports) and has not been confirmed for the Steam version — see the [Classes Guide](/guides/classes-guide).

## PS5, Switch & Xbox — Not Announced

As of August 25, 2026, **no console version has been announced**. Both official press releases list the platform as Steam only, and no console announcement could be found in any official material. If you are waiting for a PS5 or Switch release, there is nothing official to wait for yet — any "Phantom Tower PS5" or "Phantom Tower Switch" search result pointing at a playable console version is referring to something else (there are several unrelated products named "Phantom Tower").

## Offline, Online & Controller Support

- **Is Phantom Tower offline?** The mobile version is described as a single-player, offline game `[Community]`. For Steam, there is no separate always-online requirement published; the game is single-player with no multiplayer at Early Access launch (the roadmap lists co-op as "under investigation" — official). No official statement about Steam offline mode was found `[Unconfirmed]`.
- **Is there multiplayer?** Not yet. Single-player only at launch; co-op is under investigation per the official roadmap.
- **Controller support?** The evidence conflicts. SteamDB lists the Steam demo with **full controller support** `[Community]`, while a Chinese review outlet states the game does not support a controller. We could not verify either claim on the Steam store page — treat controller support as `[Unconfirmed]` for now.

## How to Buy (Without Getting Scammed)

1. **Steam:** Wishlist or buy `Phantom Tower` on the official store page, or try the free demo first. The current price is $12.99; it will rise at 1.0, so Early Access is the cheapest time to buy if you want it.
2. **Android:** Google Play, app ID `com.horienstudio.phantomtower`. The free version includes ads; the "Full Game Unlock" IAP is the mobile equivalent of paying.
3. **iOS:** App Store, app ID `6745515425`, same free-to-play model.
4. **Avoid:** "Phantom Tower PC download" results offering free full versions, trainers, or unlimited-money mods — the game has no official free-PC version, and those results are the piracy/cheat cluster of search terms (see our stance: we do not cover them, and they are not the real game).
