# Bonehold Controls & Settings Guide - Inputs, Keybindings, and Accessibility

Bonehold is a keyboard-and-mouse game with **full controller support** — both input styles are confirmed. This reference guide covers what is **confirmed** about Bonehold's inputs and settings, the actions every player needs to map, and what is still unresolved (Steam Deck status, rebinding) without inventing details.

**Honesty note:** Pixel Jackal has not published an official keybinding chart as of August 2026. The actions below are derived from Bonehold's **confirmed mechanics** (charge attacks, dodge, block, parry, interact, inventory); the specific keys are the community-referenced genre layout and are marked (unverified) — remap to whatever your hands actually prefer.

## What Is Confirmed About Inputs

| Claim | Status | Source |
|-------|--------|--------|
| Keyboard and mouse is the primary input | ✅ Confirmed | Site FAQ; launch reviews |
| Controller / gamepad support | ✅ Confirmed — full | Store page lists **full controller support, including DualShock 4 and DualSense** |
| Steam Deck official Verified badge | ⚠️ Not confirmed | No official Steam Deck compatibility statement; no Verified badge has been announced |
| In-game key rebinding | ⚠️ Unconfirmed | No official statement; community coverage does not confirm a rebind menu |
| Accessibility options | ⚠️ Limited | One launch review notes "limited accessibility options" as a con |
| Mouse/cursor behavior | ⚠️ Reported janky | One review reports cursor issues in menus — likely patched or fixable via settings; unverified |

**Bottom line:** keyboard and mouse is the primary input, and gamepads (DualShock 4, DualSense) are fully supported — pick whichever you prefer. Steam Deck's official compatibility status remains unannounced.

## The Input Actions Every Build Needs

These actions are implied by Bonehold's confirmed mechanics. Whether you use the defaults below or remap, every one of these must be comfortable — they are the entire combat language of the game:

| Action | Confirmed Mechanic | Community-Referenced Default (unverified) | Notes |
|--------|-------------------|----------------------------------------|-------|
| Move | Confirmed (3D traversal) | WASD | The 3D camera makes mouse-look movement the norm |
| Attack (tap) | ✅ Confirmed — quick attack | Left mouse click | Fast, low damage; interrupt tool |
| Charge attack (hold) | ✅ Confirmed — core mechanic | Hold left mouse | Tap → partial → full charge based on hold time |
| Dodge / roll | ✅ Confirmed | Spacebar or Shift (reported variants) | Consumes stamina; i-frames are your main defense |
| Block | ✅ Confirmed | Right mouse click (hold) | Covers multi-hit patterns; costs stamina |
| Parry | ✅ Confirmed — "glorious" | Right mouse click timed before impact | Staggers enemies; opens a full-charge window |
| Interact (doors, pickups) | Confirmed by gameplay | E (genre standard) | Keys, levers, loot |
| Inventory / equipment | Confirmed (loot system) | Tab or I (genre standard) | Prefix evaluation happens mid-run, so this must be fast |

*Every key above marked unverified is a genre-standard guess, not an official binding. If the game supports rebinding, set these to whatever feels natural; if it does not, adjust your hand position rather than your expectations.*

## Settings and Performance

The official Steam page lists system requirements (see our [System Requirements Guide](/guides/system-requirements-guide) for the full breakdown, including the page's RAM/storage typos). What to expect from the settings screen:

- **Graphics settings exist.** The game pairs hand-painted textures with pixel-art elements in a dark, glowing fortress — reviews praise the look. If performance dips, lowering the lighting/effects quality first is the standard fix for this visual style (unverified — exact setting names unconfirmed).
- **Language options are broad.** Official languages include English, French, Spanish, Polish, Portuguese-Brazilian, Russian, Simplified Chinese, Greek, Hungarian, and Japanese — all with interface, audio, and subtitles support.
- **No mid-run save.** This is a design decision, not a setting: there is no checkpoint or save system, so you cannot pause-and-quit mid-run expecting to resume. Plan sessions around it (confirmed by multiple reviews).
- **Cursor and UI quirks.** One launch review reports cursor issues and a clunky map UI. These are likely patch candidates — if you hit them, check for game updates before assuming it is your setup.

## Controller and Steam Deck: The Honest Status

This is the single most-asked control question, so let's be precise:

- **Controller support is confirmed.** The store page lists **full controller support, including DualShock 4 and DualSense** — keyboard-and-mouse is the primary input, but a gamepad is a fully supported way to play from launch.
- **Steam Deck has no official compatibility statement.** No Verified badge has been announced, and the game's launch coverage does not cover Deck performance. If you are considering a Steam Deck purchase *for* Bonehold, wait for an official statement rather than assuming Deck Verified status.

## Quick Input Checklist

Before your first serious run:

- [ ] Confirm your attack/charge hand position — you will hold that button *a lot*
- [ ] Dodge and block mapped to keys your fingers reach without looking
- [ ] Inventory key muscle-memory — prefix checks happen mid-room
- [ ] Timer expectations set: no saves, so schedule runs you can finish (or accept the loss)
- [ ] Display/graphics settings tuned to a stable frame rate before you need stable frames
