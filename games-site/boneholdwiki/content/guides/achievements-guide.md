# Bonehold Achievements Guide — All 98 Steam Achievements Explained

Bonehold ships with **98 Steam achievements** — a confirmed number from the game's official Steam store page. For a roguelike with randomized runs and permanent-per-run deaths, that is an ambitious achievement list, and completionists have their work cut out for them. This guide covers what is confirmed about the achievement system, how to approach hunting achievements in a run-based game, and — honestly — what is still unknown.

## What Is Confirmed About Achievements

Let's start with facts, because most achievement lists circulating online right now are unverified guesses:

| Fact | Status |
|------|--------|
| Total achievement count | **Confirmed: 98** (stated on the official Steam page) |
| Platform | **Steam only** — the game is Windows-only, so there are no console trophy systems |
| Achievement tracking | Steam tracks these like any other game's achievements, globally across all your runs |
| Official achievement list (names + unlock conditions) | **Unconfirmed** — no official list has been published by the developer as of early August 2026 |
| Third-party achievement trackers | **Treat with caution** — community-sourced lists exist, but with the game released July 28, 2026, none are verified against official data |

**The honest headline:** we know *how many* achievements exist (98), but the official names and unlock requirements have not been published. Any guide claiming to list all 98 by name right now is working from speculation or datamining that has not been verified. This page will be updated with the real list when one is confirmed.

## What Achievement Categories Almost Certainly Exist

While we cannot confirm specific achievement names, we can reason from how Bonehold is designed — and roguelike convention — about what the achievement list very likely covers. Treat each of these as **probable but unconfirmed**:

- **Run-progress achievements** — clearing floors, defeating bosses, completing a full run. Roguelikes almost always reward reaching milestones, and Bonehold's "duel mighty bosses" structure makes floor/boss milestones a natural fit.
- **Class achievements** — with 7 classes, completing runs (or reaching specific floors) with each class is a classic pattern. If you want to pre-emptively work toward these, playing every class is free progress in any case.
- **Death and failure achievements** — dying for the first time, dying a set number of times, dying to a trap. Bonehold's perma-death-with-no-checkpoints design makes "fail" achievements essentially free.
- **Loot and build achievements** — finding legendary items, equipping certain prefixes, hitting build synergy milestones. Given the game's item-prefix system is the heart of its buildcrafting, loot-related achievements are highly likely.
- **Kill-count achievements** — defeating cumulative numbers of skeletons, ghosts, and other enemies. The fortress is full of them; grinding these happens naturally.
- **Grind achievements** — cumulative totals across runs (gold earned, floors cleared, rooms explored). These reward long-term play rather than skill.

**Important:** none of the above category names or requirements are confirmed. Use them as a mental model for "what to do anyway," not as a checklist.

## How Achievement Hunting Works in a Roguelike

Bonehold's structure — procedural runs, permanent death, no save/checkpoint system — changes how you should approach achievements compared to a normal game:

1. **Most achievements will come naturally.** In a roguelike, the milestone achievements (first boss, first full clear) arrive on their own within the first tens of runs. Focus on learning the game first; the checklist fills itself.
2. **Class-based achievements reward variety.** If completion is the goal, rotate through all 7 classes instead of mainlining one. You get better at the game *and* make class-specific progress simultaneously.
3. **Some achievements will be pure RNG.** Loot-based achievements depend on legendary drops and prefix rolls, which are randomized per run. Expect these to take the longest and be willing to rerun floors just for drops.
4. **Deep runs matter more than fast ones.** Since runs are finite and death is permanent, a run that reaches deep floors generates far more progress (more enemies, more loot, more bosses) than five runs that die on floor 1. The single best achievement-hunting strategy is simply getting more consistent at deep runs.
5. **Check achievements after runs, not during.** With no pause-friendly meta UI confirmed mid-run, review progress between runs. Death ends a run anyway, so there is no reason to interrupt a good run to check a tracker.

## How Steam Tracks Your Progress

Because Bonehold is a Steam game, the platform itself does the tracking — and knowing how that works saves you from confusion:

- **Achievements unlock globally.** When an achievement unlocks, it is recorded on your Steam profile permanently, across all runs and all save data (there is no save data to lose anyway, since runs are self-contained).
- **Unlocks happen the moment the condition is met.** Steam records the unlock timestamp instantly. If the game crashes or you die before the run ends, the achievement still counts if the condition was met.
- **Your progress is visible in your Steam library.** The game's library page shows the percentage of the 98 achievements you have earned, and the global player percentages (what share of owners has each achievement) are shown per-achievement — once the list is published, that data helps you judge which achievements are rare and likely grindy.
- **Offline vs. online unlocks.** Steam queues offline unlocks and syncs them the next time you are online. Nothing special to do; just be aware a late sync can happen.
- **No in-game tracker is confirmed.** Whether Bonehold itself shows achievement progress in-game is unconfirmed. Rely on Steam's overlay and library views instead of assuming an in-game menu exists.

These are Steam platform facts, not game facts — they apply to every Steam game, so they are reliable guidance for how your 98 achievements will behave.

## Tools for Tracking Completion

Until the official achievement list is published, these are the practical tools:

- **Your Steam library page for Bonehold** — the authoritative counter. It shows your earned count out of 98 and, per achievement, the global unlock rate.
- **Steam community hub and discussions** — where players will post the first verified achievement lists. Cross-check any list against multiple posts before trusting it.
- **Third-party trackers like SteamDB and similar sites** — they mirror official Steam data. Useful once the list exists; the data is only as good as the source (Steam itself), so they are trustworthy for counts but not for unlock requirements invented by users.
- **Your own notes** — for a roguelike, a simple text file per class ("cleared floors 1-3, died to X boss") is often the most useful tracker of all, because it tracks your *ability*, which is the actual bottleneck for most achievements.

The one thing no tool can do yet: tell you the requirements for achievements that have not been officially documented. Treat every claimed requirement as provisional until it is widely corroborated.

## Planning Runs for Achievement Progress

Because Bonehold runs are long and death is permanent, run planning is achievement planning. A few structures that pay off regardless of the list:

- **The "progress run" vs. the "goal run."** Most runs should be progress runs: push one floor deeper than your last best, try a new class, experiment with a prefix combo. Dedicate occasional goal runs to a specific target (a boss you have not beaten, a class you have not tried) once you know your skill level. Mixing both in every run dilutes both.
- **Play the demo habits into the full game.** If you came from the free demo, the early floors should be comfortable — use them to build momentum for the first boss, not to farm.
- **Learn one deep-floor routine.** Consistency comes from a repeatable approach: same defensive habits, same charge discipline, same room-pulling routine. Achievement progress compounds when your baseline survival is reliable.
- **Rotate classes on a schedule.** Rotating every run means you never build class proficiency; mainlining one class means class achievements take forever. A good rhythm: play your main class until a milestone (a boss clear), then one run with a different class, then back.
- **End runs deliberately.** With no save system, a run ends in death or completion anyway. If a run has clearly stalled (low health, no sustain, bad gear), using it to practice a new technique is better than grinding it out — every run should teach you something.

None of this depends on knowing the achievement list. It is good roguelike practice that also happens to be the most efficient way to hit whatever the list turns out to be.

## Tips That Work No Matter What the List Says

These strategies are useful regardless of the actual achievement list, because they improve your overall run consistency:

- **Master one class first.** Play Knight or another defensive class until you can regularly reach deep floors. Consistent deep runs out-earn sloppy wide runs.
- **Then rotate classes.** Class-based achievements are the most common roguelike pattern; playing all 7 covers that base.
- **Chase legendaries.** Legendary items are confirmed to exist and are described as build-defining power spikes. Loot achievements, whatever they are, will want legendaries.
- **Never skip free progression.** Bosses, elite rooms, and chests all generate progress. Clear what you can safely clear.
- **Expect an RNG endgame.** If your final few achievements are loot-related, treat them like lottery tickets: keep running, keep full-clearing, and the drops eventually come.
