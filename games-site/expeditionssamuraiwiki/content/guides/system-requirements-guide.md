## Performance Optimization Tips

General guidance that applies to any Unreal Engine title of this scope — and will be refined with real benchmarks after launch:

1. **Install on an SSD.** Level streaming during real-time exploration is dramatically smoother from an SSD; this is the highest-impact upgrade for open-level CRPGs.
2. **Keep drivers current.** Both NVIDIA and AMD ship game-ready drivers around major launches — install before August 7.
3. **Close background load.** Browsers and streaming in the background matter most during the stealth pillar, where frame drops cost you detection timing.
4. **Start with the recommended preset, then tune.** Lower shadows and view distance before resolution — the biggest visual quality-per-frame gains.
5. **Watch VRAM if stuttering.** Stutter with textures on ultra usually means VRAM pressure — step textures down one notch.
6. **Laptops: cap the frame rate.** A frame cap (60 or below) keeps thermals and fans sane on long sessions — important for a game with 8-hour acts.
7. **Verify file integrity after launch day patches.** Early Access titles patch often; a corrupted update is the most common post-launch "performance problem."

## Performance FAQ

**Will the Early Access build run differently from 1.0?** Likely yes. Early Access titles typically ship with optimization work still pending — a modestly demanding launch build that improves by full release is the norm. Plan for the launch build's spec sheet, not the final one.

**Is the game well-optimized on older hardware?** Unknown until benchmarks exist. The series' previous titles (Expeditions: Rome, Viking) were well-regarded on mid-range hardware, which is a hopeful sign — but each game is its own project.

**Does co-op double the requirements?** No — co-op shares one host's machine; the second player joins the same session (a friend on a lower-spec machine can play in your session, subject to whatever the launch build requires for joining).

**Can I run it on a laptop?** Likely, if it meets the minimum spec when published — expect thermal management to be the real constraint over long sessions; cap the frame rate and keep the machine ventilated.
