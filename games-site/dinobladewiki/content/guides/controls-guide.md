# Dinoblade Controls Guide — Inputs, Platforms & System Requirements

Dinoblade is a **PC-only** game on Steam (Windows), built in Unreal Engine 5, with full controller support. This guide covers the confirmed input facts, the platforms the game runs on, and the official system requirements.

**Honesty note:** Team Spino has not published a full default-keybind reference. The confirmed inputs below come from gameplay coverage and the in-game tutorial; where exact bindings are unknown, that's marked.

## Confirmed Combat Inputs

These are the controls documented in the game's tutorial and walkthrough coverage:

| Action | Confirmed Input |
|--------|-----------------|
| **Light attacks** | Standard attack input (part of the tutorial's combo system) |
| **Heavy attacks** | Separate attack input; **holding it charges a fire projectile** (costs 5 Resonance + stamina) |
| **Block / Parry** | **Hold the block input, release right before the incoming strike to parry** — the parry is a release-timing mechanic, not a separate tap |
| **Dodge roll** | Dedicated dodge input with invincibility frames |
| **Sprint** | Movement-related input (tutorial: sprinting is a covered mechanic) |
| **Lock-on** | Lock-on targeting exists; **the scroll wheel switches between locked targets** |
| **Healing charges** | Consumable-style heal (charges refill at Save Stones) |

**The parry input is the key control fact:** unlike most Soulslikes where parry is its own button, Dinoblade's parry is **holding block and releasing it right before the strike lands**. Practice the release timing — see the [Parry Guide](/guides/parry-guide).

## Platforms

| Platform | Status (as of August 2026) |
|----------|----------------------------|
| Windows (Steam) | Available since July 23, 2026 |
| Consoles (PS5 / Xbox / Switch) | **Not available; no console ports announced** |
| Mobile | Not available |

Dinoblade is a single-player game — there is no co-op or PvP.

## System Requirements (Official, from the Steam page)

### Minimum

| Component | Requirement |
|-----------|-------------|
| **OS** | Windows 10 64-bit |
| **CPU** | Intel Core i5-7500 / AMD Ryzen 5 1600 |
| **RAM** | 4 GB |
| **GPU** | NVIDIA GTX 1050 (4 GB) / AMD Radeon RX 560 |
| **DirectX** | Version 12 |
| **Storage** | 13 GB available (the demo requires 6 GB) |

The game is well-optimized for modest hardware — the minimum spec is a GTX 1050-class GPU with 4 GB of RAM. If your machine meets the minimum, expect a playable experience at 1080p with settings tuned down.

## Settings and Accessibility

**Confirmed by coverage:**

- **Gore can be reduced or disabled** — the game includes frequent blood effects and cutscene violence, with an option to tone it down. Note that the game still carries a mature-content listing.
- **Full controller support** — a controller is the recommended way to play a parry-heavy game.
- **Rebindable keys** — the settings menu includes rebinding (standard for Steam releases; exact default bindings are undocumented).

**Not officially documented (TBD):** exact default keybinds per action, FOV settings, upscaler support (DLSS/FSR), and console-command options.

## Getting the Best Parry Experience

1. **Play with a controller if you can** — release-timing parries are easier with a trigger/button than a mouse release.
2. **Disable or reduce motion-heavy settings** (motion blur, camera shake) if the game offers them — parry games reward visual clarity.
3. **Learn the release timing in the tutorial** — the opening cavern is designed for exactly this.
