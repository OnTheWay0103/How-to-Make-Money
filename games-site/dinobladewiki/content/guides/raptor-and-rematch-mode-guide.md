# How to Play as the Raptor & Use Rematch Mode in Dinoblade

Dinoblade's free October 2026 content update added two things players had been asking for: **a playable Raptor in Story Mode** and **Rematch Mode**, which lets you fight defeated mini-bosses again. The announcement headline says it plainly: "Playable Raptor, REMATCH MODE, Steam Fall Sale 20%." The playable Raptor landed on September 29, 2026, and Rematch Mode followed on October 2 — roughly two months after the game's July 23 launch.

This guide explains how to access both features, what is actually confirmed about them, and how to use them for practice without wrecking your save or your expectations. It also covers the Raptor-specific fixes that followed, because the first version of any new mode tends to have rough edges.

## What the October Update Actually Added

Two headline features, plus follow-up fixes:

| Feature | What it does | Confirmed? |
|---------|--------------|------------|
| **Playable Raptor** | Adds a Raptor as a selectable character in Story Mode | Yes — Steam announcement |
| **Rematch Mode** | Re-fight mini-bosses you already defeated in Story Mode | Yes — Steam announcement |
| **Target-lock fix** | Fixed target lock against the Swamp Boss | Yes — patch note |
| **Raptor camera fix** | Fixed camera problems while playing the Raptor | Yes — patch note |
| **Load Game UI fix** | Fixed the Load Game UI not appearing if you play as Raptor first | Yes — patch note, October 12 |
| **Map size optimization** | Optimized the player character map size | Yes — patch note, October 2 |

Notice what is **not** in that table: no new region, no new boss, no new weapon tree, and no separate Raptor campaign. The update adds a character option and a replay option to the existing Story Mode. That is the honest shape of it.

## How to Access the Playable Raptor

The official announcement does not publish a quest requirement, a currency cost, or a completion gate for the Raptor. What the patch notes do show is that the Raptor is chosen in **Story Mode**, and that the game needed a fix for the Load Game UI when a player starts as the Raptor. That strongly implies the Raptor is selectable from the story flow rather than unlocked deep into a campaign — but because the announcement never states the exact condition, treat "available immediately" as **[Unconfirmed]** until you see it on your own menu.

A safe access routine:

1. **Update the game first.** Let Steam finish downloading the October build. If the Raptor does not appear, restart Steam and verify the game files.
2. **Open Story Mode.** The announcement specifically says "Story Mode," not Boss Rush and not a separate menu. If you are looking for the Raptor in Boss Rush, you are looking in the wrong place.
3. **Start a new story run or load an existing one.** The patch note about the Load Game UI suggests both paths were intended to work. If the Load Game screen does not appear on the current build, update again — that exact bug was fixed on October 12.
4. **Look for a character-select step.** If the game does not offer a choice on an existing save, start a fresh Story Mode save. Whether an existing save can switch characters mid-run is **[Unconfirmed]**.

If you have already started a Spinosaurus run, do not delete it to chase the Raptor. Finish the update, check the character-select or load screen first, and only start fresh if the option genuinely is not offered.

## What Changes When You Play as the Raptor

The confirmed answer is: **you play the same Story Mode as a different character**. The update does not add a Raptor-only campaign, and no official source describes a separate Raptor storyline.

What is **not** officially documented:

- The Raptor's exact moveset, damage profile, stamina economy, or Soul Arts **[Unconfirmed]**
- Whether the Raptor uses the same Great Sword progression or a different weapon path **[Unconfirmed]**
- Whether achievements, unlocks, and Boss Rush access are shared with your Spinosaurus save **[Unconfirmed]**
- Whether the Raptor has unique endings or story scenes **[Unconfirmed]**

That uncertainty matters for planning. Do not assume the Raptor is a "hard mode" or a "fast character." Those labels are community guesses, not official descriptions. The safe assumption is that the core combat rules still apply: parries build posture, posture breaks open counterattacks, stamina gates every action, and not every attack can be parried. Learn the Raptor's own attack animations and parry timing on the early canyon enemies before you judge the character.

### A Practical Raptor Run Plan

Because the Raptor's kit is undocumented, build your first run around fundamentals rather than a preconceived build:

1. **Spend the first 20 minutes on parry timing.** Fight the smallest dinosaurs in the opening canyons and parry instead of dodging. You are learning the Raptor's animation commitment, which is the one thing that changes between characters.
2. **Test the dodge before trusting it.** Roll i-frames are the answer to red/unparryable attacks. Confirm the Raptor's dodge distance and recovery yourself; do not import Spinosaurus habits blindly.
3. **Bank healing at save points.** Resting restores healing and respawns enemies — the standard Soulslike trade. Do not push a new character deep on a empty heal bar.
4. **Upgrade deliberately.** Attribute and skill upgrades are confirmed progression layers. If the Raptor shares progression with your existing save, spend cautiously until you know what the character scales with; if it does not, treat the first region as a tutorial again.
5. **Keep a backup save.** The update is new and had at least three follow-up fixes. A manual backup costs nothing and protects a long run.

## How Rematch Mode Works

Rematch Mode lets you **re-fight mini-bosses you have already defeated in Story Mode**. That is the full official description. It is not a boss rush, it is not a randomizer, and it is not a new difficulty tier.

What that means in practice:

- **The fights are drawn from Story Mode.** You are not creating a new save or a new campaign to use it.
- **Only defeated mini-bosses are eligible.** If you have not beaten a mini-boss yet, it is not in your rematch pool.
- **The final boss and full boss roster are not confirmed to be included.** The announcement says "mini bosses," so treat main-story Alpha fights and the final encounter as **[Unconfirmed]** additions.
- **Rewards are not documented.** Whether a rematch grants XP, materials, achievements, or nothing is **[Unconfirmed]**. Do not farm rematches expecting progression until you confirm the reward screen yourself.

### How to Use Rematch Mode for Practice

The best use of a repeatable mini-boss is deliberate practice, not loot farming. A routine that works:

1. **Pick one mini-boss with an attack you keep failing.** The T-Rex-style Alphas and weapon-armed tyrannosaurs are the confirmed showcase fights, but any mini-boss you have beaten will do.
2. **Set a single goal for the session.** Examples: parry every horizontal swing, dodge every red-flash attack, or never let stamina hit zero.
3. **Stop after three clean attempts.** Rematch Mode removes the runback, which is exactly what makes it a good lab — and exactly what makes it easy to grind angrily for an hour.
4. **Take the lesson back to Story Mode.** Practice only counts if it transfers to a fight where death costs something.

Rematch Mode also pairs naturally with the confirmed **Boss Rush Mode**, which unlocks after the final boss. Boss Rush is a back-to-back gauntlet; Rematch Mode is a single-fight rehearsal. Use Rematch to clean up a specific matchup, then take the improved timing into Boss Rush.

## Known Issues and Fixes

The October update shipped with a short tail of hotfixes. If something feels broken, check this list before blaming your timing:

| Symptom | Status |
|---------|--------|
| Target lock misbehaves against the Swamp Boss | Fixed in a follow-up patch |
| Camera behaves badly while playing the Raptor | Fixed in a follow-up patch |
| Load Game UI does not appear when playing as Raptor first | Fixed October 12, 2026 |
| Player character map size looked wrong | Optimized October 2, 2026 |

If you still see one of these after updating, verify your game files and restart Steam. If the problem persists, report it on the Steam Community hub rather than deleting saves or reinstalling the game — a reinstall will not fix a code-side bug and may cost you local progress.

## Should You Start a Raptor Run Now?

Start a Raptor run if you have already finished the campaign and want a different character for the same story, or if you are early enough that restarting costs you little. Wait if you are mid-campaign on a Spinosaurus save and the character-select screen does not offer a switch — the update does not promise mid-run character swapping, and losing a long save to experiment is a bad trade.

Either way, update before you play, back up your save, and treat the Raptor as a new character to learn rather than a shortcut. The parry loop is still the game. The Raptor just changes the animations you have to read.
