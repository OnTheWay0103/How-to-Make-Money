# Gear Enhancement — What's Confirmed

**Correction first**: earlier versions of this guide documented a 15-level enhancement system with success rates (100% down to 5%), failure penalties, enchantment scrolls, and material costs. **None of that is confirmed.** Titan Roc has never published an enhancement system with levels, success rates, or destruction-on-failure mechanics. Those tables were invented and have been removed. Here is what is actually known about gear in Vahrin's Call.

## What Is Confirmed About Gear

### Gear Is Customisable

Official materials confirm that **weapons, armour, potions, traps, and other gear can be customised** to develop an ideal playstyle. "Customisation" is confirmed — the specific mechanics of that customisation (enchanting, upgrading, sockets, etc.) have not been detailed publicly.

### Loot and Treasures Are Core to the Game

The game's own description and launch reviews confirm:

- **Loot** is a core part of exploration — quests, enemies, and hidden treasures reward gear.
- The hand-crafted world is full of **hidden treasures**, with exploration consistently praised as the game's strongest feature.
- An entire **"whole huge area" hidden behind a side quest** reportedly contains significant rewards.

### Gear Supports the Classless System

Since any character can use any gear (no class restrictions), equipment is a build tool rather than a class gate. A magic-heavy fighter can wear heavy armour; an archer can mix in mage gear — the game's pitch is freedom of combination.

## Practical Gear Advice (Based on Confirmed Systems)

1. **Treat loot as progression.** With no confirmed enhancement system, gear upgrades come from finding better items — so explore, clear side quests, and check every hidden treasure.
2. **Prioritise customisable gear.** The confirmed customisation systems (spell attributes, potions, traps) are where you can invest; gear choice matters, but flexibility is the game's strength.
3. **Keep a backup set.** Since skills improve through use, switching playstyles is real — a second set of armour for a different style costs little and saves backtracking.
4. **Sell what you don't use.** Loot flows freely from exploration; there is no confirmed reason to hoard low-value items.
5. **Hunt the hidden area.** The side-quest hidden zone is reportedly one of the richest sources of notable gear.
