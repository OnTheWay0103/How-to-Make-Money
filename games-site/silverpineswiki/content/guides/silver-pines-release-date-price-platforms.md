## Genre and Play Mode

| Field | Value |
|-------|-------|
| Genres | Survival horror, metroidvania, action, adventure |
| Play mode | **Single-player only** |
| Co-op / multiplayer | None |
| Steam features | Achievements, Full controller support, DualShock support, DualSense support, Steam Cloud, Family Sharing |
| Content descriptor | General mature content |

Silver Pines is a **single-player game**. There is no co-op, no multiplayer, no PvP and no online component of any kind — Steam lists single-player as the only play mode for both the main game and the demo. If you have seen a "Silver Pines multiplayer" video or article, it is describing something that does not exist.

The controller support list is worth noting because it is unusually complete for an indie horror game: **full controller support plus explicit DualShock and DualSense support**. A horror game with a PlayStation-style controller layout is a deliberate choice, and it pairs oddly — in a good way — with a save system built around physically walking to a phone booth.

Steam also lists **achievements** as a category, which confirms the game ships with them **[the achievement list itself is Unconfirmed]**, plus Steam Cloud saves and Family Sharing.

### How violent is it?

Steam's content descriptor for the main game is **general mature content**, with the developer's own note:

> "This game contains blood, violence, horror themes and general mature themes unsuitable for younger players."

The **demo's** note is more specific:

> "This title contains violence, gore, blood, alcohol reference and bad language throughout."

Both are worth reading literally. There is **no nudity or sexual content descriptor** on either the main game or the demo. Regional ratings we can read — Germany's USK-equivalent entry and Indonesia's IGRS — land at 16 and 18 respectively with violence, drugs and horror descriptors. If you are looking for atmospheric horror without gore, this is not that game.

### Windows (official minimum)

| Component | Requirement |
|-----------|-------------|
| OS | Windows 10 |

| Memory | 8 GB RAM |
| Graphics | NVIDIA GeForce GTX 660 Ti or AMD Radeon R9 270X |

| Notes | Requires a 64-bit processor and operating system |

### Windows (official recommended)

| Component | Requirement |
|-----------|-------------|
| OS | Windows 11 |
| Processor | Intel Core i5-6600 or AMD Ryzen 5 1600 |
| Memory | 8 GB RAM |
| Graphics | NVIDIA GeForce GTX 770 or AMD Radeon R9 380 |
| DirectX | Version 12 |
| Storage | 5 GB available space |

A few observations that follow directly from these official figures:

- **5 GB of storage is small.** Silver Pines is a 2.5D game with hand-drawn and rotoscoped animation rather than a 3D open world, and the install size reflects that. You will not need to clear space for this one.
- **8 GB of RAM in both tiers.** The minimum and recommended memory figures are identical, which usually means the game is not memory-bound at all.
- **The GPU jump is modest.** A GTX 660 Ti to a GTX 770 is a single generational step, and both are old cards. This is an undemanding game to run.
- **DirectX 12 is required at both tiers**, which is slightly stricter than the low GPU floor suggests — a very old DirectX 11-only machine may not be supported even if its raw performance is adequate.
- **No macOS or Linux requirements exist**, matching Steam's platform data.
