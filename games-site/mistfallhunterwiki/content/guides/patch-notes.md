## Patch Notes Overview

This page tracks all official updates, patches, and balance changes for Mistfall Hunter. Patch notes are compiled from official developer announcements on Steam and Discord. Bookmark this page to stay current with gameplay changes that affect your builds and strategies.

---

## Current Version: Release 1.0 + Day-One Hotfix

**Release 1.0 launched July 30, 2026** on Steam / PS5 / Xbox Series X|S (also day-one on Xbox Game Pass). All playtest builds (0.6.x–0.7.x) are obsolete — the 1.0 build **rebalanced every class**, so any tier list, build, or guide written before July 30 is out of date.

### What Changed in 1.0 (vs. Playtest 0.7.2)

| Area | Change |
|------|--------|
| **All classes** | Full rebalance of every class — talents, cooldowns, and base stats differ from the playtest. Beta meta is invalid |
| **Matchmaking** | Solo and Trio queues only (no Duo queue); second map is trio-only |
| **Servers** | Launch regions: US / DE / BR / SG / CN. No dedicated EU or OCE region — see the [Server Regions & Ping Fix Guide](/guides/server-regions-ping-guide) |
| **Season 1** | Live at launch — Withered Knight gains a new Polearm + Shield weapon stance |
| **Price** | $24.99 standard / $39.99 Deluxe (launch -10%); free with Game Pass |

### Day-One Hotfix (July 30, 2026)

Released within hours of launch to address the worst launch issues:

| Type | Detail |
|------|--------|
| **Balance** | Withered Knight buffed further — Charged Dash, Thrust, Lance Combo and block stamina costs all improved (see table below) |
| **Fix** | Soul of Return no longer consumed twice when entering/exiting the spirit tree |
| **Fix** | Sorcerer tutorial key prompts fixed (some languages) |
| **Fix** | Console players can now reconnect after disconnect mid-raid |
| **Fix** | Item splitting issues resolved |
| **Fix** | Multiple crash fixes (Windows / Xbox-PC) |
| **Fix** | PS5 deck display and execution animation audio fixes |
| **Fix** | Gamepad input handling improvements |

#### Withered Knight Hotfix Balance Table

| Ability | Before | After |
|---------|--------|-------|
| Charged Dash | ~65 base damage | ~75 base damage |
| Thrust | Shorter range | Longer range + faster recovery |
| Lance Combo | 3 hits | 4 hits, higher stagger |
| Block stamina cost | 6/s | 5/s |

The buff caused a community backlash ("the best class got even better") — see the [Tier List Guide](/guides/tier-list-guide) for the current meta discussion.

### Known Issues (as of August 1, 2026)

- **No OCE server, no dedicated EU server** — EU players report 120–180ms; officially acknowledged, no ETA
- **Rubber banding / desync** in peak hours on all regions — server-side, acknowledged
- **PC reconnect after disconnect** still not fully fixed (console was fixed in the hotfix)
- **Second map locked for solo players** (trio-only queue) — design decision, widely criticized

## Playtest Build 0.7.2

**Released:** July 20, 2026
**Patch Size:** ~600 MB

### New Content

| Feature | Details |
|---------|---------|
| **New Map: Ashen Wastes** | Volcanic extraction map with 5 named POIs, 2 boss spawns, and 12 extraction points |
| **New Weapon Type: War Scythe** | Available for Mercenary class. Medium range, medium speed, high sweep damage. |
| **Season Pass Preview** | UI for upcoming Season 1 battle pass (live in August 2026) — track non-expiring Pre-Season challenges |

### Balance Changes

| Change | Before | After | Impact |
|--------|--------|-------|--------|
| Shadowstrix Vanish cooldown | 45s | 55s | Small nerf to solo Shadowstrix |
| Sorcerer Glacial Blink | 3 charges | 2 charges | Significant nerf to Sorcerer escape |
| Mercenary Shield Block stamina cost | 5/s | 4/s | Buff to Mercenary sustain |
| Greatsword (Withered Knight) base damage | 65 | 72 | +10% DPS for Withered Knight |
| Longbow (Blackarrow) headshot multiplier | 2.0x | 1.8x | Small nerf to ranged burst |
| Healing Potion heal amount | 40 HP | 50 HP | All classes benefit |
| Corroded enemy HP (all maps) | -10% | -15% | Easier early-game farming |
| Extraction timer (solo) | 60s | 75s | Solo extraction takes longer |

### Map Changes

- **Ashen Wastes** added to map rotation (affects all queues)
- **Mossveil** — reduced fog density by 20% based on player feedback
- **Ironmire** — added 3 new extraction points on the eastern edge
- **Sunken Grotto** — removed 2 loot spawns near the central point of interest to reduce camping

### Bug Fixes

- Fixed Shadowstrix smoke bomb not blocking line-of-sight for Sorcerer ice spells
- Fixed extraction point spawning inside collision geometry on Mossveil
- Fixed "Infinite Loading" screen when party leader disconnects during matchmaking
- Fixed camp upgrade "Scout Tower" not updating minimap until zone reload
- Fixed Gyldenblood display showing incorrect value after selling items in bulk
- Fixed audio crackling when multiple fire spells are active simultaneously
- Fixed War Scythe hitbox being 0.3m shorter than the visual model

| Type | Detail |
|------|--------|

### Class Balance

| Change | Detail |
|--------|--------|
| Blackarrow Arrow Rain damage | Reduced by 15% |
| Blackarrow Trap duration | Reduced from 30s to 20s |
| Mercenary Shield Charge cooldown | Reduced from 12s to 10s (buff) |
| Mercenary War Cry shield amount | Increased from 100 to 150 (buff) |

| Seer healing aura range | Reduced from 15m to 10m (nerf) |
| All class base HP | Increased by 25 (buff for all) |

### New System: Camp Upgrades

Camp upgrades are persistent account-wide improvements that affect all characters:

| Upgrade | Cost | Effect |
|---------|------|--------|
| Workbench (Tier 1) | 500 Gyldenblood | Unlock gear repair |
| Workbench (Tier 2) | 1,200 Gyldenblood | Unlock gear crafting (Common → Uncommon) |
| Scouting Tower | 1,000 Gyldenblood | Reveal extraction points on minimap at match start |
| Medic Station (Tier 1) | 750 Gyldenblood | Passive HP regen between matches (2 HP/s) |
| Stash Expansion (Tier 1) | 1,500 Gyldenblood | +50 inventory slots |
| Training Dummy | 300 Gyldenblood | Practice combos in camp |
