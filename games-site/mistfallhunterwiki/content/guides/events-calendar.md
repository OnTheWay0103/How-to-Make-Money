## Event System Overview

Mistfall Hunter runs regular events — some seasonal, some weekly, some tied to community milestones. Missing an event means missing exclusive rewards.

## Recurring Weekly Events

| Event | Schedule | Rewards |
|-------|----------|---------|
| **Double Extraction XP** | Every Saturday | 2× extraction rank XP |
| **Boss Rush** | Every Sunday | Extra boss drops, leaderboard rewards |
| **Material Surge** | Random weekday | Double material drops in specific biomes |
| **PvP Arena Weekends** | Fri-Sun | Arena tokens, exclusive PvP cosmetics |

## How to Prepare

1. **Save premium currency** — Seasonal cosmetics are limited and never return
2. **Stockpile materials** — Event crafting recipes use 2× normal materials
3. **Join the Discord** — Event announcements drop there first
4. **Clear your schedule** — Major events run 2-4 weeks, don't miss the end
