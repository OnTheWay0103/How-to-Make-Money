# Elemental Builds — Shock, Poison & Acid Full Loadouts

> The strongest builds in Beast of Reincarnation are elemental. Match affinities across your **sword, arrows, Spirit Stones, Koo's Bloom Arts, and Koo's Charm** to inflict your chosen status more often — statuses out-damage raw parry chains on every boss. Verified from launch guides (launch version, August 2026).

---

## Build Fundamentals

Every elemental build follows the same skeleton:

```
Element Sword + Element Arrows/Bolts + Status Amp (Koo Root)
  + Element Bloom Art (Koo) + Element Charm (Koo) → Status stacks fast → punish windows
```

**Status Effect Amp** (Koo Incantation Root) is the backbone — it makes all statuses build twice as fast. Take it in every elemental build.

---

## 1. Shock Build — Best Against Bosses (S-Tier)

Shock paralyzes foes briefly, opening them for strong attacks and combos — the best status for boss fights.

| Slot | Piece | Notes |
|------|-------|-------|
| Sword | **Thunderwave Sword** (AoE lightning) or **Fall Thunder** | Fall Thunder = better single-target Shock damage |
| Arrows/Bolts | **Lightning Arrows & Bolts** | Midair shots apply Shock safely |
| Spirit Stones | Homing Shots + any crit/attack stones | See Spirit Stones guide for the full set |
| Koo Bloom Art | **Sakura: Javelin** | Shock application + mobility |
| Koo Charm | Any **Shock** ability charm | Match the element |
| Koo Item | **Bolt Shard** (high Shock buildup) | Near-guaranteed Shock proc |

**How to play**: Parry to fill FP → Javelin/Bolt Shard to Shock → punish the paralysis window with combos → repeat. Works on every boss including Corvus (weak to Shock).

---

## 2. Poison Build — Best Sustained Damage (A-Tier)

Poison causes passive HP loss over time; consistent reapplication is the key.

| Slot | Piece | Notes |
|------|-------|-------|
| Sword | **Hunter's Sword** | The only Poison-inflicting sword found |
| Arrows/Bolts | **Poison Arrows & Bolts** | Ranged DoT layering |
| Spirit Stones | Status-oriented stones + Entanglement series | Keep the gauge full |
| Koo Bloom Art | **Dokuzeri: Fang** | The only Poison Art for Koo — unlock after Ch. 2's boss |
| Koo Charm | Any **Poison** ability charm | — |

**How to play**: Keep Dokuzeri: Fang on cooldown, layer Poison Arrows between combos, and let DoT melt tanky fights. **Nue Malefact is weak to poison** — this build trivializes Chapters 1–3's repeated Nue fights.

---

## 3. Acid / Corrosion Build — Best vs Armor (A-Tier, late-game)

Corrosion slows enemies and tears apart armored foes' defenses. Requires Chapter 7 for Koo's Acid Art.

| Slot | Piece | Notes |
|------|-------|-------|
| Sword | **Hazebringer** | The only Acid sword found |
| Arrows/Bolts | **Acid Arrows & Bolts** | — |
| Spirit Stones | **Homing Shots** + Sharpshooter | Build Corrosion from range |
| Koo Bloom Art | **Acid Burst** | Drops from Corvus (Ch. 7, Lv. 38) — the only Acid Art for Koo |
| Koo Charm | Any **Corrode** ability charm | — |

**How to play**: Pelt from range with Homing Shots + Acid Arrows to stack Corrosion, then close in with Hazebringer combos once defenses crumble. **Taurus is weak to Acid** — if you have Acid access by Ch. 4, it ends the fight quickly; otherwise use guaranteed statuses (Shock/Flame/Poison) since Taurus rarely stands still.

## 4. Endgame Deep Dive: The Thunderwave Build

The strongest verified late-game build is **The Thunderwave** — a Shock-crit hybrid that converts parries into slow-time lightning nukes. Buildable from Chapter 3 onward once you reach the wandering merchant.

### Full Loadout

| Slot | Piece | Why |
|------|-------|-----|
| Sword | **Thunderwave Sword** (upgraded) | Summons lightning strikes hitting multiple foes; upgrade it at the Cleanse Walker Workbench |
| Armor | **Insulating Mail** | High Lightning resistance, 5 Spirit Stone slots — you're using lightning offensively, don't die to it |
| Arrows | **Lightning Arrows** | Ranged Shock for free procs |
| Spirit Stone 1 | **Entanglement Stone** | Start fights with Gauge 3 + Koo FP 3 — open every fight at full power |
| Spirit Stone 2 | **Onslaught** | Battle-start Attack boost |
| Spirit Stone 3 | **Florescent Recovery** | Bloom Arts restore HP over time — sustain |
| Spirit Stone 4 | **Entangled Combo** | Reaching 15 combos restores the Entanglement gauge |
| Spirit Stone 5 | **Critical Damage Increase** | Bigger crits |
| Koo Charm | **High-level ATK Charm** with Lightning / crit chance | Lightning strikes on attack; the charm's element matches Shock |
| Koo Items | Frailty Fang, Binding Fang, Destructive Fang, **Bolt Shard** (high Shock buildup), Healing Bouquet, Recovery Tonic | Fang series = offensive Ambers; Bolt Shard = guaranteed Shock |

### Skill Loadout

**Emma**
- **Entanglement Overdrive** (Strength-gated) — slow time + massive lightning damage; the build's nuke button
- **Helm Splitter** — aerial AoE, evasion, Down Gauge building
- **Shakuyaku, Botan** — Blade Arts from Nushi progression
- Recovery Effect Boost + Roll (basics, non-negotiable)

**Koo**
- **Pounce** Roots: Taunt, Detect Hidden Items, Healing Bouquet
- **Incantation** Root: **Status Effect Amp** (statuses build 2x faster)
- Bloom Arts: Sakura: Javelin (Shock), Bolt Shard, Healing Bouquet, Emergency Medicine

### Rotation

1. **Open** with Entanglement Stone's starting Gauge/FP (3 + 3)
2. **Parry** the boss's opening combo → FP fills → Javelin + Bolt Shard to Shock
3. **Punish** the paralysis window with Thunderwave combos (lightning procs on each hit)
4. **Build to 15 combo** → Entangled Combo refreshes the gauge
5. **Pop Entanglement Overdrive** during the boss's second phase → slow-time lightning nuke
6. Repeat — Healing Bouquet/Florescent Recovery keeps you alive between windows

### Budget / Early Version (Pre-Ch. 3)

Before the Thunderwave sword and merchant access:

- Any Lightning-element sword + **Fall Thunder** if found
- **Insulating Mail** or Floral Wraps with Momentum + Onslaught + Florescent Recovery
- Sakura: Javelin + Bolt Shard for Shock procs
- Emma: Roll + Recovery Effect Boost + Helm Splitter; Koo: Status Effect Amp + Taunt

This version carries you through Chapters 3–6 until the full set is available.
