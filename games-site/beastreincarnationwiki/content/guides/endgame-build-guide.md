# Endgame Build — The Thunderwave (Chapter 3+)

> The strongest verified late-game build: **The Thunderwave** — a Shock-crit hybrid that converts parries into slow-time lightning nukes. Buildable from Chapter 3 onward once you reach the wandering merchant. Verified from launch guides (v1.0.6, August 2026).

---

## Full Loadout

| Slot | Piece | Why |
|------|-------|-----|
| Sword | **Thunderwave Sword +3** | Summons lightning strikes hitting multiple foes; +3 upgrade for damage |
| Armor | **Insulating Mail** | 32 Defense, 70 Lightning Resistance, 5 Spirit Stone slots — you're using lightning offensively, don't die to it |
| Arrows | **Lightning Arrows** | Ranged Shock for free procs |
| Spirit Stone 1 | **Entanglement Stone** | Start fights with Gauge 3 + Koo FP 3 — open every fight at full power |
| Spirit Stone 2 | **Onslaught** | Battle-start Attack boost |
| Spirit Stone 3 | **Florescent Recovery** | Bloom Arts restore HP over time — sustain |
| Spirit Stone 4 | **Entangled Combo** | Reaching 15 combos restores the Entanglement combo |
| Spirit Stone 5 | **Critical Damage Increase** | Bigger crits |
| Koo Charm | **ATK Charm III** + Lightning II / crit chance | Lightning strikes on attack; the charm's element matches Shock |
| Koo Items | Frailty Fang, Binding Fang, Destructive Fang, **Bolt Shard** (100 Shock buildup), Healing Bouquet, Recovery Tonic | Fang series = offensive Ambers; Bolt Shard = guaranteed Shock |

## Skill Loadout

### Emma
- **Entanglement Overdrive** (Strength-gated) — slow time + massive lightning damage; the build's nuke button
- **Helm Splitter** — aerial AoE, evasion, Down Gauge building
- **Shakuyaku, Botan** — Blade Arts from Nushi progression
- Recovery Effect Boost + Roll (basics, non-negotiable)

### Koo
- **Pounce** Roots: Taunt, Detect Hidden Items, Healing Bouquet
- **Incantation** Root: **Status Effect Amp** (statuses build 2x faster)
- Bloom Arts: Sakura: Javelin (Shock), Bolt Shard, Healing Bouquet, Emergency Medicine

---

## Rotation

1. **Open** with Entanglement Stone's starting Gauge/FP (3 + 3)
2. **Parry** the boss's opening combo → FP fills → Javelin + Bolt Shard to Shock
3. **Punish** the paralysis window with Thunderwave combos (lightning procs on each hit)
4. **Build to 15 combo** → Entangled Combo refreshes the gauge
5. **Pop Entanglement Overdrive** during the boss's second phase → slow-time lightning nuke
6. Repeat — Healing Bouquet/Florescent Recovery keeps you alive between windows

## Budget / Early Version (Pre-Ch. 3)

Before the Thunderwave sword and merchant access:

- Any Lightning-element sword + **Fall Thunder** if found
- **Insulating Mail** or Floral Wraps with Momentum + Onslaught + Florescent Recovery
- Sakura: Javelin + Bolt Shard for Shock procs
- Emma: Roll + Recovery Effect Boost + Helm Splitter; Koo: Status Effect Amp + Taunt

This version carries you through Chapters 3–6 until the full set is available.
