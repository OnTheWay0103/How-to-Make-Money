# Farming Guide — Best Ways to Farm Sapphires, Gold & Inscription Shards

Sephiria's meta-progression is gated behind resources. Sapphires unlock Destiny Inscriptions (permanent upgrades), gold determines what you can buy mid-run, and Inscription Shards expand your socket capacity. This guide covers efficient farming routes for every resource.

---

## Sapphire Farming (Destiny Inscriptions)

Sapphires are the **permanent meta-currency**. You earn them from **every run — win or lose** — and spend them on Destiny Inscriptions that carry across all future runs.

### How Sapphires Are Earned

| Source | Notes |
|------|------|
| **Any run, win or lose** | The baseline — even dying on Chapter 1 pays sapphires |
| **Defeating chapter bosses** | Boss kills are a major sapphire source — further in the tower pays more |
| **Completing a full run** | A Chapter 6 clear pays a significant bonus |

### Efficient Sapphire Farming

**Play fast, play often.** An efficient sapphire-per-hour approach:

1. Use your **fastest-clearing build** (Crossbow or Greatsword with element tablets are favored in community discussions)
2. Run Normal climbs and **push toward bosses** — skip optional content you don't need
3. Die or clear, then restart — every run pays, so run speed is the farm

**The most important tip:** because even failed runs pay sapphires, there is no "wrong" way to farm. Playing the game *is* the farm.

### What to Unlock First (Priority Order)

| Priority | Destiny Inscription | Why |
|:--:|------|------|
| 1 | **Home Repair** | Unlocks the Talent tree — the gateway to other meta-progression |
| 2 | **Extra Potion Slot** | +1 consumable slot is a massive survivability increase |
| 3 | **Starting Weapon Choice** | Pick your weapon at run start instead of a random roll |
| 4 | **Artifact Slot +1** | A second permanent artifact slot — build-defining |
| 5 | **Shop Discount** | Cheaper shop purchases every run |
| 6 | **Bonus Gold Start** | Extra gold on run start helps early shop purchases |

## Gold Farming (Mid-Run Economy)

Gold is spent mid-run at shops and upgrade points. It resets every run.

### Gold Sources

| Source | Notes |
|------|------|
| Breaking objects (barrels, crates, pots) | **Break everything** — it adds up over a chapter |
| Enemy kills | Elites and bosses drop the most |
| Gold pickups | Found around the tower, especially in secret rooms |
| Secret rooms | High gold density — see the [Secret Rooms Guide](/guides/secret-rooms-guide) |

### Gold Spending Priority

1. **Healing potions** — always buy if available before a boss floor
2. **Tablets that match your build element** — the strongest mid-run power
3. **Weapon upgrades** — only if you're committed to your current weapon
4. **Buff potions** before the boss — only the ones matching your build

## Inscription Shard Farming

Inscription Shards unlock and upgrade socket slots on your gear. They persist between runs.

### Shard Sources

| Source | Notes |
|------|------|
| **Secret rooms** | The best source — learn to spot cracked walls |
| **Boss kills (first time per difficulty)** | One-time bonuses |
| **Challenge room clears** | Reliable mid-run income |

### Shard Farming Route

**Secret room hunting** is a reliable way to farm Inscription Shards:

1. Equip the **Astral Compass** artifact if you have it (it reveals secret rooms on your map)
2. Run Chapters 1-3 — these have the easiest-to-spot cracked walls
3. Search every wall section in dead-end rooms; cracked walls have a distinct visual texture
4. Repeat — shards accumulate fast when you know the triggers

A focused secret-room run yields a solid shard income. See the [Secret Rooms Guide](/guides/secret-rooms-guide) for the full detection methods.

## Artifact Farming (Endgame)

Some artifacts are **permanently unlocked through specific milestones** — they then appear in future run pools. For the full artifact picture, see the [Artifacts Guide](/guides/artifacts-guide). Key farming-relevant unlocks:

| Artifact | Unlock Condition | Farming Use |
|------|------|------|
| **Golden Maple Leaf** | Clear Chapter 2 | +15% XP — faster leveling during farms |
| **Astral Compass** | Find 10 secret rooms | Reveals secret rooms on map — essential for shard farming |
| **Vault Key** | Clear Gauntlet Mode | +1 artifact slot — more build options during farms |

## Time-Efficiency Summary

| What You Want | Best Method |
|------|------|
| Sapphires | Any run — fast Normal climbs with a quick clear build |
| Gold (mid-run) | Break everything + prioritize secret rooms |
| Inscription Shards | Secret room hunting (Chapters 1-3) |
| Artifact unlocks | Complete the specific unlock conditions |
| Permanent power | Unlock Home Repair first, then the priority list above |

**The most important farming tip:** don't obsess over farming. Every run gives sapphires even if you die on Chapter 1. Unlock Home Repair first, grab the Golden Maple Leaf, and then just play — the meta-progression will come naturally as you learn enemy patterns and build synergy.
