# Farming Guide — Best Ways to Farm Sapphires, Gold, Inscription Shards & More (1.0)

Sephiria's meta-progression is gated behind resources. Sapphires unlock Destiny Inscriptions (permanent upgrades), gold determines what you can buy mid-run, and inscription shards expand your socket capacity. This guide covers the most efficient farming routes for every resource in 1.0.

**Last updated: August 9, 2026 (1.0).**

---

## Sapphire Farming (Destiny Inscriptions)

Sapphires are the **permanent meta-currency**. You earn them from every run — win or lose — and spend them on Destiny Inscriptions that carry across all future runs.

### How Sapphires Are Earned

| Source | Sapphires | Notes |
|------|:--:|------|
| Defeating a chapter boss | 50-100 | Scales with chapter number |
| Completing a full run (Chapter 6 clear) | +200 bonus | One-time per clear |
| Daily Challenges | 30-80 | Resets daily; always worth doing |
| Gauntlet Mode clear | 100-200 | Best consistent source |
| Secret boss kill | 50 | Each secret boss once per run |
| Hard Mode multiplier | +50% all sapphire gains | Worth enabling once you can clear Chapter 3 consistently |

### Fastest Sapphire Farm

**Gauntlet Mode speed runs** are the most efficient sapphire-per-hour:

1. Equip your fastest-clearing build (Greatsword or Crossbow with AoE tablets)
2. Run Gauntlet Mode on Normal difficulty
3. Skip exploration — rush to boss doors, only detour for Green Heart nodes if HP is low
4. Each clear: ~100-150 sapphires in 15-20 minutes

**Alternative: Chapter 1-2 boss rush**. If Gauntlet is too hard:
1. Start a normal run
2. Clear Chapters 1 and 2 (fastest chapters)
3. Die intentionally to the Chapter 3 boss (or clear it if you can)
4. Repeat — ~60-80 sapphires per 10 minutes

### What to Unlock First (Priority Order)

| Priority | Destiny Inscription | Sapphire Cost | Why |
|:--:|------|:--:|------|
| 1 | **Home Repair** | Low | Unlocks the Talent tree — gateway to all other meta-progression |
| 2 | **Extra Potion Slot** | Medium | +1 consumable slot is a massive survivability increase |
| 3 | **Starting Weapon Choice** | Medium | Pick your weapon at run start instead of random |
| 4 | **Artifact Slot +1** | High | Second permanent artifact slot — build-defining |
| 5 | **Shop Discount** | Medium | 15% off all shop purchases |
| 6 | **Bonus Gold Start** | Low | Extra gold on run start helps early shop purchases |

## Gold Farming (Mid-Run Economy)

Gold is spent mid-run at shops, anvils, and enchantment altars. It resets every run.

### Gold Sources

| Source | Gold Range | Notes |
|------|:--:|------|
| Breaking objects (barrels, crates, pots) | 5-30g each | **Break everything.** Adds up to 200-400g per chapter |
| Enemy kills | 3-15g each | Elites drop more; bosses drop the most |
| Money nodes (coin icon on map) | 80-200g | Always take these if you need gold for an upcoming shop |
| Selling unwanted relics/tablets | 15-50g each | Sell off-theme items at shops |
| Secret rooms | 100-300g | Highest gold density in the game |

### Gold Spending Priority

1. **Greater Healing Potions** — always buy if available before a boss floor
2. **Rare/Epic tablets** that match your build element
3. **Weapon upgrades** at the Anvil (only if you're committed to your current weapon)
4. **Buff potions** before the boss (only the one matching your build)
5. **Rerolling shop inventory** — last resort; only when you have excess gold and need a specific item

**Don't waste gold on**: Common relics past Chapter 2, off-element artifacts, cosmetic items (they're fun but don't help you clear).

## Inscription Shard Farming

Inscription Shards unlock and upgrade socket slots on your gear. They persist between runs.

### Shard Sources

| Source | Shards | Notes |
|------|:--:|------|
| Secret rooms | 2-5 | Best source — learn to spot cracked walls |
| Boss kills (first time per difficulty) | 3-8 | One-time bonus; replaying same boss gives fewer |
| Challenge room clears | 1-3 | Arena and Gauntlet rooms |
| Daily Challenge rewards | 2-5 | Resets daily |
| Hard Mode multiplier | +50% | Same as sapphires |

### Shard Farming Route

**Secret room hunting** is the most efficient shard farm:

1. Equip the **Astral Compass** artifact if you have it (reveals secret rooms)
2. Run Chapters 1-3 — these have the easiest-to-spot cracked walls
3. Search every wall section in dead-end rooms; cracked walls have a distinct visual texture
4. Reset after Chapter 3 boss and repeat

A good run yields 8-15 shards in ~20 minutes.

## Artifact Farming (Endgame)

Permanent artifacts are unlocked through specific achievements, not random drops. For the full artifact unlock list, see the [Artifacts Guide](/guides/artifacts-guide). Key farming-relevant artifacts:

| Artifact | Unlock Condition | Farming Use |
|------|------|------|
| **Golden Maple Leaf** | Clear Chapter 2 | +15% XP — faster leveling during farms |
| **Astral Compass** | Find 10 secret rooms | Reveals secret rooms on map — essential for shard farming |
| **Vault Key** | Clear Gauntlet Mode | +1 relic slot — more build options during farms |

## Time-Efficiency Summary

| What You Want | Best Method | Est. Per Hour |
|------|------|:--:|
| Sapphires | Gauntlet Mode speed runs | 300-500/hr |
| Gold (mid-run) | Break everything + prioritize Money nodes | Varies per run |
| Inscription Shards | Secret room hunting (Ch 1-3) | 25-40/hr |
| Weapon unlocks | Clear chapters with different weapons | Per achievement |
| Artifacts | Complete specific unlock conditions | Per achievement |

**The most important farming tip**: don't obsess over farming. Every run gives sapphires even if you die on Chapter 1. Unlock Home Repair first, grab Golden Maple Leaf, and then just play — the meta-progression will come naturally as you learn enemy patterns and build synergy.
