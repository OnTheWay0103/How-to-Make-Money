# Infinite Mode Guide — The Real Endless Content in Sephiria 1.0

**Sephiria 1.0 / Updated: August 6, 2026**

> **⚠️ Correction (Aug 6, 2026):** pre-1.0 guides promised a literal "Infinite Mode" unlocked after Hard Mode, with floor milestones at 25/50/100 and endless artifact drops. **That mode does not exist in the released game.** Sephiria 1.0 (launched July 31, 2026) has 6 chapters and ends at Chapter 6 — the real endless content is **Gauntlet Mode** (endless waves), **Hard Mode** (60 levels), and **Boss Rush**. This guide covers the endless content that actually shipped.

---

## The Endless Content That Actually Exists

| Mode | Format | Unlock | The "Infinite" Appeal |
|------|--------|--------|-----------------------|
| **Gauntlet Mode** | Endless wave survival, no final wave | Complete all 6 chapters + Floor 20 in New Game+ + 500 Memoriam Shards entry | The true infinite mode — dies when you do |
| **Hard Mode** | 60-level climb with 6 modifiers | Complete the base game (Chapter 6 ending) | The leaderboard ladder |
| **Boss Rush Mode** | Back-to-back boss gauntlet | Endgame unlock | Fast replayable boss practice |

Gauntlet Mode is the closest thing to the "Infinite Mode" pre-release guides described: **the gauntlet continues until you die. There is no final wave.**

## Gauntlet Mode: The Real Infinite Mode

### Core Rules

- **Fixed loadout** — weapon, blade arts, relics, and inscriptions are locked before the run; no changes mid-run.
- **No rest points** — health and Focus carry over from wave to wave. Sustain decides your ceiling.
- **Scaling** — every 5 waves difficulty rises; every 10 waves a break wave (elite or boss) appears.
- **Wave types** — standard, elite, boss, swarm, hazard, curse, and void (wave 50+).

### Wave Survival Guide

| Wave Type | Waves | Best Strategy |
|-----------|-------|---------------|
| Standard | 1-4, 6-9... | AoE blade arts, conserve Focus |
| Elite | Every 5th | Focus one elite at a time, parry often |
| Boss | Every 10th | Learn patterns, use Special arts |
| Swarm | 15, 25, 35... | Wide-arc blade arts + mobility relics |
| Hazard | 18, 28, 38... | Mobility arts, kite off the fire/ice pools |
| Curse | Every 20th | Kill at range; save dodge for death explosions |
| Void | 50+ | Defensive relics mandatory; Sacred Radiance recommended |

### Scoring for Leaderboard Prestige

| Factor | Value |
|--------|-------|
| Kill score | 100 pts standard / 500 elite / 2,000 boss |
| Speed bonus | 1.5x on kills if 5 waves cleared in 3 minutes |
| Combo multiplier | +0.1x per kill within 3 seconds (max 5.0x) |
| No-hit bonus | 2x points for a damage-free wave |
| Parry bonus | +50 pts per parry + 1s combo extension |

**Rank thresholds:** Bronze (0-10k) → Silver (10-25k) → Gold (25-50k) → Platinum (50-100k) → Diamond (100-200k) → Eternal (200k+). Eternal rewards 2,500 Memoriam Shards, an ancient relic, and the Eternal Emblem title.

**The score rule:** speed and no-hit bonuses multiply everything — a slow clean run scores worse than a fast scratched run. Push tempo.

### Endless-Specific Rewards

- **Gauntlet Crest** — +50% score for 10 waves (use at wave 20+).
- **Gauntlet Crown** — permanent: start every run with +1 Focus charge.
- **Ancient Relics** — gauntlet-only, including Infinity Stone (all blade arts cost 1 less Focus) and Unyielding Heart (one revive per run).

## Hard Mode: The 60-Level Ladder

Hard Mode is the other half of the post-game: a 60-level climb (vs. the base cap) with **6 modifiers** on top of base difficulty:

| Modifier | Effect |
|----------|--------|
| Blood Festival | Enemies lifesteal; healing scales with party size |
| Pseudo-Vanguard | Elites gain vanguard-style buffs |
| Deterioration | Progressive pressure over the climb |
| Tension | No potions in boss fights |
| Heavy Heart | You carry junk artifacts |
| Proliferation | Enemies multiply world-wide |

**Infinite-style advice for Hard Mode:** builds that sustain (life-steal Scythe, Spellweaver Tome) outperform burst builds past the mid-climb — the same rule that governs Gauntlet past wave 40. See the [Hard Mode Guide](/guides/hard-mode-guide) for the full modifier breakdown.

## Building for Endless Content

| Mode | Build Priority |
|------|----------------|
| Gauntlet (early waves) | Burst + AoE to farm score speed bonuses |
| Gauntlet (wave 30+) | Life-steal, healing relics, defensive survivability |
| Gauntlet (wave 50+) | Defensive relics mandatory, Sacred Radiance |
| Hard Mode | Sustain, sustain, sustain — modifiers punish downtime |

**General rule:** the deeper you go, the more your build must heal itself. Every endless run in Sephiria is decided by your sustain floor, not your damage ceiling.
