This page answers the platform questions people actually ask about Dressmaker — *is it on Mac, is it on Switch, is it on Switch 2, is it on PS5 or Xbox, is there a mobile version* — with a direct answer for each, plus the reasoning behind it. Almost all of these answers are **no**, and the source for that is Steam's own platform data for App ID **4019220**.

## macOS: Yes — With One Caveat

Dressmaker is a **macOS game**, and the official minimum specification is:

| Component | Requirement |
|-----------|-------------|
| Processor | **Apple M1** |
| Memory | 8 GB RAM |
| Storage | 1 GB available space |

**The caveat: the official minimum names Apple M1, which is Apple silicon.** Intel Macs are not listed in the minimum specification. If you are on an Intel Mac, treat compatibility as **[Unconfirmed]** and check the Steam store page again closer to launch — minimum specs are sometimes revised, and the store page is the only place that revision will appear.

For comparison, the official **Windows** minimum is Windows 10 or later, an Intel Core i5 or AMD Ryzen processor, 8 GB RAM, Intel UHD 630 graphics or better, DirectX 11, and 1 GB of storage. Both platforms require 1 GB of free disk space, which is small — Dressmaker is a 2D simulation, and the install size reflects that.

**No recommended specifications have been published for either platform.** Any site showing "recommended" specs for Dressmaker is estimating.

## Why There Is No Console Version

No PlayStation, Xbox or Nintendo version of Dressmaker has been announced. This is not a case of an announcement being imminent and unlisted — there is simply no console version, and no stated plan for one.

That is consistent with how the game is built. Dressmaker is designed around precise pointer input: placing pattern pieces on cloth, aligning grain lines, guiding fabric through a sewing machine. Steam lists a **Mouse Only Option** for the game, which tells you the designers were optimising for a mouse rather than a gamepad. Porting that interaction model to a controller is a real design problem, not a packaging exercise.

It is also consistent with how Cozy Lives is positioned: Dressmaker is the first release from Free Lives' cozy-games label, and a first release from a new label on two platforms is a normal scope.

**If that changes, the store page changes first.** No third-party "Dressmaker Switch release date" article can be more current than the official listing.

## Is Dressmaker on Nintendo Switch or Switch 2?

**No — and no Switch version has been announced for either console.**

This is one of the most-searched Dressmaker questions, and the interest in Switch 2 specifically is understandable: it is a cozy simulation, and cozy simulations do well on handhelds. But interest is not an announcement.

The practical warning that follows: because "Dressmaker Switch" is a searched phrase, it is also a phrase that scam pages target. There is no Switch version to download.

## Mobile: There Is No Official App, and No APK

**There is no official Android or iOS version of Dressmaker.** Steam's platform data lists Windows and macOS only. No mobile port has been announced.

Because the game does not exist on phones, there is no legitimate APK. If you have found a site offering a "Dressmaker APK", a "Dressmaker mobile mod", or a "Dressmaker free download for Android", then whatever that file is, **it is not Dressmaker** — there is no official build for it to be a copy of. Installing it is a straightforward security risk.

The same applies to desktop: the only two legitimate sources for Dressmaker are the **Steam store page** (App ID 4019220) and the **itch.io prototype page**. Anything else is unofficial. We go through this in more detail in [Is Dressmaker Free?](/guides/dressmaker-free-steam-vs-itch-prototype)

## What About Steam Deck and Linux?

**Linux:** Steam lists Linux as **unsupported** for Dressmaker. That is a decision by the developer, not an accident of the store listing.

**Steam Deck:** no Steam Deck compatibility rating had been published as of September 12, 2026 **[Unconfirmed]**. Two things are worth noting rather than guessing about:

- Deck compatibility ratings are applied by Valve and can appear at or after launch, often without an announcement
- Dressmaker's listed **Mouse Only Option** means the game does not assume a controller, and its **Playable without Timed Input** category means it does not demand twitch reactions — which is generally good news for Deck play, though this is our reasoning, not a confirmed rating

Check the store page after launch for an actual rating rather than trusting a pre-release claim.
