## Genre and Play Mode

| Field | Value |
|-------|-------|
| Genres | Casual, Simulation |
| Play mode | **Single-player only** |
| Co-op / multiplayer | None |
| Steam features | Achievements, Family Sharing, Custom Volume Controls |
| Accessibility | Mouse Only Option, Playable without Timed Input |

Dressmaker is a **single-player game**. There is no co-op, no multiplayer, no PvP and no online component of any kind — Steam lists single-player as the only play mode. If you have seen a "Dressmaker multiplayer" video or article, it is describing something that does not exist.

The two accessibility categories are worth calling out because they are genuinely unusual and they fit the game's design: **Mouse Only Option** and **Playable without Timed Input**. Dressmaker is built around deliberate, unhurried decision-making — cutting fabric and stitching seams — and Steam's categories confirm the game does not require you to play against a clock.

Steam also lists **achievements** as a category, which confirms the game ships with them [the achievement list itself is Unconfirmed].

### macOS (official minimum)

| Component | Requirement |
|-----------|-------------|
| Processor | Apple M1 |
| Memory | 8 GB RAM |
| Storage | 1 GB available space |

A few observations that follow directly from these official figures:

- **1 GB of storage is small.** Dressmaker is a 2D simulation, not a 3D open world, and the install size reflects that. You will not need to clear space for this one.
- **8 GB of RAM is the standard floor.** If your machine runs other modern indies comfortably, it will run Dressmaker.
- **Integrated graphics are fine.** Intel UHD 630 is an integrated GPU, so a discrete graphics card is not required on Windows.
- **macOS requires Apple silicon.** The official macOS minimum is Apple M1. Intel Macs are not listed in the minimum specification — if you are on an Intel Mac, treat support as **[Unconfirmed]** and check the store page again closer to launch.
- **No recommended specifications have been published.** Any site listing "recommended" specs for Dressmaker is estimating, not reporting.

## What You Get on September 21

To set expectations accurately, here is what is officially confirmed to be in the game at launch:

- **The full dressmaking pipeline** — sketch, fabric selection, pattern arrangement and cutting, machine sewing, decoration, mannequin preview
- **Five fabrics** — cotton, linen, wool, silk and velvet
- **Per-panel fabric control** — a different fabric for each panel of a garment
- **Grain and bias modelling** — pattern alignment changes the finished dress
- **A town of customers** — orders built around important events and individual tastes, which you can satisfy or sabotage
- **A shop window** — display your own designs and sell pre-made dresses off the rack
- **Reputation and coin** — the two confirmed reward tracks
